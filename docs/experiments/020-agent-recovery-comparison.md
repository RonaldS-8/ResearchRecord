# 实验 020 · Agent 级动作条件恢复试点

状态为已批准的探索性预登记。配置、分组、提示、判据和代码随本次提交冻结，仅在 LabServer 执行。设计见[ADR-0018](../adr/0018-agent-recovery-comparison.md)。

## 假设与对照

利用历史动作价值和任务内反馈的 Agent，在动态任务上可提高严格完成率，或在完成与正确停止不退步时节省恢复费用。竞争解释包括静态恢复约束已足够、近期反馈配合成本阈值已足够、固定续程已覆盖前瞻收益，以及模型增量来自工具实参绑定。历史偏移可能使旧估计失效。预期低价且有信息的诊断能改变后续选择并产生净收益，等价低价的无信息诊断没有决策收益。

核心比较为 Action-Conditioned Memory、LLM + 轻量决策器分别对原始 ReAct 和完整冻结 BTM。另跑 BTM 去先重试约束和 BTM 静态提示加均匀先验。非 LLM 保留 Gate 17 的固定重试优先／切换优先、历史局部阈值、最近反馈规则、三节点强闭式规则（备用不可靠时沿用固定局部续程）、确定性解析加相同轻量决策器、完整有限步规划。它们共用公开输入与动作条件校准，逐步决策。

## 最小配对矩阵

复用 Gate 17 的合同、价格、执行预算、依赖、双账本与严格终态审计。各主格使用预约／凭证归档两家族、新测试种子 1821–1822、每家族每种子实例 0，共四个起点。两家族曾用于 Gate 17 评估，Gate 18 复用家族合同并使用新的事件键，结论限于这些合成合同。策略共享合法首错及外生事件表。分支和调用顺序改变时，同一语义事件仍使用同一个抽样键。

| 格 | 复用条件 | 控制与比较 |
|---|---|---|
| 动态 | `dynamic`，匹配历史 | 跨节点相关故障。第二节点的成功回执可能追加第三节点及后续实参。 |
| 独立 | `independent`，匹配历史 | 保持公开路径及边际主工具成功率，移除跨节点关联。 |
| 独立＋旧历史 | 独立格同一批起点，改用动态格的冻结历史 | 只换历史摘要，检验相关结构偏移。复跑 BTM、BTM 去先重试、Memory、混合组和使用校准的规则，其余组复用对应配对结果。 |
| 低价诊断 | `cheap_probe`，动态匹配历史 | 有信息诊断，费用 1/20。 |
| 无信息诊断 | `null_probe`，动态匹配历史 | 同价，改变证据质量。 |
| 备用压力 | `unreliable_backup`，匹配历史 | 备用有失败风险，自然观察路径阻断、早停与备用后的续程。 |
| 共同阻断 | Gate 17 的双失败见证，两家族各两个新标识 | 使用同一合法前缀，再实际执行 A 和 B 并记录两次失败，随后在仍有预算的同一公开阻断点交给 Agent。此处唯一可用动作是停止，单列为接口验收。 |

主格 20 个起点，另有 4 个共同阻断起点。六个模型策略共 144 条回合，独立格旧历史复跑 16 条，共 160 条评估轨迹，另有 36 条训练历史回合。每回合最多八次模型请求，全批最多 1,568 次。单步最多 16,000 输出 Token、300 秒超时，串行、无 SDK 自动重试，沿用项目的 Qwen 模型修订、聊天模板和采样配置。配对组共用模型种子和决策步号，记录服务实际版本和种子。协议失败单独终止该回合并计入分母。服务故障与非法动作分列。

## 历史来源与隔离

- **BTM 观察历史。** 对三个历史条件各用包裹和发票两训练家族、种子 1801–1803、每家族每种子两个实例，各生成 12 条相同权重的基础 ReAct 轨迹，共 36 条。留存回合和切换统计的支持数。条件内从相同公开键取值，无覆盖用明确标记的均匀先验。若主比较依赖的主工具／错误或首节点 A→B 切换全无样本，保留该格结果并标为 BTM 证据不足。
- **动作条件校准。** 沿用 Gate 17 的独立分配 A／B 校准臂、训练家族和种子。A 臂以可靠备用保证三个节点都能采集 A 的可见成败，用小网格拟合二状态保持概率和对称发射概率。B 臂用预分配的首次 B 返回估计备用率。发射概率描述给定候选状态时工具成功的概率。拟合网格取发射概率 1/2、3/5、7/10、4/5、9/10、19/20，保持概率沿用 1/2、3/4、9/10。最大似然并列时优先较弱关联，再优先较弱发射差异。按 Gate 17 验证家族制品发布和原验证种子报告预测误差、分母及不可区分的候选。只使用合法训练观测拟合，诊断精度和路由概率沿用公开合同。
- 历史条件映射在运行前登记，公开模型请求只含指定统计摘要。任务及凭据标识不编码拆分、历史条件、种子和隐藏实现。冻结后验跨回合复用，任务内更新仅用已揭示回执。观察历史与受控训练各自披露采集策略和调用规模。BTM 对比度量完整方法包差异，两个历史对照与解析对照用于解释来源。

## 记录与 Go / No-Go

对每格、家族和模型种子报告严格完成率、正确停止率、工具费、诊断费、输入／输出 Token、模型与端到端延迟、调用数、调用冗余、非法动作及协议／服务故障。费用包含失败调用。成功轨迹的工具冗余相对同实现的最短合法完成，诊断调用单列，失败轨迹另报已花费用和调用数。共同阻断点的正确停止分母是所有交接回合。自然阻断单列配对的结构不可恢复实例分母及各策略到达可认证阻断的比例，只有在合法反馈足以认证阻断后主动停止才计正确。预算耗尽与过早停止分别记录。没有不可恢复样本的格记不适用。口径沿用现有计价与评分，不启用全局指标草案。

逐对报告完成不一致数、费用差和首动作分歧。后续动作仅在共同公开检查点直接比较，分叉后的后续轨迹单列。每个观察到的收益至少复核其首个分歧、证据来源和后续账单。BTM 完整／均匀对照检验历史后验，完整／去先重试检验提示约束，Memory／ReAct 检验提供估值的效果，混合组／确定性解析检验 LLM 语义提取的增量。按同一公开历史对照冻结值与反馈更新值的动作排序，辅助判断信息作用。对已分叉的策略轨迹只报告配对结局和机制解释。

- **工程 Go。** 通过既有防泄漏与专项测试。同起点前缀、公开权限与事件键一致，未揭示的未来结果变更时请求输入不变。拒绝越权、错误实参及缺证据抽取，账本、依赖、终态和共同阻断独立验收通过。若核心 BTM 历史缺乏覆盖，按证据不足处理，保留失败和负结果。
- **方法 Go。** 预指定五个自然主格为主要比较。候选须分别对 ReAct 和完整 BTM 满足以下任一条件。其一，净多完成至少两例。其二，完成例数相同且平均工具与诊断总费用至少少 5%。两条均要求两个家族方向一致（允许一家持平）、无家族完成数下降、正确停止数及非法动作率不退步，并至少有一条可复核的同检查点后续决策分歧。费用较高的完成率收益单列取舍。Token、延迟与环境费用分别报告。先重试消融解释全部差距时，仅记录提示约束效应。
- **强基线 No-Go。** 候选若只胜过 LLM 提示基线，而同权限最强简单规则或确定性解析加同决策器达到同等或更好的完成、停止与恢复费用，则记录 Agent 对照结果，停止据此扩大方法。旧历史导致的退化、诊断的净亏损、两家族方向冲突及协议失败如实报告。小批结果只用于决定是否值得进一步验证。

保存到 `results/<run_id>/` 的内容包括冻结提交、环境和模型版本、完整配置、随机种子、训练统计、全量模型请求与响应、工具与诊断轨迹、评分、逐对差异及失败记录。已有冻结配置和结果单独保留。
