# 实验 031 · main Gate 29 家族扩展与 Agent 验收

2026-11-11。探索性开发与工程验收，见 [ADR-0029](../adr/0029-benchmark-family-expansion.md)。

## 预登记

**问题与假设。** 同一执行和评分基础设施能验证不同业务义务。Qwen 在库存首动作被约束为查询时，能够自行绑定请求号、消费实际结果并完成续程；在新家族可从自然语言执行合法闭环。竞争解释是写死续程、凭据越权、参考序列评分、效果漏记、诊断泄漏或模型漏义务。成功和失败均保留，不以方法优劣选任务。

**现有证据。** Gate 28 固定检查点和完整启动各一对，四回合都在写入超时后停止，无诊断、盲重试或重复效果，严格完成 0/4。本轮原样复核归档及当前 CPU、防泄漏接口。

**新家族。** 制品发布读取构建或授权镜像，凭项目发布权限创建指定版本记录，再查询实际发布内容，核验项目、版本和摘要。非幂等发布可能在提交前／后丢回执，按项目版本查询当前记录。设施授权从人员资格与独立审批取得证据，使用限定区域凭据设置指定人员的权限期限，再查询生效状态。同值置位幂等；过期凭据可在原范围刷新；审批拒绝不能靠刷新绕过。两个读取入口均须具备合法语义，不把镜像名或不同人员当独立实现。

**CPU。** 正常和备用路径、暂态重试、持续切换、共享失效、写入未提交／丢响应、资格／审批／凭据来源、越权、伪造或跨会话回执、缺复核及重复副作用均验收。发布重复实际创建应拒绝，设施同值幂等重放只计一次效果，语义变更再写须记录。诊断只读实际当前状态且单独计费。所有旧测试回归。脚本工具序列只验工程。

**模型回合固定为 6 个。** 先运行库存未提交／已提交检查点各一次，第一个 SDK 工具动作约束为请求查询，模型自己生成实参，此后恢复完整合法工具集。辅助组单列。随后原生 ReAct 完整启动制品持续读故障、制品已提交丢回执、设施正常、设施凭据过期各一次。若 CPU 未通过则不运行模型。结果不触发加跑或路径提示修补。

模型为 Qwen3-4B-Thinking-2507，修订 `768f209d9ea81521153ed38c47d515654e938aea`，温度 0、种子 2901，每回合最多 12 次 SDK 请求、每次 6144 输出 Token，工具总预算 16。最多 72 请求。辅助检查点沉没执行费 2 单列。沿用每次已公布接口调用 1 工程单位，工具、诊断、Token 和时延分报。归档版本、配置、配对事件及完整请求／回执／状态，所有失败保留。

**放行。** 两个新家族各须有严格 CPU 闭环，且至少一家有真实 Agent 完整执行证据。失败按实际调用归为恢复选择、工具理解、绑参、缺后续义务或环境缺陷，无法区分的原因明确标记。自主 ReAct、受约束首动作和脚本续程分别报告。本轮不估计动作因果价值，不进行 BTM／Memory／Hybrid 比较。

## 谱系与下一阶段

新增两个任务均为开发样例。基础义务、恢复相关工具实现和故障事件用显式清单记录，种子或参数改写不增加独立样本。任务轴留出新的目标／依赖，复用公开合同；契约轴隔离等价插件、传递后端、身份／刷新链；故障轴隔离持续性、关联范围或反馈规则及事件派生。非目标因素共享须预登记。统一 Agent、执行器与账本属于基础设施。

待家族闭环与分组通过后再登记独立探索池。写入规则需支持按实际状态查询后恢复，与原生 ReAct 和知情可行参照共享合法工具和同一 LLM 续程。脚本 $Q^{\pi_{\rm rule}}$、模型 $Q^{\pi_{\rm Agent}}$ 与缺支持外推各自标记。样本量、验证侧规则选优、配对区间及预算须先审核。
