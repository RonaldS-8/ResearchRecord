# 实验 027 · Gate 25 ToolMaze Agent 恢复工程验收

2026-11-10。探索性 CPU 工程验收。依据[ADR-0025](../adr/0025-toolmaze-agent-recovery.md)和[Gate 24 资产审计](026-agent-recovery-benchmark-audit.md)。云端基线 `e386eff`。本轮验证执行与评分，模型效果留待独立试验。

## 预登记

- **问题与假设。** 在相同公开首错下，原生工具调用和已观察回执可以驱动合法重试或切换，独立验收能识别真实完成。竞争解释包括插件成功或原生评分误报、私有参考路径补参、同值但没有合法生产者、账本漏掉复合工具的内部写入，以及故障标签进入模型请求。
- **样本与条件。** 固定 C3-001、C3-002。正常、原读工具首次暂态失败、同工具持续失败、两个注册读取入口均返回明确不可用四种工程夹具。仅拦截选定读取工具。暂态和持续条件的首错文字相同。请求费用按每次已公开工具调用 1 工程单位检查账本，含失败调用。无显式诊断、无模型计费。预算 16 次调用或回答轮次。回放使用确定性调用序列，非模型评估或方法比较。
- **预期通过。** C3-002 两条原生替代路径分别可经合法重试和切换完成。错回执、缺步骤、重复效果、未完成即停止及私有工具调用均不得计成功。可公开证实全部候选入口阻断时正确停止。C3-001 可执行前缀和归档，但错误票据与预约请求不得计完成。配对请求无故障模式、真值、未来结果、参考路径或测试标签。收费与实际调用一致，历史隔离测试通过。
- **独立性审计。** 只读清点现有 C2–C4 任务、替代入口工具族与 P1/P2 文件覆盖，六个设计样例成组排除。报告库存、代理分组和已通过验收的独立样本三种数字。样本审计不按策略收益筛选。
- **证据。** 在 LabServer 隔离工作树使用既有 `.venv` 运行 CPU 验收。保存运行提交、配置、Python/SDK 版本、输入摘要、完整验收轨迹和结果。保留失败批次。测试客户端只回放本地构造的结构化消息。
