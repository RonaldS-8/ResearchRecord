# 实验 008 · Gate 6 显式故障恢复决策空间审计

状态：范围已批准，具体设计待审核。依据 [ADR-0007](../adr/0007-gate6-native-recovery-audit.md)，先审计 C3，再根据验收结果决定是否扩展 C4。复用 C2 的既有观测与规则对照。全程使用云端现有环境和原生 ToolMaze，范围限 P1/P2。仅回放工具和评分，不调用 Qwen，不实现 HMM，不重跑 Gate 5。

## C3 小样本验收

- 按任务 ID 排序，选择最先具有 P1/P2 成对原生输入的 3 个 C3 任务。枚举其参考路径中的首故障起点，按工具与参数的完整前缀去重。样本选择与运行结果无关。无法回放的起点保留在清单中，不事后替换。
- 每个起点设共同恢复调用预算，取该任务最长参考路径的调用数加 2，以容纳完整切换路径和最多两次起始重试。固定重试基线比较上限 1 与 2，失败后切换。所有分支均重建执行器并重放同一前缀。超预算单列，探索结论限于该预算和枚举范围。
- 逐条用保存的原生轨迹重新评分，并核对通过标记、匹配路径、成功与失败调用计数和可见反馈。分别报告原生评分结果与合法可执行性。核对同一策略在相同可见输入时首动作一致，检查隐藏字段不会进入策略输入，并运行必要的防泄漏测试。
- 小样本只验收回放与评分流程，历史统计的独立来源与正式比较范围须在后续运行前锁定。验收后提交样本覆盖、失败案例和评分差异，等待用户决定是否扩展。

## 配对与判据

1. **状态不可区分性。** 按任务、初始路径、工具调用及参数配对。用独立的原生执行器回放同一合法前缀，到首个显式故障为止。比较策略实际可见的任务、工具说明、调用历史与原始反馈，原样保存。初始可见信息有差异的样本单列。前缀无法合法回放的样本记录原因和分母。
2. **最优动作是否变化。** 从同一配对起点回放重试、直接切换到各候选路径、重试失败后切换及停止。验证参数来源与依赖，使用原生评分，并记录合法完成、失败或停止、逐工具调用数和从首次故障后开始的总调用数。C4 保留每个替代工具组的首次触发状态，回放后续故障。仅在明确的候选路径、步数预算与成本口径下报告最优，保留所有并列动作。如果存在跨 P1/P2 的共同最优动作，该对不构成按状态改变动作的证据。
3. **后续反馈的增量价值。** 对照直接切换、重试一次失败后切换、预登记的固定重试上限，以及仅使用既有或独立训练任务的历史统计规则。策略可见信息、动作集合与预算对等。重试失败本身是合法信息，已由重试后切换基线利用。用全状态知情参照估计改善上界，参照单列，路径真值和 P 标签不进入被比较策略。若未能建立独立且可比的历史统计，明确将该项标为未验证。

## 成本与阶段判断

- 任务完成与调用成本分开报告。用原始工具调用数作审计代理，同时保留逐工具符号成本，便于发现价格假设是否改变动作排序。不采用未确认的正式计价，也不把主动停止等同于正确停止。
- 信息价值的候选证据须同时满足首次观测相同、两态的最优首动作集合不相交，以及使用后续反馈的可执行规则在任务完成率不降时节省调用。以配对状态分别报告结果，并显式标记历史统计的来源和状态权重。知情参照的优势只作为上界。若简单规则已达到该上界，则本审计条件下没有进一步收益空间。
- C3 完成后先汇报三项判据、未覆盖样本和反例，由用户决定是否用同一口径审计 C4。禁止依据结果调整原始数据、工具模拟器、扰动或评测。正式运行前登记预算、样本范围、统计来源、输入与价格假设。云端保存配置、完整轨迹、评分、环境版本及运行提交。
