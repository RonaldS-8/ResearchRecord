## 假设与变量矩阵

在相同静态知识、操作规则和合法实参绑定下，动作条件价值可能改善恢复动作选择。竞争解释是共同知识、先重试条款或参数修复已解释增益，或强简单规则已覆盖可获得的收益。

| 组 | 动态信息 | 决策与约束 | 用途 |
|---|---|---|---|
| BTM 任务级统计 | 工具／错误和来源→替代工具的回合完成后验、分母 | LLM 选动作，共同规则 | 核心对照 |
| Action-Conditioned Memory | 当前各合法动作的完成概率、工具费、诊断费及训练支持 | 同一 LLM 选动作，共同规则 | 与 BTM 只比较统计表示和估值 |
| LLM + 动作价值决策器 | 与 Memory 相同的历史拟合和估值 | LLM 抽取，校验后由决策器选动作，共同规则 | 混合循环及语义抽取对照 |
| 无历史 | 空历史字段 | 与核心提示组相同的选择器和共同规则 | 测量静态知识和规则下历史的增量 |
| BTM 加先重试 | 与核心 BTM 同一份后验 | 只加 Gate 18 的先重试提示条款 | 与核心 BTM 组成加约束／去约束消融 |
| 非 LLM 参照 | 同权限的公共观察与同源估值 | 固定切换优先、三节点强规则、确定性解析加同一决策器 | 检查简单规则和语义抽取的增量 |
| Gate 18 原始参照 | 原始 ReAct、完整 BTM 及原始消融的已存结果 | 原端到端提示与实参接口 | 独立报告，不并入新接口的因果对照 |

共同规则允许当前合法的诊断、重试、切换和停止。先重试消融只改提示，动作菜单和执行权限一致。在合法重试仍可用的检查点记录实际遵循率，并分别记录何时不适用、首次动作改变及后续费用。正确停止评分沿用 Gate 18，过早停止与预算耗尽分列。

## 冻结资产和运行规模

- 复用 Gate 18 五个自然主格的 20 个起点，保持预约／归档家族、种子 1821–1822、合法前缀、外生事件键、工具与反馈、诊断价格和步数预算。共同阻断 4 例只验收合法停止与接口。独立格旧历史 4 例只复跑三种核心组，复用同一个事件表，只换冻结摘要。旧历史格的无历史参照复用本轮匹配独立格结果。原始端到端参照引用 Gate 18 的归档。各配对组共用 Qwen3-4B-Thinking-2507 修订、采样配置和步种子。输入／输出 Token 与延迟分项计量。
- 五个模型组各跑 24 个主格与共同阻断回合，另有 12 个旧历史回合，共 132 个配对评估回合。先用两个训练与评估名单之外的既有发布家族验证夹具做模型验收。一个走至少两个决策并经回执进入附加验证再严格完成，另一个在共同阻断点合法停止。每回合最多八次模型请求，全批上限 1,072 次，串行，无自动重试。验收失败时保留轨迹并暂停配对。
- 同源训练使用 Gate 18 的三个冻结历史队列，每队列 12 条，登记输入文件哈希。以实际合法动作及已返回观察拟合 Gate 18 的保持／发射参数网格及原并列规则。用 A 成败和实际购买的诊断更新观测似然，每次合法推进才转移，B 率用该队列实际 B 尝试的成败频率。归档每队列、节点和动作的支持数，并分别列 BTM 键覆盖与 $Q^\pi$ 的直接样本或模型外推。已核对三个队列首节点 B 各 12 次，A 分别为 0、0、5 次。保留缺样本标记，禁止用测试结局或 Oracle 补数。Gate 18 的独立校准验证数据只用于冻结后的预测核验。

## 分析与 Go / No-Go

- **工程 Go。** 防泄漏和专项测试覆盖归档合法绑定、坏实参拒绝、抽取的唯一权限、伪造或错引回执、逐轮调用决策器、诊断费独立入账、动态分支和阻断停止。两个云端模型验收回合均按预期结束。配对期间每个实际调用和合法账本独立审计，失败回合保留并计入分母。
- **误差与分歧。** 在每个主起点及固定切换轨迹的后续公开检查点，用评估侧相同外生事件对每个合法动作分支回放。后续各臂共用冻结的局部续程 $\pi$，严格评分并单列费用。比较 $Q^\pi$ 的完成概率与实际结局，报告 Brier 分数，以及两类费用各自的平均绝对误差和有符号偏差。按动作和支持度分层，同起点的分支共用随机量，样本数按起点列示。BTM 回合后验以其本身的回合目标报告覆盖及校准，不能直接当作单个动作的预测。回放结果不反馈给策略。逐对记录首次合法动作分歧、后续共同检查点、退出原因和实际账单。区分合法动作差异、提示遵循和协议拒绝，分叉后的结果作配对结局。
- **方法 Go。** 以五个自然主格为主，动作价值候选相对共同规则 BTM 净多完成至少两例，或完成数相同且每任务平均工具费与诊断费合计至少低 5%。要求两个家族方向一致（允许一家持平）、无家族完成数下降，正确停止和非法动作率不退步。至少有一例可复核的合法决策分歧解释收益，且证据不全来自训练无直接覆盖的动作。单列每格严格完成、正确停止、工具费、诊断费、调用数、输入／输出 Token 与端到端和模型延迟。失败回合计费，双成功子集另列以排查低费用来自提前退出。
- **No-Go 或证据不足。** 若动作一致、强简单规则在完成和停止上持平且在可比完成轨迹上费用不高，或收益只能由提示条款与实参修复解释，则保留负结果，停止扩大该方法。覆盖不足、协议未放行或跨家族冲突时明确结论范围。复用 Gate 18 的测试起点构成探索性配对复查。
