## 事前冻结的 simple_feedback

这是工具级强制控制器，由 LLM 生成全部参数并完成任务；不提供额外自然语言建议，不伪造回执，不自动生成引用，不自动答复。只输入同一公开任务/合同/报价/已观察调用：

1. 已获有效回读：解除限制，由模型给最终答复；已写但未回读：选择回读工具。
2. 已有主读证据或粒度核验证书：选择写入；仅有备用待核验凭据：选择粒度核验。
3. 主读已经两次返回失败：选择备用读。
4. 没有可写证据、诊断尚未调用且公开诊断价≤1/10：选择诊断，最多一次。
5. 诊断实际返回 persistent_hint：选择备用；transient_hint 或无诊断：至多重试主读一次，再失败则备用。

不读故障概率、gamma、Z、Bayes 表或 Oracle；规则不区分 X1/X2，报价门槛在结果前固定，未通过验证集选择。每个被限制的 SDK 请求记录对应检查点；约束工具与实际调用、参数合法性、工具结果可用性和完整后缀结果分别记录。
