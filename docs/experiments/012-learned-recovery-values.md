# 实验 012 · Gate 10 探索性验收

问题是历史动作条件经验是否在新任务上改善恢复选择。对照包括固定仅重试、直接切换、失败后切换、只用公开价格的阈值、聚合首重试率、上下文首重试率、上下文版 One-bit Memory 和按上下文直接估计的动作结局。回合完成率和观察到的切换后完成率用 Beta(1,1) 平滑并保存样本数；在缺乏对应工具／错误键的留出任务上，任务统计对照使用公开价格与 1/2 默认先验。完整 BTM 未运行。

- 开发 018，训练 019/024，测试 020/027/032。020 与 027 共享故障工具及恢复子结构，放入同一留出组。训练与测试间故障工具不同，检验可见上下文的跨工具迁移；不据此推断同键下完整 BTM 的行为。
- A/B/控制格的首重试概率为 3/4、1/4、1/2。两动作分层均衡随机分配，每训练任务每格每动作 16 条，共 192 条；重试失败后固定切换。测试每任务每格 16 个起点，共 144 对照起点，分别回放直接切换、失败后切换和仅重试。历史与测试种子为 101 和 102。控制格检验较弱条件下的行为，允许价格使阈值不同。
- 报价沿用 Gate 3 的单位请求价，每次实际调用计 1，含失败调用。从首错后起计，显式诊断在本批禁用。测试分支只由冻结策略的动作选择关联，不用其他反事实分支作为策略输入。该阶段仅有一次重试，带上下文 One-bit Memory 的失败位只负责切换。
- 预期上下文估计在两个留出组都比聚合或最强固定可完成对照省调用，且完成数不降；逐组复核，保留不支持结果。直接动作价值使用历史原始费用，跨任务报价变化可能使其失准。若两组未达标，或覆盖度不足，当前设计不进入后续正式比较。若简单上下文阈值已覆盖收益，则不进入复杂方法开发。
- 先通过原有隔离测试和扩展专项测试，再运行云端 .venv。每次运行记录提交、配置、输入哈希、轨迹及结局费用。模型、推理、正确停止率不适用，未恢复但可恢复的样本单列为未完成。
