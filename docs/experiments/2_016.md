新协议 23 次决策均自然结束或产生工具调用。第一步均未查询既有发布，C 中两组都真实重复提交。正面回执摘要在首步为空，缺少确认不等于确认未提交。证据组包含摘要及检查提醒，因此不能分离这两者的作用。C/T/P 是一个任务族，确定性单次运行。冻结 2_015 的领域知情规则会先查，三条件通过。部署预算诊断在 4096 截断，8192 实耗 5677 Token，输出自报 unknown 却要再次写入的 JSON。其字段和实参合法，但冻结方法的 unknown 写入约束会拒绝；诊断没有执行该动作。这修正了失败归因，但未显示放宽预算即可恢复。

GOAT 原版拓扑采样器处理六条从公开合同首个 Returns 字段获得的边，产生 18 条序列。各自在三个世界重置执行，全部调用成功的序列 C/T/P 分别 3/3/2 条，满足冻结严格条件 0/2/1 条。静态绑定只读顶层同名字段，不能展开列表内的发布 ID，C 的零通过也有此竞争解释。CPU 给固定非空结束语，不能视作模型回答。摘要和完整原始轨迹哈希见[GOAT 检查](../evidence/2_016/goat-execution.json)。本轮仅运行作者采样器；边提取、绑定和模拟执行是本项目适配。原生 GOAT 在线链依赖 ToolBench 代理，direct 后端未实现，本轮未调用代理或训练。GPU 使用共享原始合同菜单，未把 CPU 验证链提供给模型，不能估计已验证候选的增益。

决策：停止优化正面回执摘要。下一项可证伪改动应聚焦非幂等写入的提交未知：候选写入前核对同一义务是否有未决尝试，若合同提供只读核查则取证；核查为空后必须允许合法写入。需要在未见任务族验证，并设已提交、未提交、状态不可查和明确允许重复四类反例，防止退化成一律阻止写入。
