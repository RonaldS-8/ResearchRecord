# 实验 009 · Benchmark Selection Gate 云端探针

探索性接口验收，种子 42。不使用模型，不修改基准及评分器。比较原生结果与代码审计，探针输出留在云端。只检验能改变选型的条件，单例不外推。

- CostBench：先用原生旅行工具目录和求解器，从同一个类型起点比较原路径和排除首选工具的路径，核对异质成本。单独探测原生禁用能否保持同一受影响工具，以及原生答案评分是否独立于执行记录。有现成查询和执行输入时补一条真实工具调用，未覆盖的完整回合另记。
- ToolMisuseBench：选取按生成器索引排序的首个 v2 检索超时任务。使用相同种子和调用前缀，比较重复回放以及重试、换工具或停止分支。额外用相同超时返回的持续触发配置检验能否构造隐藏状态配对，明确区分生成器默认值与审计夹具。用原生成功判据核对，记录 Agent 观测是否相同。
- 竞争解释是原生恢复能力已经足够，或优势只来自可见故障、答案匹配或任务绑定单一工具。支持迁移至少需要合法完成的多步替代路径、可复现的配对恢复起点和原生评分覆盖，成本改造量另计。
