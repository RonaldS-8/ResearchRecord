# 2_021 已见检查点的跨模型诊断

问题：2_020 中 M3 自主完成、M4 直接停止但给出入口即完成，这一模式能否在本地 Qwen3-8B-AWQ 上重现？竞争解释包括模型版本、思考训练与量化差异，不能单独归因为参数量。固定沿用全部 M3/M4，各用直接、知情首步、知情前两步、知情全链；组内共享历史、工具池、预算和解码设置。顺序与 2_020 一致，种子 201701、温度 0、每次输出上限 8192，无外部 API。仅换模型，沿用原工具调用及评分实现。每格一次，最多 44 次模型请求，服务及运行合计最多 100 分钟；异常或截断保留。实际启动前记录模型校验清单、vLLM 版本、代码 SHA。原始数据 results/2_021-gpu-01。

比较直接组与各提示的实际工具序列、实参、首次偏离、严格完成、费用、Token 和延迟。直接完成说明该检查点可自主恢复；只有给入口后完成则说明入口信息有价值；只有更长提示后完成才支持进一步调查后续决策。复用既有 4B 结果。M4 两步及全链提示分别与 2_019 GOAT 采样适配和规则的冻结输出逐字对应；共享相同首步，不能检验自动入口排名优劣。此对照不构成 GOAT 全流程复现。M3/M4 的机制、长度及预算共同改变，不能识别纯链长或共享节点效应。两例均为已见开发材料。今晚不因结果换样或调提示。
