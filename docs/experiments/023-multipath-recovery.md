# 实验 023 · 多路径恢复的机制预注册

状态为已批准的探索性预登记。配置、代码及判据在小规模试验前冻结。本轮使用确定性执行与 CPU 回放。Qwen3-4B Agent 组尚未放行。执行与计价见 [ADR-0021](../adr/0021-multipath-recovery.md)。

## 假设与最小矩阵

假设是首动作可能同时改变后续合法工具、条件成功率与剩余费用，任务级历史后验可能掩盖这些差异。竞争解释是报价阈值、最近反馈或固定顺序已能捕捉全部收益，或差异主要来自历史估计误差与有限抽样。所有方法在同一合法首错、任务、工具接口和随机事件下比较。

获取期间网关状态好／坏各半。A 在两态的成功率为 0.60／0.05，B 为 0.90／0.10，C 恒为 0.70。共享格中 A、B 使用同一状态，给定状态的尝试抽样独立。去关联格中两者状态独立且边际不变，探针仍观察 A 的网关。B 成功后是否签发短作用域凭据另用独立事件抽样。下表中的生成参数只供模拟、精确校验与评估，诊断准确率作为公开合同。

| 格 | A/B 故障 | B 成功后需验证概率 | 诊断准确率 |
|---|---|---:|---:|
| 完整机制 | 共享 | 0.50 | 0.80 |
| 去依赖 | 共享 | 0 | 0.80 |
| 去关联 | 独立 | 0.50 | 0.80 |
| 无信息诊断 | 共享 | 0.50 | 0.50 |
| 同质续程对照 | 独立 | 0 | 0.50 |

各格的工具报价、诊断费和执行额度相同。C 的外部登记与原生登记等价计费。使用语义事件键配对各格和策略，分别标识 A／B／C 抽样、网关、凭据与诊断噪声。跨格复用随机数，调用顺序不消耗其他事件键。共同阻断与紧预算见证只作验收，保留随机留出中的自然失败与负结果。

## 预登记反例与消融

反例用完整分布精确枚举，固定同一公开检查点的可行菜单和后续合同。以下数值为推导值，不计入留出结果。

1. **下游依赖改变顺序。** 从 A 已失败、B/C 均可选且剩四次执行的检查点出发。B、C 独立，成功率为 0.50、0.70，无信息探针。都可尝试到首个成功，严格完成率同为 0.85。相同登记费用相消。无短凭据时，B 优先的预期工具费 2.20，C 优先 2.36。恢复 B 的短凭据分支后，B 优先多付期望验证费 0.50，C 优先多付 0.15，排序变为 C 优先（2.51 对 2.70）。无论先试哪条路径，额度都足以履行全部揭示义务。
2. **相关故障改变同一失败后的选择。** 在同一检查点关闭验证差异与诊断信息，只切换是否共享故障。独立时 B 成功率仍为 0.50，选 B。共享时 A 的失败将好态后验降为 $8/27$，B 成功率降至约 0.337，低于 B 优先的成本阈值 $1.20\times0.70/2.00=0.42$，选 C。同一共享条件下，若 A 失败前收到正／负诊断，失败后的 B 成功率分别约为 0.602、0.176。最近错误一致，早期证据可令动作反转。该反例同时给出一个强阈值对照。
3. **诊断的价值可消融。** 在共同首错后只剩两次执行，且无额外验证义务。登记占一次额度，失败后无法靠另一条获取路径完成。无探针选 C，严格完成概率 0.70，期望工具费 2.280。共享故障下，准确率 0.80 的探针使正信号后的 B 成功率为 0.74，负信号后仍选 C，平均完成概率为 0.72，期望工具费 1.888、诊断费 0.05。把探针改为同价无信息或让 B 与 A 网关独立，诊断均无法提高完成。宽预算随机格另报告诊断是否改变决策，以及同完成率下扣除诊断费后的节省。

## 历史、划分与误差

- **冻结划分。** 训练用包裹、发票，种子 2101–2103，每家族每种子每格 12 例。每组 6 条固定 A→B→C 自然选路，另 6 条在结果出现前分配给六种获取顺序，每种首动作各有一条起始诊断与一条无诊断记录。成功后只执行合法后续步骤。验证用制品发布，种子 2111–2112，每种子每格 8 例，用于选基线及验收拟合。留出用预约、凭证归档，种子 2121–2124，每家族每种子每格 8 例，合计 320 个主起点。沿用家族合同，事件与轨迹是新抽样。保留全部预分配实例。
- **同源估计。** BTM 与动作价值用同一训练池，分开标记自然和分配轨迹。保留按错误键、切换、合法检查点、首动作和回执类型的支持数。对共享程度 $\rho\in\{0,1/2,1\}$ 做小网格似然拟合，$\rho$ 表示 B 使用 A 网关状态而非独立状态的概率。A/B 两态发射率从 $\{.05,.10,.25,.40,.60,.75,.90,.95\}$ 取值，约束好态成功率不低于坏态。似然只含合法返回的尝试和探针，起始好态先验为 1/2。并列优先低相关、再优先低态差和固定网格顺序，报告并列模型的价值范围。C 的可用率及短凭据概率用相应合法回执的 Beta(1,1) 后验均值。按原报价累加完整续程费用，零直接支持明确标记为外推。
- **匹配、偏移、缺样本。** 主格用各自匹配历史。完整机制格另用去关联格历史检查相关性偏移。分别使用等量的 36 条分配轨迹或 36 条固定顺序轨迹，检验首动作缺少直接样本时的排序。固定顺序中 B/C 从未在交接点首试，后续观察按实际节点另计。用仅评估侧的已知生成参数计算同一拟合续程的条件期望，把预测减实得拆成拟合偏差与留出抽样残差。分层报告排序翻转、完成 Brier 分数、工具费与诊断费的绝对误差及有符号偏差。按起点和种子报告分母。

## 强基线与放行

固定重试用 A→B→C，固定切换用 B→C→A，最佳固定顺序从六种顺序中按验证集严格完成、正确停止、平均总费用择优，并列按 A、B、C 字典顺序。局部阈值按当前成功率与报价选择，另保留将凭据的期望后续费用计入阈值的强规则。用同一拟合分别运行固定信念、最近反馈和完整历史，再对比最佳固定续程、可买一次诊断的局部规则和有限步前瞻。固定续程枚举剩余获取顺序，按当前信息核算实际失败分支和登记义务。无诊断时，一次成功即固定后续合同，若精确顺序枚举与完整前瞻不同，先核对实现。

CPU 上的 BTM 代理以当前失败键对应的回合恢复或切换后验排序，缺键用同一 Beta 先验，并列用验证集冻结的顺序。动作价值代理使用同一强制首动作和冻结续程给出的三分量。两组共用合法菜单、验证、停止规则与绑定。另提供同样允许诊断的参考策略。CPU 代理结果单列。若批准 Agent 配对，则在同一 Qwen3-4B、同一静态知识与恢复规则下比较 BTM 与 Action-Conditioned Memory，并保留无历史和先重试消融。Oracle 和已知生成参数但状态隐藏的参照分列。

- **工程 Go。** 防泄漏与专项测试通过。逐例核对未来事件置换前的公共视图相同、错误凭据与跳过验证被拒、终态与双账本一致、阻断正确停止和预算耗尽分离。三项反例及各自消融重现预登记结果。
- **机制证据。** 先报告三项反例及随机矩阵各机制的配对差。严格完成、正确停止、工具费、诊断费和冗余分列，Token 在 CPU 阶段记不适用。样本内分差若与同续程期望方向不一致，注明抽样不确定性。
- **进入 Agent 的建议门槛。** 完整机制留出中，候选相对验证集冻结的最强简单规则，在两个家族均无完成或正确停止退步。精确期望严格完成率至少提高 2 个百分点，或同完成率下平均工具与诊断总费至少低 5%。至少三组测试种子的实得配对方向一致，且有一条能复核的合法动作分歧。任一强简单规则仍在完成、正确停止和费用上持平或占优，保留机制证据并判方法 No-Go。达到门槛只提交 Agent 审核。本轮沿用冻结条件，不用留出结果重新挑参数、实例或种子。

## 云端结果（2026-11-10）

预登记提交 `abe49a2`。首次验收的较早证据反例回放遗漏了首选失败后的合法备用，精确求值已包含该续程。提交 `42b390b` 修复回放后，25 项云端测试通过，含防泄漏和新合同专项测试。配置、划分与判据沿用预登记。运行 `results/023-gate21-multipath-01/` 于新加坡时间 00:08 完成，包含 360 条训练轨迹、80 个验证起点、320 个留出起点及 4,992 条留出策略轨迹。留出严格审计均通过，无过早停止或预算耗尽。无模型请求，Token 不适用。

**机制反例均重现。** 受控回放与精确期望逐项一致。A 已失败的检查点，加入 B 短凭据义务使 B/C 顺序的工具费从 2.54／2.70 变为 3.04／2.85，完成概率均为 0.85。关闭该义务、仅恢复故障关联也使 C 优先。诊断与最近 A 错误一起使用时，正／负早期证据分别选择 B／C。在紧预算见证，购买诊断使完成概率从 0.70 到 0.72，工具费从 2.280 到 1.888，另付 0.05，合计期望节省 0.342。无信息或故障独立时，诊断没有完成收益。见云端 `witnesses.json`。

### 完整机制格

最佳固定顺序由独立验证集选为 A→C→B，与固定信念、最近反馈、完整历史阈值、最佳固定续程和单次诊断规则并列最强。它们与完整规划在 64 个留出起点的动作、完成、停止和费用一致。即使使用已知参数且状态隐藏，仍走同一序列。

| 策略 | 严格完成 | 正确停止 | 平均工具费 | 平均诊断费 | 期望总费用 |
|---|---:|---:|---:|---:|---:|
| 固定重试 A→B→C | 58/64 | 6/6 | 2.756 | 0 | 2.679 |
| 固定切换 B→C→A | 58/64 | 6/6 | 3.244 | 0 | 3.106 |
| 最佳固定顺序、完整规划（各组） | 58/64 | 6/6 | 2.269 | 0 | 2.408 |
| BTM 任务级代理 | 58/64 | 6/6 | 2.756 | 0 | 2.679 |
| Action-Conditioned Memory 代理 | 58/64 | 6/6 | 2.269 | 0 | 2.408 |
| Oracle（真值上界） | 58/64 | 6/6 | 1.944 | 0 | 1.991 |

预约完成 30/32，归档 28/32，固定顺序与完整规划在四个种子上均持平。Memory 代理相对 BTM 代理的平均工具费下降 17.7%，完成率相同。43 例的首次分歧发生在 A 失败后，BTM 代理选 B，Memory 选 C。全训练池的 A→B、A→C 回合后验分别为 23/25、33/37，在该检查点的后续工具费估值却是 3.045、2.874，同续程精确值是 3.183、2.782。固定 A→C→B 覆盖同一收益。两代理的成功轨迹平均工具冗余分别为 1.05、0.66。这里比较的是确定性统计代理。

### 消融与历史误差

| 格 | 完整规划完成 | 正确停止 | 平均工具费／诊断费 | 完整规划期望总费 |
|---|---:|---:|---:|---:|
| 完整机制 | 58/64 | 6/6 | 2.269／0 | 2.408 |
| 去依赖 | 58/64 | 6/6 | 2.131／0.034 | 2.280 |
| 去关联 | 59/64 | 5/5 | 2.306／0 | 2.454 |
| 无信息诊断 | 58/64 | 6/6 | 2.269／0 | 2.408 |
| 同质续程 | 59/64 | 5/5 | 2.294／0 | 2.245 |

- 完整机制格和无信息格均未买诊断。去依赖格中，完整规划在 43 次 A 失败后才购买诊断，单次诊断规则每例先买。两者工具费与完成相同，延后购买仅节省平均诊断费约 0.016，期望总费用下降 0.7%。同质续程格中，完整规划的期望费用低于验证集选出的固定顺序（2.245 对 2.353），留出实得方向相反（2.294 对 2.244）。这两项分别保留，格间共享事件键，不把各格当作独立重复。
- 在完整机制格的 120 个归档获取检查点，匹配、偏移和固定顺序稀疏历史的首选与各自同续程精确估值一致。固定顺序历史在交接点 B/C 都是零首试，仍可由后续尝试外推。等量的分配历史覆盖各个首动作，却在 A 刚失败、无诊断的具体检查点没有 B 的直接样本。该历史在该检查点把 B/C 预期工具费估为 2.692／3.072，生成律下是 3.183／2.782，造成 43 处排序翻转。这 43 行重复的是同一公开证据形状，属于同一外推偏差。平衡分配和固定顺序历史同为 36 条，首动作覆盖与局部覆盖分别解释。
- 以完整机制匹配历史的 64 条首节点 A 预测为例，工具费偏差 +0.201 由拟合偏差 +0.062 与抽样残差 +0.139 构成，完成 Brier 为 0.085。分配历史的对应费用偏差 −0.581 则主要来自拟合偏差 −0.504，抽样残差为 −0.078。诊断及逐动作、支持度、家族和种子分项见 `evaluation.json`。同续程精确期望见 `expected.json`。

**工程与机制 Go，方法 No-Go。** 新合同确实产生可复核的选路反转。完整机制留出与强简单规则逐步持平，去依赖格的诊断时机收益也低于预登记的节费门槛。Gate 21 的证据支持描述合成环境中历史估值如何影响恢复选择。Agent 比较尚未运行，未进入 Qwen3-4B 配对。
