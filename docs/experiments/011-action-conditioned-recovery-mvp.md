# 实验 011 · Gate 9 最小验收

依据 [ADR-0009](../adr/0009-action-conditioned-recovery-benchmark.md) 和[设计](../action-conditioned-recovery-benchmark.md)。检查任务恢复汇总能否识别具体首动作，以及上下文经验和诊断反馈的费用价值。竞争解释为固定重试、失败后切换、直接切换、上下文阈值、One-bit Memory 和完整 BTM。完整 BTM 仅保留为后续对照，本验收不运行模型。

固定 Gate 7 的 C2-018 起点。恢复报价为动作包价：重试调用计 1，其成功后的路径续程包含在报价内；切换包计 2，含替代路径所有调用。工具调用数另计。上下文 A/B 的健康概率为 3/4、1/4。每个上下文穷举两种状态和四种固定策略。诊断校验格先验 1/2、准确率 4/5 或 1/2、单次费 1/10，穷举两种状态与两种信号。诊断仅可在首次恢复动作前调用一次。失败重试不可重复。无随机采样，种子不适用。

验收要求配对首视图相同、故障调用前缀一致、各分支完成及费用与精确值一致、负例拒绝、现有及新增隔离测试通过。A/B 最优分别为重试后切换和直接切换，费用 3/2 与 2；等权上下文策略费用 7/4。诊断校验的最优费用分别为 9/5 与 2（无信息时跳过诊断）。只在 LabServer 执行，保存配置、版本、提交、轨迹和结果，模型字段不适用。任一验收失败保留产物。通过仅代表 MVP 可用，强简单规则覆盖收益时不启动方法开发。
