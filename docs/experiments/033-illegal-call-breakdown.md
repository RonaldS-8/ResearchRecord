# 实验 033 · Gate 31 历史非法调用的规则分类与分项统计

2026-11-11。只读审计，探索性，承接 [实验 032](032-public-contract-audit.md) 与 [ADR-0030](../adr/0030-public-contract-revision.md)。Q2、诊断与 $Q^\pi(h,a)$ 沿用 AGENTS.md。本轮没有模型请求，不修改任何已归档轨迹、评分或评分规则。

## 预登记

**问题。** 现行严格完成对非法调用一律否决。已归档的 ToolMaze-Recovery 模型回合里，被拒绝的调用分别是哪条规则拒的、收了多少费、有没有留下实际效果、有多少回合仅因非法调用而未获严格完成。这些分项是之后讨论评分口径的事实依据。

**分类规则，先于查看轨迹固定。** 只读每次调用已保存的公开返回，按“哪一层规则拒绝了它”归类，不推断调用者意图。一次调用可同时触发多条规则，各计一次。

| 类别 | 判定依据 | 是否计费 |
| --- | --- | --- |
| `unadvertised_tool` | 调用了本任务未公布的工具或调用格式无效 | 否 |
| `argument_schema` | 缺必填参数、类型不符、多余参数、数量非整数、期限格式不符 | 是 |
| `task_scope` | 参数与本任务授权的值不一致：资源标识、请求号、项目、区域、版本 | 是 |
| `business_precondition` | 参数合规但业务插件拒绝：引用不存在或非本会话签发、证据与写入不匹配、前置状态不满足 | 是 |
| `unclassified` | 标为非法但不匹配以上任何依据 | 视原记录 |

`task_scope` 同时覆盖“标识写法不同”和“访问了别的资源”。模拟环境每个任务只有一个授权资源，两者无法区分，因此不称为越权。分类同时识别 Gate 30 修订前后的两套报错文本。

**分项。** 每回合报告：原 `strict_success` 与 `issues`（照抄）、非法调用数及按类别计数、非法调用的已收费用、其中留下实际效果的次数、是否“终态谓词通过、已作答且未报告阻断，仅因非法调用未获严格完成”。汇总给出各项合计。归档中保存的 `illegal_calls` 与重新计数不一致时标记，不修正。

**假设与竞争解释。** 依据实验 029–031 的记录，预期 12 个模型回合中只有 Gate 29 设施正常回合有 1 次非法调用，类别为 `task_scope`，收费 1，无实际效果，且该回合属于“仅因非法调用未获严格完成”；其余 11 回合为 0。竞争解释是记录漏报了其他非法调用、分类规则漏掉某种报错文本而落入 `unclassified`、或非法调用留下了效果。任何一项出现都如实报告。

**范围。** `results/029-gate27-smoke-01/`、`results/030-gate28-agent-01/`、`results/031-gate29-agent-01/` 下的 `episode.json`。CPU 脚本见证和 Gate 18–23 的旧环境归档格式不同，不在本轮范围。

**不变性。** 工具只读源文件，逐个记录其 SHA-256，报告写到另行指定的新文件，目标已存在则拒绝写入。
