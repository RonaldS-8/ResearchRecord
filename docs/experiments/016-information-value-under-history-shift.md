# 实验 016 · 历史适用性、诊断与执行反馈

状态为已批准的探索性机制验收。参数、条件和判据随本文件冻结。仅在 LabServer 运行，保存版本、配置、历史来源、配对轨迹和账单。本轮为机制与回放验收。

## 最小模型

固定一次合法首错后的检查点。隐藏变量 A 表示旧经验是否适用。历史只覆盖 A=适用，首重试成功率 p=3/4；偏移态的首重试成功率为 1/4。留出等权两态，历史策略的首重试在两态费用分别为 1.5、2.5（无额外证据），总体均值 2 会掩盖偏移态的损失。历史适用性不是执行状态。策略可在有线索格读到故障前合法返回的兼容性线索，其对 A 的准确率为 4/5。它把首重试概率更新到 13/20 或 7/20，原始工具错误保持一致。

- 每次重试费 1。切换由两次工具调用完成，费 2，始终存在合法完成路径。最多两次重试，失败后可切换。停止合法且零增量费，在这些可恢复格记为未完成。正确停止率不适用。
- 显式诊断限首次恢复前一次，费用 1/10 或 2/5。诊断返回关于首重试能否成功的有噪信号，准确率由对应校准格提供给所有策略。探针不推进任务，也不直接返回真值。
- 首重试失败后，第二次重试的边际成功率为 1/2。执行反馈格中，真实失败调用的两种错误细节把该概率更新为 4/5 或 1/5；其他格为无信息反馈。探针信号与第二次重试及其细节在给定首重试结局后独立。执行反馈随失败调用进入公开历史，仅收一次工具费。

无后续信息时，直接切换费 2，先重试失败再切换的期望费为 1+2(1−p)。在等完成率下，p>1/2 时首选重试。执行反馈格的失败检查点，先重试的费用随两种错误分别为 1.4 和 2.6，切换均为 2。期望成本的手算基于上述条件概率与同一失败后续策略，待云端枚举和逐分支账单核验。

## 最小矩阵与基线

各行都含旧经验适用和偏移两态。精确展开执行、已有线索与探针的联合支持并保留各分支的概率权重。每种故障实现复制给不同首动作和策略，同一行同一可见历史的分支共享前缀、预算、工具、价格和预先分配的随机结果。跨行变动只来自指定观测通道或探针报价。

| 格 | 既有线索 | 诊断准确率／费 | 执行细节 | 预期最优总费用 |
|---|---|---|---|---:|
| 中性对照 | 无 | 1/2／0.1 | 无信息 | 2.00 |
| 仅既有线索 | 有 | 1/2／0.1 | 无信息 | 1.85 |
| 有信息诊断 | 无 | 4/5／0.1 | 无信息 | 1.80 |
| 诊断过贵 | 无 | 4/5／0.4 | 无信息 | 2.00 |
| 仅执行细节 | 无 | 1/2／0.1 | 有信息 | 1.85 |
| 两种新增信息 | 无 | 4/5／0.1 | 有信息 | 1.77 |
| 更新概率但不换动作 | 有 | 3/5／0.1 | 无信息 | 1.85 |

最后一格的探针可改变后验，但两种诊断结果都不跨过各自既有线索后的动作阈值，净价值为负。中性格的无信息探针保持正费用。总费用仅相加同一模拟货币单位的工具费与诊断费，结果仍分列。

同权对照含固定重试／切换、忽略经验的公开成本规则、冻结旧经验的上下文阈值及动作条件估值、One-bit Memory、读取合法当前反馈的简单语义规则，以及按成本门槛选择探针的简单规则。需要校准时，只用与留出分离的训练摘要或同一公开校准表；任何组都不能以任务 ID 或反馈变体读取适用性真值。额外报告已知生成参数但只读公开观测的最优值，以及单独标记的知情 Oracle 上界。完整 BTM 待验证，LLM 判断及 LLM 加决策器为后续可选对照。[Bench2Robust 附录 B.1](https://arxiv.org/html/2608.11977v2#A2.SS1)

## 验收与 Go / No-Go

- **工程 Go。** 既有及专项防泄漏测试通过。相同起点的公开前缀、合法动作和预算一致，枚举与逐分支严格完成、终态及账单一致。诊断只经付费返回，失败重试只记工具费。报告可恢复场景的过早停止、配对动作分歧、按适用态分列的完成率及实际费用。
- **机制 Go。** 有效信息至少在一个同起点反事实中改变后续最优动作，并在完成数不降时节省净费用，或提高严格完成率。无信息、过贵和后验变化但动作不变的格须如实复现。观察到差异但未通过执行验收时记为证据不足。
- **方法 Go。** 冻结的强简单规则使用相同公开信息、历史和报价后仍有可复核的差距，才考虑增加状态估计或有限步规划；如果差距来自公开语义识别，再考虑小批 Qwen。若简单规则达到理论最优、提升仅表现为不确定性降低，或付费后没有净收益，则相应方向 No-Go，保留负结果。Token 和推理延迟在本轮 CPU 枚举中不适用。

执行用 Gate 12 发票家族。既有线索随准备步骤的合法返回，首错、任务路径和恢复动作保持不变。所有格开放一次首步探针及至多两次重试，最后仍可切换或停止。平局优先直接切换、其次重试、再诊断。旧经验使用冻结的 3/4 摘要，校准格提供等权先验及探针准确率。无训练拟合或随机采样。公开信息最优由独立树枚举计算，再逐条执行并与闭式简单规则核对。

## 结果

运行提交 `0f15158`，云端 `results/016-gate14-minimal-01/`。21 项测试通过。七格展开 288 个带概率权重的故障实现，执行 2,880 条策略轨迹。同一公开线索下的初始视图一致，全部调用依赖、终态及双账本通过核验。所有恢复规则严格完成率为 100%，固定停止为 0%。正确停止率、Token 和推理延迟不适用。

| 格 | 工具费 | 诊断费 | 总费用 | 公开最优首动作 |
|---|---:|---:|---:|---|
| 中性 | 2.00 | 0 | 2.00 | 切换 |
| 仅既有线索 | 1.85 | 0 | 1.85 | 按线索重试或切换 |
| 有信息诊断 | 1.70 | 0.10 | 1.80 | 诊断后重试或切换 |
| 诊断过贵 | 2.00 | 0 | 2.00 | 切换 |
| 仅执行细节 | 1.85 | 0 | 1.85 | 重试，失败后按细节再试或切换 |
| 两种新增信息 | 1.67 | 0.10 | 1.77 | 诊断，必要时用失败细节 |
| 后验变化但动作不变 | 1.85 | 0 | 1.85 | 只用既有线索 |

冻结历史阈值在中性格总均值为 2，按适用／偏移分层为 1.5／2.5。仅已有线索规则的分层成本为 1.6／2.1，体现适用态费用增加和偏移态损失下降。只用失败位的 One-bit Memory 在执行反馈格费用为 2；读取失败细节后可降为 1.85。低价探针与执行反馈结合时，较只用执行反馈再省 0.08。无信息、过贵及后验变化但排序不变的探针都未被最优策略购买。

**机制 Go，方法 No-Go。** 简单探针门槛规则与独立树枚举逐条同选，账单一致。分态差异和信息价值成立于冻结的合成机制与公开校准条件，尚未验证真实跨任务历史校准。完整 BTM 和 LLM 均未运行。
