# 实验 018 · 动态执行路径下的序贯恢复

状态为已批准的探索验收。版本、权重、预算、种子、基线和判据随本次提交冻结。仅在 LabServer 运行。以下数值为手算预期，实际回放尚未验证。

## 最小机制

在发票准备、取得凭据、按需追加核验三个槽位中，选择同一个槽二原始故障为起点。槽二成功后，执行返回以公开概率 q 请求槽三，具体要求此前不可见。槽三消费槽二凭据。A 的每次有效调用费 9/8，B 费 2；失败收费且不给凭据。每槽每条路线至多尝试一次。B 在主格总能完成当前槽。先验中每槽 A 的边际可用率均为 1/2。

- **故障模型。** 令槽二、三各有一个好／坏服务状态 Z。给定其 Z，A 的可用率分别为 9/10、1/10，各次调用条件独立。关联模式共用 Z，独立模式各抽 Z。关联模式中两槽 A 成败相同的概率为 41/50，属于部分关联。允许用未知混合权重 w 生成两种模式。模式、Z 和未执行结果不进入公开视图。
- **三类观测。** 槽一的正常准备回执可附带关于槽二服务状态的有噪质量标记，准确率 3/4，无新增动作。付费诊断报告该状态的带噪信号，准确率 4/5 或 1/2，费用为 1 或 1/20，只在起点可用一次。A 的成败和槽二回执是执行性信息，均按原动作收费。各信号在给定服务状态后独立生成；槽三是否出现独立于服务状态和选路。
- **未知关联估计。** 独立历史集拟用 64 个训练发票实例，每个合法暴露两槽 A 成败，A 失败后用可靠 B 完成并保证进入槽三。估计器只使用配对的公开执行结果。若同向频率为 m，则 w 的频数估计为裁剪到 [0,1] 的 (m−1/2)/(8/25)。报告支持度，估计冻结后进入留出。已知机制对照只获得分布参数，Oracle 另见当前状态和故障实现，均不读取尚未发生的槽三请求。训练与测试实例、随机流及实际轨迹分开。

信念是给定训练摘要和当前全部合法历史后，对模式与服务状态的条件分布。有限树在每个合法动作后按观测概率加权续程，分别输出严格完成概率、实际工具费和诊断费。主比较先最大化严格完成概率，再在同完成率下比较同币种费用。额外报告成功率与费用的分项取舍。

## 两个预登记反例

1. **相同当前任务状态，不同合法历史。** 在关联格取 q=1/4。配对首槽正常回执的两个质量标记。其余当前字段一致，包括槽位、凭据、首错、可选动作、预算、报价及调用次数；标记保留在合法历史中。两种标记把槽二 A 可用率分别更新到 7/10 和 3/10。预期高标记先试 A，低标记直接 B。验证时检查两组最优首动作集合是否不相交。
2. **相同故障信念，不同未来路径分布。** 在关联、无已有标记的两格固定当前 A 可用率 1/2 与相同联合故障信念。只把已知槽三请求率从 1/4 改到 3/4，两个格的实际请求均在槽二成功后揭示。忽略诊断时，先 A 的当前额外费为 1/8，若出现槽三，其执行反馈可节省 103/400。于是 A 相对 B 的全程费用差从 +97/1600 变为 −109/1600，预期首动作从 B 反转到 A。槽二执行结果对槽三 A 的预测价值应在独立格消失。

## 最小矩阵

| 格 | 变量 | 核验重点 |
|---|---|---|
| 1–2 | 关联，q=1/4 或 3/4 | 同故障信念下的首动作反转 |
| 3 | 独立，q=3/4 | 同拓扑和边际故障率下的负对照 |
| 4 | 复制格 2，在合流处增加两项确定性必做检查 | 增加调用数，路径包报价与有效决策预算保持一致 |
| 5 | 复制格 1，公开已有质量标记 | 同当前任务状态下的历史反转 |
| 6 | q=3/4，真实 w=3/4 | 同一实现上比较已知 w、历史估计及错误的独立假设 |
| 7–8 | 复制格 2，低价诊断准确率为 4/5 或 1/2 | 净信息价值与无效诊断 |
| 9–10 | 复制格 2，B 每槽独立以 3/4 可用；执行预算 4 或 3 | 备用失败与预算的独立比较 |

格 1–6、9–10 使用高价诊断。扩展的确定性检查逐调用记录，已含在包价内。可靠 B 的主格留足两槽各尝试 A、B 的共同预算；格 4 额外保留两次专用检查额度。压力格的诊断单列，工具预算约束实际执行。两路线均失败且无法再取得必需凭据，或预算不足以完成剩余依赖时，允许显式停止。验收分别记录路线阻断后正确停止、预算耗尽终止和过早停止。判定以当前合法动作、公开失败证据及剩余资源为准，并由评估器独立核对该实现的可达性。预算耗尽不算正确显式停止。

## 基线、指标与判据

- **状态估计对照。** 同一选择器分别用边际固定值、上一条反馈、全合法历史的频数模型。已知机制和历史估计在同一留出实现上分别报告，不混作同权限基线。
- **规划对照。** 固定重试／切换、简单语义规则、局部概率与成本阈值、Gate 15 规则及带 q 的闭式扩展、上下文动作条件价值、全历史有限枚举。对固定后续策略的动作价值与逐步重选分开。以相同信念估计比较不同前瞻，以相同前瞻比较不同估计。可用与屏蔽同一合法信号的对照作为信息贡献分析。
- **工程 Go。** 概率质量守恒，逐轨迹校验合法参数、唯一终态、动态任务要求、停止分类、前缀与两套账本。既有及新增防泄漏测试通过。按格分别报告严格完成、正确停止、预算耗尽、工具调用、工具与诊断费用及恢复冗余。冗余以同一实现的最短合法完成为参照，未完成分支另列。无模型推理时 Token 和推理延迟不适用。
- **机制 Go。** 两个反例须在合法回放中出现互斥的最优首动作集合，且相对相应局部规则减少费用或提高严格完成率。仅增节点的控制应保持动作价值排序。诊断收益按实际后续动作和净费用核对。未知关联如因样本误差未恢复反转，保留结果。
- **方法 Go / No-Go。** 只有使用相同公开信息与训练摘要的强简单扩展在留出上仍有可复核差距，才考虑后续方法。若闭式规则持平、额外反馈只改变后验，或任何费用优势以完成率下降换得，按对应假设报告 No-Go。完整 BTM 暂未运行，任务级历史统计另列。

历史采样种子为 1601，留出使用完整概率支持，无抽样种子。固定重试和切换在失败后尝试另一条合法路径。费用和完成率并列时优先 B、A、诊断、停止。Gate 15 规则把下一槽视为必需，带 q 规则按其出现概率计价。可靠且预算充足时使用闭式续程；压力格提供固定局部续程的动作价值对照。Oracle 在每个决策点可见 A/B 的可用性，实现中的路由回执仍须经执行取得。
