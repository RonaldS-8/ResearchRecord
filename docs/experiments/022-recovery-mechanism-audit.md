## 合法分歧与冗余调用

主分析使用 20 个自然起点。对每个候选，在 BTM 轨迹上重建首次分歧前的前缀，逐步核对公开视图，确认两动作都合法。由同一状态分别强制两个动作，之后用同一个冻结局部规则 `local_full` 继续，复用原事件表和严格双账本。回放费用从分歧点算起，Agent 实得结局另列。重复格复用了家族与种子的随机键，20 个起点只有四组家族 × 种子基础键，以下计数是描述性结果。

| 候选相对共同规则 BTM | 首步／后续首次分歧 | 回放总费用更低／更高 | 回放严格完成净增 | Agent 实得严格完成净增 |
|---|---:|---:|---:|---:|
| Memory | 1／17 | 16／2 | 1 | 1 |
| 混合决策器 | 12／8 | 13／7 | 0 | 1 |

Memory 另有两例全程同选。与 BTM 共同完成的 18 例上，BTM、Memory、混合组分别平均多调用 1.39、0.11、0.44 次执行工具。这里以每个必需节点一次成功工具调用为冗余基准，诊断另计。

- **估值切掉一次合法但无收益的回切。** 动态预约 1821 中，三组先用 B 取得凭据。在相同登记节点，BTM 选 A，Memory 和混合组继续用 B。训练在该节点实际试过 A 六次、B 八次。BTM 提供的 A 登记失败后回合恢复与 A→B 切换均为 2/2，平滑后 0.75，统计键没有回答凭据已由 B 获得时应如何登记。估值给 A、B 的严格完成概率均为 1，预计后续工具费为 3.17、3.00，固定先验与反馈更新同序。受控回放中 A 失败后需再调用 B，A、B 起步的后续工具费分别为 3.20、2.00，均严格完成。固定切换走同一条低费路径。动态归档 1822 的 A 成功，后续回放仍需额外验证，费用差缩小为 4.40 对 4.00。
- **停止与续程可解释新增完成。** 备用压力归档 1821 中，BTM 和 Memory 先尝试 B，收到同一失败后只剩 A 和停止。B→A 的观察历史为 1/5，平滑后 2/7，A 的同节点历史尝试数为 5。Memory 看到尝试 A 的估计严格完成概率为 0.374、停止为 0，尝试后以 7.60 的后续工具费严格完成。BTM 停止，后续费用为 0，严格评分为过早停止。混合组从首步选 A，实得全程工具费为 7.60。强制其首动作 A 与 BTM 首动作 B、统一后续时，两边都能完成，费用分别为 7.60、9.60。固定切换从 B 开始也完成，全程 7.20。此例的混合组完成收益随停止规则而变。只加入先重试条款的 BTM 也完成此例，主格首步重试从 0/20 到 6/20，平均工具费由 6.60 升至 6.68。
- **诊断能改选路，也能增加费用。** 混合组在低价有信息格购买四次诊断，两次正信号把下一动作估值首选从 B 改成 A。按相同事件表，与固定切换相比两次正信号分别多花、少花 0.40 工具费，另外各付 0.05 诊断费。四例完成数和平均工具费相同。无信息格没有购买。Memory 在备用压力预约 1821 诊断后沿用 BTM 的执行序列，多付 1.00。无历史组 16/20，共同规则 BTM 18/20，差距来自后续继续执行。混合组与确定性解析、三节点规则在全部 28 组动作一致。给定一次模型采样和这些共享事件键，能定位真实动作与费用差，无法分离 LLM 采样波动或估计总体效应。

**值得研究的是支持不足导致的动作排序偏差。** 独立格生成律的状态保持率为 1/2，同源观察历史却拟合到 9/10，且首节点 A 零直接尝试。拟合值把首动作 A 排在 B 前，预计工具费 4.967 对 5.000。在生成律下固定同一个拟合续程，期望费为 5.325 对 5.000，排序反转，两个动作完成概率仍为 1。压力格 B 拟合可用率为 13/22，冻结生成值为 3/4，独立验证中 B 成功 36/48。压力格分支的平均严格完成概率相对同续程生成律，A 和 B 分别低估 0.117、0.129。这些分层误差支持下一轮核验历史覆盖与排序稳定性。全体 A 回放的负费用偏差不足以支持给 A 统一加价。

## 固定切换的边界与论文证据

四个可靠备用格共 16 个起点。B 在每个节点都成功，A/B 提供同等节点凭据，登记后的验证抽样与选择的供应商无关，预算足以跑完三个必需节点。固定切换和 Memory 在这 16 个起点都只走 B，费用与路径一致。单节点若 B 必成、A 失败后还能试 B，且后续费用相同，A 优先的期望成本是 $c_A+(1-p_A)c_B$。同完成率下须 $p_A>c_A/c_B=0.60$ 才省费。B 的成败不提供主工具健康证据，成功推进后仍按状态转移更新信念。即使在四个备用压力起点，宽预算下 B 失败仍可试 A。固定切换拿到全部三个可恢复任务，并在另一例正确停止。全批与两候选共同完成的 19 例上，固定切换平均总费用为 5.54，低于 Memory 的 5.80、混合组的 5.65。

Gate 17 的精确见证已表明，若一次执行反馈能指导后续两个选路节点，追加节点可改变首动作排序。该批强三节点规则与完整规划仍在 2,560 个起点逐步一致。Gate 19 再次表明，需要检验的是**反馈和下游依赖会不会让可选路线的排序反转**。增加同质节点或可互换备用，可能只增加调用。多个不可靠备用若共享故障域，或者返回的凭据改变后续验证与预算，切换本身才可能同时改变成功机会、信息和续程成本。相关机制见[实验 019](019-stochastic-dynamic-recovery.md)及[下一轮设计](../adr/0020-recovery-mechanism-audit.md)。

**可写入论文的结论。** 同一合法起点和续程下，任务级恢复后验无法直接给出两种动作的剩余费用。Gate 19 提供了同检查点、同外生事件、严格完成相同而费用不同的可追溯反例，也提供了固定切换覆盖收益、历史拟合反转排序的反例。正式对照须保留共同规则 BTM、单独的先重试消融、最佳固定顺序、成本阈值、最近反馈及确定性解析。Gate 18 原端到端 ReAct 12/20、完整 BTM 论文提示复现 17/20，独立保留。Gate 19 方法仍为 No-Go，证据限于既有合成合同及复用起点。下一轮可先核验新合同是否产生可识别的动作反转，依据强规则的留出表现决定是否值得进入模型试点。
