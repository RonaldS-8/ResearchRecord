# 2_011 · 前五候选的次序变体

探索性 CPU 复算。输入为 2_009 已见四任务的冻结前五。比较按工具序列去重、按排序后工具多重集去重的数量。假设部分候选位用于相同工具的不同次序；若两列相同则该任务不支持此解释。每任务五条，全量一次，无模型。此指标只描述候选构成，不判定不同次序等价或恢复成功。

以 JSON 中 candidate_routes 分任务计算 len(set(map(tuple, routes))) 和 len({tuple(sorted(r)) for r in routes})。任务 002、005、011、026 的有序计数均为 5，多重集计数依次为 3、4、3、5。共 5/20 个候选位重复使用本任务前面出现过的工具组合。天气任务 026 没有此现象，单靠合并排列无法修复它的候选。未改变排序或执行器。
