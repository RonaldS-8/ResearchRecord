## 1. 修正了什么

| 问题（验收报告编号） | 性质 | 修正版的做法 |
| --- | --- | --- |
| 保存的似然落后一次 M 步（数学 4） | 实现缺陷 | 多做一次 E 步，使似然和期望计数属于返回的参数；重启选择与 BIC 都用它。同时记录“若仍用旧似然，选出的重启、是否带转移、状态数是否不同” |
| 固定容差依赖比较顺序，且局部容差不保证全局损失（数学 3） | 决策规则定义不清 | 两条与顺序无关的规则，见第 2 节 |
| 标签表默认取自生成器（数学 2） | 接口边界不清 | 标签表只从日志读取（`logged_labels`） |
| 回退用的 ACV 仍是依赖顺序的容差 | 同上 | 回退改为同样与顺序无关的 ACV |
| 结果里有负零，其符号随 Python 版本变（复现 B1 的原因，见反思报告） | 记录方式 | `d1` 的结果写盘前把负零写成零，并在文件里记录 Python 版本、平台和命令 |

**没有改的：** 隐马尔可夫模型仍按“决策步”转移（一次记录的动作及其反馈转移一次，成功后自动跟随的调用不转移）。理由：本实验所有生成器的故障规律本身就是按决策步定义的（成功率按公开事件序列索引），按决策步是与生成器一致的写法；改成逐调用会改变实验机制。隐藏状态不变的情形下两种写法完全相同，Gate 42A 的执行器属于这种情形。动态状态接到逐调用的真实执行器之前，需要另行定义并验证，本轮不做。

## 2. 两条与顺序无关的比较规则

记某个节点上动作 $a$ 的模型估计为（完成率 $c_a$，费用 $f_a$）。

- **节点带 `within(δ)`**：在 $c_a\ge\max_b c_b-\delta$ 的动作里取费用最低的。结果只由集合决定，与比较顺序无关。每个决策最多放弃 $\delta$ 的条件完成率，一个最多 $H$ 个决策的计划在模型内最多放弃 $H\delta$。
- **全局界 `priced(δ)`**：取 $c-\lambda f$ 最大的计划，$\lambda=\delta/F$，$F$ 是任何计划费用的上界（调用预算乘以最高公开单价）。这是一个全序，没有顺序问题，并且对整棵树成立
  $$c(\pi^\star)-c(\pi_\lambda)\ \le\ \lambda\,\big(f(\pi^\star)-f(\pi_\lambda)\big)\ \le\ \lambda F=\delta ,$$
  其中 $\pi^\star$ 是完成率最高的计划。它只在“每放弃 1 个百分点完成率至少省下 $F/(100\delta)$ 的费用”时才让步。$\lambda$ 只在规划器内部使用，评分仍分别报告完成率与费用。

两条界都只在拟合出的模型之内成立；模型错了，真实损失可以更大。

## 4. 登记的判断（不符即被否定）

| 编号 | 内容 |
| --- | --- |
| R1 似然修正 | 在全部（种子, N）上，旧似然会选出不同“5 状态结构”的比例不超过 2%，会选出不同 BIC 状态数的比例不超过 5%。若超过，c4 的模型选择结论须重写 |
| R2 节点带与旧容差 | M5、M3、S4b、A、E 上 N≥300 时，`belief3_within0.01` 与 c4 的 `belief2_tol0.01` 相比，平均完成率相差不超过 0.5 个百分点、费用相差不超过 1% |
| R3 全局界的代价 | S4b、N=3000：`belief3_priced0.01` 的平均费用不低于 3.75（估计噪声去不掉，省不下钱），`belief3_priced0.05` 不高于 3.70。M5、N=3000：`belief3_priced0.01` 不高于 3.47。即费用优势在 S4b 上依赖容差的宽度，在 M5 上不依赖 |
| R4 M3 上的完成率优势不来自隐藏状态 | M3 上 N=30、100、300：`pooled_within0.01` 与 `acv_untried` 的平均完成率都不低于 0.99。若成立，M3 的小样本完成率不能再算作隐藏状态的证据 |
| R5 M5 上需要隐藏状态 | M5 上 N=100、300：`belief3_within0.01` 的平均完成率比 `pooled_within0.01` 和 `acv_within0.01_untried` 都高至少 3 个百分点，实质性落后的种子至少少 20 个 |
| R6 负对照不变 | 混杂日志下修正版的平均费用不低于 ACV（4.40）；迁移到 0.3、0.1 时与 ACV 相差不超过 0.05；B2R-mini 上 N=3000 时 `belief3_within0.01` 的费用不低于 `acv_tol0.05` |
| R7 小样本的全局界 | A、M5、B2R-mini 上 N≤100：`belief3_priced0.01` 的平均完成率不比 `belief3_strict` 低 0.5 个百分点以上（全局界在模型内不超过 1 个百分点，且小样本下它应接近严格） |

## 5. 事先写下的止损读法

- R4 成立而 R5 不成立：小样本优势全部来自“不在没数据的地方停下”和共享统计，与隐藏状态无关。建议停止信念模型这条方法线。
- R5 成立、R3 的 S4b 部分成立：隐藏状态的贡献限于“认出互斥路径的结构性并列”；共享故障上的费用优势依赖一个没有全局保证的容差，不能作为结论。
- R6 成立（预计如此）：混杂、迁移、结构失配下没有任何保护，这是适用边界，不随修正改变。
- 是否值得投入真实 LLM 实验，只按“是否还剩一个范围明确、可以被否定的假设”来判断，不以信念模型优于 ACV 为目标。
