## 证据和审计口径

每请求原始kwargs（无认证头）、响应/推理/usage、起止时间与延迟逐行落盘；每回合配置、全部公开事件、真实模型参数、独立重放评分、strict/义务、非法调用、费用及终答保存云端results/047-*与046-*。报告按模型/检查点/合同/记录/措辞/命名分别列分母，不混合原始与变体；token输入/输出/缓存/推理分列，工具费和API费用不相加。CPU脚本绑定的合法路径只用于验证，不作为Agent结果。

按045R E（明确文本）、B（行为支持）、U（未知）逐回合编码。表现与原因分列；推理不是内部因果证明。主因A语义误读；B执行（引用/对象/字段与纯格式分别）；C仅在正确理解合同和反馈有证据时的恢复决策错误；不足标unknown；SDK/解析/基础设施另列。至少核对备用路径识别、满足用户目标、反馈理解、所选动作可完成性、更好路径预算可行性、成对C1是否避免损失。C1成对差异支持合同影响，但文本长度/注意力和合并澄清项仍混杂。语义澄清有效不等于原合同充分或Q2不存在。

## 选题 Go / No-Go（探索性，非显著性检验）

强模型在足够差异任务接近≥90%而4B失败集中：当前M3/M4不支持强Agent普遍恢复瓶颈；优先小模型可靠恢复/能力差异或新真实不确定场景。仅两个机制及措辞重复不足以满足“足够差异”。语义/执行主因超过失败半数或澄清明显消除主失败：当前Benchmark/接口问题优先，暂不开发决策算法。清楚合同下强模型仍有可复现C类错误且有任务/成本损失：Q2可Go进入强规则/成熟恢复基线检验，不能推新数学方法必要。其余Inconclusive，明确缺什么数据。最终必须在“继续Q2/小模型可靠恢复/合同问题/证据不足找新场景”给出当前建议；无真实结果时不提前裁决。
