# 006：Gate 4 Qwen3-4B 诊断决策最小实验

目标：先验证真实模型能选择恢复动作、调用付费诊断并继续完成任务，再观察其价格选择。用户批准本实验；环境及评分继承 Gate 3，不修改 Benchmark、任务、成本或故障机制。不微调、不做 RL、不扩任务、不追求推理优化。

## 假设与竞争解释

假设：模型能完成工具交互，并在低价下较多选择诊断、高价下较少选择诊断，接近固定价格规则的成本。竞争解释：模型只重复同一动作、不会利用诊断结果、反复购买无用诊断、不能完成工具协议，或只是任务信息/评分异常造成表面成功。

可证伪标准：诊断后的动作不利用返回、价格选择无差异或成本高于规则均如实报告；基本交互失败则停止。任何泄漏、原生与独立评分不一致、固定输入/环境哈希变化均停止。不会通过改提示、采样、任务或价格修复负结果。

## 冻结配置与合法信息

- 现有 10 个任务：018/019/020/021/023/024/025/027/028/032，P1/P2，诊断 0.25/0.75；固定短入口首次故障后开始，工具尝试成本 1，底层调用预算 32、恢复动作预算 8 不变。
- 模型 Qwen3-4B-Thinking-2507，云端 vLLM 0.31.0、Transformers 5.17.0、OpenAI SDK 3.42.0；本地 HF 修订 `768f209d9ea81521153ed38c47d515654e938aea`。登记模型文件清单、配置和 tokenizer 哈希、服务器模型信息。
- 沿用现有 temperature=1、max_tokens=16000、timeout=300s；seed 基数 0，每次模型请求使用 0+恢复决策步号。tool_choice=auto、parallel_tool_calls=false、SDK 重试 0。只接受一个合法无参函数调用，不截取、不解析文本替代、不补救格式。记录截断和失败。
- 模型只看公共任务、背景工具描述、公共历史、一般故障动力学、先验和报价；使用 retry/switch/diagnose 函数。首次两状态请求（含 seed）必须相同。当前状态、模式标签、原始故障原因、路径、参考参数和私有审计均不得进入模型输入。
- 不提供“最优动作”、理论收益 0.5 或诊断阈值公式。诊断返回后可继续选择动作，未完成前文本结束算协议失败，不由运行器代选恢复动作。

## 分阶段运行

1. 提交设计，再实现适配与必要自检；原 `tests/test_no_leakage.py` 及 Gate 3 测试继续通过。用假的模型响应测试记录完整性、严格解析、成对输入一致、诊断回传与错误拒绝，不调用 GPU。
2. 接口自检：018、低价、私有 P1，附加固定指令“先调用一次 diagnose，再根据结果恢复”；模型仍不知道状态。必须真实调用 diagnose 并完成恢复，否则停止。该运行单独标记、保存全记录，不计入自主策略评价，不据失败修改提示。
3. 自主单任务：018×两模式×两价=4 情况，无附加动作提示。合法但不经济的选择不算接口错误；不要求必须诊断。全部基本交互/评分正常后进入完整运行。
4. 完整自主对照：10×2×2=40 情况，每种情况一个轨迹、同一种子规则，串行执行，不重复挑选较好结果。模型重复调用诊断的真实费用照计。若任一情况出现致命协议/评分/泄漏问题，保存部分结果并停止后续情况。

## 评价和错误类型

按价格分别报告：尝试数/预定数、合法完成率、全部尝试成本及成功部分成本（失败低花费不作为优势）、平均恢复/总成本、至少一次诊断的轨迹比例、诊断总次数、已记录 Token 总量及每请求/每轨迹延迟。模型资源不擅自计入 Gate 3 费用。

对照 Gate 3 同任务/模式/价格的固定规则、最佳无诊断完整恢复策略及独立知情参照。先核对对照配置/源码和输入哈希；原始对照只使用匹配情况。界面自检和单任务试运行不混入 40 情况结果。

预定分类：低价初始未选诊断、高价购买诊断、重复诊断、诊断后明知持续仍重试/可恢复却切换、失败重试后再次重试或购买诊断、初始选择期望成本更高的切换，以及提前文本结束、无效/多工具调用、非空参数、输出截断、请求错误和预算耗尽。描述选择错误时使用当时合法信息，不能仅因事后知道状态而判错。

## 归档和停止

每阶段新建 `results/<run_id>/`，保存运行提交、冻结配置与系统提示、模型版本、服务信息、种子、输入/源码哈希；每次请求发送前写全输入，响应后保存完整原始响应（含 reasoning、finish_reason、usage）、耗时和解析结果。保存环境完整轨迹、全部公共输入、费用、原生及独立评分。失败包括请求无返回时未知 Token，不记成真实 0，不覆盖、不下载本地。

本实验不改变研究指标定义。Gate 3 的正收益是预设环境参照，不保证模型实现它。运行后按观察与解释分别汇报；触发停止条件后不调参、不继续完整运行。
