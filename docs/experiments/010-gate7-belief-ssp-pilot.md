# 实验 010 · C2-018 故障恢复最小原型

状态：单任务原型有条件批准，尚未执行。参照 [ADR-0008](../adr/0008-toolmaze-belief-ssp-pilot.md) 和[实验 005](005-diagnostic-mvp.md)。本任务已用于 Gate 3–5，定位为探索性机制验收。固定已验证的合法前缀、受影响节点与替代路径。

## 状态、事件和收费

公共状态含任务、有效结果及其来源、剩余路径、合法反馈和剩余预算。私有故障状态为暂时故障未恢复 T、已恢复 H、持续故障 P。故障前缀成功后，T/P 各半。事件顺序固定如下：

1. 首次受影响调用固定失败，T/P 返回同一扩展错误。先记录失败并计费，再以概率 h 将 T 转为 H。P 保持。策略的首个决策发生在转移之后，此时对 H/T/P 的先验分别为 h/2、(1−h)/2、1/2。
2. 重试读取调用前状态。H 调用原生工具并公开真实结果，成功后展开原路径。T/P 返回扩展错误且不产生有效输出，然后仅对 T 执行同样的恢复转移。H 中的真实原生调用失败按验收异常留档，不能当成故障模型中的失败。转移和诊断随机数使用独立随机源，枚举按相同顺序展开。策略先对调用结果条件化，再预测下一决策时的状态。
3. 诊断读取当前状态，输出「已恢复」或「未恢复」。灵敏度 Pr(报告已恢复|H)=a，特异度 Pr(报告未恢复|T)=Pr(报告未恢复|P)=a。给定完整隐藏状态序列，各诊断噪声独立；给定公共历史，连续诊断通常相关。诊断不推进恢复时钟。每次都计费并消耗一个恢复决策，允许重复。
4. 切换展开固定合法替代路径。停止直接结束。两者不推进受影响工具的恢复时钟。每个顶层工具尝试计对应费用，失败也计。诊断单独计费，不计入底层工具预算。共同上限为 8 个恢复决策和 32 次底层工具调用，后者包含固定前缀与首错。预算不足的宏按实际执行和收费报告，未完成。首错及此前费用单列。

环境和枚举使用同一份事件定义及参数。独立验收用手算概率和真实回放核对，不能以两者共用实现作为正确性证据。

## 预登记矩阵与强基线

先验各半。恢复概率 h 取 1/4、3/4，另设 h=1 边界。诊断准确率 a 取 1/2、3/4、1，分别代表无信息、有噪声和完美。诊断价格取 Gate 3 的 0.25、0.75。执行成本三组：全 1，或故障工具和替代入口分别取 0.5/1.5、1.5/0.5，其余为 1。全格报告。这些是受控参数，尚无现场标定，不能解释为真实故障率或价格。

- 固定规则含直接切换和**最优重试阈值**。枚举从 0 到共同预算允许的最大次数，失败达到阈值则切换。对每格保留最佳阈值及并列。
- 诊断规则含先诊断和达到失败阈值后诊断。枚举信号到「直接切换 / 重试至阈值后切换」的映射。另纳入最多两次诊断的信号计数规则，避免把重复付费取证的收益只留给理论策略。
- One-bit Memory 只保存「本回合是否已有一次失败重试」。按该位选择重试、切换或诊断，诊断后按该位和当前信号选择后续动作。公共预算仅用于判断动作可行性，不用剩余步数反推失败次数。枚举其可行动作表。强对照取上述规则族每格最优。所有规则使用同一公开参数、合法接口和成本。
- 理论最优对合法历史做有限预算反向枚举。并列时保留全体最优首动作。独立 Oracle 读取当前隐藏状态，使用相同预算与行动，不预知未来随机数。报告严格完成概率及期望恢复费用（含失败分支），先比较完成率，再比较同完成率费用。停止单列。无不可恢复案例时正确停止率记不适用。

竞争解释是最优重试阈值或简单诊断规则已达到理论最优。为了定位差距来源，同时报告禁止诊断时的最优值和基线值。单任务无法检验跨任务路径规划优势。

## 两层 Go / No-Go

1. **原型验收。** 真实前缀和完成分支通过原生 P0 与独立验证。拒绝错参、跳步、伪造返回和非法复用。成对首观测相同，未付费时没有诊断返回，公共输入不含真值。现有 `tests/test_no_leakage.py` 和扩展专项测试均通过。独立手算核对一次首错转移、两次失败后的后验、连续诊断联合概率、账单及预算边界。概率质量守恒，理论最优不劣于各基线，知情参照不劣于理论最优。任一不符先保存证据，排查实现。
2. **科研放行。** 只在 a=3/4 的非完美诊断格上判断主标准。要求同严格完成概率时，理论最优相对强简单基线的期望费用至少低 0.05 实验单位，达标格的取值合计须覆盖两个非边界 h、两种诊断价格和至少两种执行成本配置。不要求所有格都有差距，所有负结果与并列完整报告。该门槛是预设的结构筛选线。即使通过，也只提议扩展，须另用独立证据说明参数合理性并审核。未通过则保留原型作为负结果，不调整参数或更换任务来追求收益。

运行只在 LabServer 的现有环境。保存预登记与运行提交、输入哈希、配置、枚举概率和轨迹、回放核对及隔离结果。精确枚举无采样种子，若另有种子化回放测试则记录测试种子。模型与推理框架记不适用。
