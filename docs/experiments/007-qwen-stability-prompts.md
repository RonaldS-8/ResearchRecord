# 实验 007：诊断决策稳定性与成本提示对照

日期：2026-11-05。状态：先登记，后实现与运行。授权：用户 Gate 5；技术约定见 ADR-0005。

## 问题与冻结条件

Gate 4 高价过度诊断是否跨随机种子重复出现？仅增加一句成本比较提示能否改善？竞争解释：单次采样偶然性，或简单提示已足以达到固定规则水平，不需要新增诊断算法。

冻结 Gate 4 的 10 任务、P1/P2、0.25/0.75 价格、先验、预算、Qwen3-4B 修订、服务、工具、评分器及温度 1 等请求参数。原 Prompt 字节不变；成本提示只在系统文本末尾增加一句：

> 决策前比较重试、切换和诊断的预期总成本，诊断收益不足时不要购买。

不告知最优动作、公式或阈值，不修改全局指标草案。冻结种子为 0、1、2；后续第 t 次决策使用 seed+t，与 Gate 4 的步号规则一致。

## 成对抽样与预算

正式：10 任务 × 2 价格 × 2 Prompt × 3 种子 = 120 对，即 240 条环境轨迹。每对先检查完整初始请求相同，只请求一次初始动作，将同一 assistant 消息（含工具调用标识与推理）复制到两个独立会话，再分别执行 P1/P2 和接收真实反馈。后续串行独立请求，不重新抽初始动作。

顺序：种子 0/1/2 → 配置中任务顺序 → low/high；每个种子中按任务序号+价格序号+种子序号的奇偶交替两种 Prompt 顺序；每对先 P1 后 P2。仅一个实验请求在途，不改变服务容量。顺序不能消除时间漂移，结果不作因果推广。

最小运行自检另取 018/low/原 Prompt/seed0 一对，不纳入正式指标；必要测试用模拟客户端核验共享抽样、独立反馈、计数和失败保留。通过后执行确定性检查：018/high/原 Prompt/seed0，temperature=1 和 0 各重复 3 次，除温度外完全相同，共 6 请求，不执行恢复、不混入正式结果。记录完整响应；分别比较动作和 assistant 消息（含推理，排除响应 ID/时间/usage 等外层元数据）。不要求一致，也不调参消除不一致。

每条环境轨迹最多 8 决策；一对最多 1+7+7=15 次真实模型请求。正式上界 1800 次，自检上界 15，确定性检查 6，总上界 1821；每请求最多 16000 生成 Token，因此生成上界 29,136,000 Token。预计常见一次诊断后恢复约 360 次正式请求；估计不是预算保证，不因中间表现筛选种子、补跑或提前选择最优结果。

描述性标准预先固定：原 Prompt 高价每个种子都至少一半初始动作诊断，称本次三种子中重复过度诊断；否则不支持这一强稳定性说法。成本提示若每个种子高价诊断率都低于原 Prompt、合法完成率不降且恢复均值不高于 4.05，才称本实验中解决高价问题；同时报告低价是否退化。任何较弱改善照实列出，不改判据。样本小，不作总体统计显著性或模型普遍能力结论。

信息泄漏、评分异常、基本协议失败立即停止，保留部分结果；随机输出、重复诊断或非最优动作本身不停止。预算耗尽仍未合法完成属于基本交互失败，停止并记录。强基线接近上限或结果否定假设时如实报告，不改变设置继续挽救。全量完成后仅分析，不自动开启新实验。
