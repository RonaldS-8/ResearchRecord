# 实验 025 · 动作条件恢复的 Agent 效率试点

探索性预注册。冻结配置和代码提交后，先做工程验收，再执行一轮小规模模型配对。执行接口见[ADR-0023](../adr/0023-agent-efficiency.md)。

## 样本、分组和预算

- 保留 Gate 22 的完整机制和无信息诊断两格，任务家族为预约、凭证归档，需求为标准、跨域。使用新种子 2321、2322。每家族和种子组合预指定准备回执正负，以家族和种子序号和的奇偶交错，偶数为正。在 Gate 22 原事件生成器的前 128 个编号中取首个满足该公开回执的实例。保持原条件生成律并对正负各赋一半权重；选择只读公开回执，不按隐藏结果或候选表现筛选。同一基础事件跨需求和诊断格配对，共 4 个基础事件、16 个带条件的起点。逐种子分列，先导结果不用于总体优势声明。
- 每起点运行无历史、共同规则 BTM、Action-Conditioned Memory、LLM 加动作价值决策器，以及 BTM 加先重试、完整论文提示复现两个独立参考，共 96 个评估回合。非 LLM 保留 Gate 22 验证集最佳固定顺序、最近反馈、完整历史费用阈值及完整规划。混合组用同一完整历史固定续程的确定性解析作为机制核对，实得工具路径差与模型开销分别解释。
- 每个模型组先跑两条共同夹具。一条从已购买诊断且 A/C 已失败的合法前缀开始，需用 B 得到短凭据、验证后登记。一条在三个路径均已失败的合法检查点正确停止。12 个验收回合须全部完成预期结果并提供完整 Token 账目。若验收失败，保留轨迹并暂停试点。
- Qwen3-4B-Thinking-2507 修订 `768f209d9ea81521153ed38c47d515654e938aea`，vLLM 0.31.0，服务最大上下文 40,960。沿用 Gate 19 的 temperature 1、单请求最多 16,000 输出 Token、300 秒超时、每步种子 `16 × case_seed + turn`，串行且无自动重试。评估按预定起点序号轮换模型组顺序。环境执行额度、探针额度与 Gate 22 相同。每回合最多 6 个模型请求，全批上限 **648**，输出上限 10,368,000 Token，输入理论上限 16,174,080 Token。验收计入预算。

## 计价与归因

冻结参考价为每百万输入 Token 0.01 美元、每百万输出 Token 0.03 美元，取 2026-11-10 查到的同名模型 Hugging Face Inference Providers / Nscale 档。输出包含服务记入 completion 的推理 Token。上限折算约 0.473 美元；实际在 LabServer 本地 vLLM 执行，参考价用于情景估算。[Hugging Face 价格表](https://huggingface.co/inference/models?model=Qwen%2FQwen3-4B-Thinking-2507)

报告严格完成率、结构阻断分母下的正确停止率、提前停止、非法和协议或服务失败。工具与诊断费用、执行调用和冗余、模型请求、输入／输出 Token、请求延迟总和与端到端墙钟分别报告。未知 usage 的回合计入完成率及环境账本，涉及 Token 或模型美元的配对明确列可计价分母。成功轨迹冗余沿用 Gate 22。按全部回合、与 BTM 共同成功的同任务子集，以及失败和正确停止单列。保留逐任务差、首次合法分歧与执行路径。

模型美元按冻结费率计算。环境费用分别保留模拟工具费与诊断费。只在情景表中设每一模拟单位统一映射为 $k$ 美元，报告 $k=0,0.0001,0.001,0.01,0.10$ 时的 $\Delta\mathrm{USD}=\Delta\mathrm{model}+k(\Delta\mathrm{tool}+\Delta\mathrm{diagnosis})$。差值以候选减 BTM；当环境差非零，给出正的盈亏平衡点及两侧的方向，或说明在非负映射下无交点。映射仅是敏感性情景。

记录同一 tokenizer 下共同系统、各臂附加系统文本、动态历史块、公开观察和动作 schema 的独立长度，实际输入计费以服务 usage 为准。在相同起点比较 BTM 和 Memory 的动态统计长度。逐任务同时看调用次数、总输出 Token、推理延迟及合法路径差。若只看到文字长度或固定规则即可解释的收益，单独归因；该试点未操纵文本长度，长度归因限于描述。

## 判据

- **工程 Go。** 旧防泄漏和专项验收通过，合法实参及费用双账本一致。六个模型组均完成两条夹具且 usage 齐全。同起点、种子及事件键一致。协议和服务失败保留并归类。
- **值得扩大。** 候选总体和两个家族的严格完成均不低于共同规则 BTM，正确停止与非法动作不退步。共同成功至少 8 个起点，工具费或执行调用下降至少 5%，且总 Token 和推理时间均下降至少 5%，两个测试种子同向。收益须能在合法路径上复核，另与强固定顺序、最近反馈、完整历史阈值和完整规划比较。若简单规则已覆盖环境收益，或只有提示长度和成本迁移证据，则不扩大。两类费用取舍与盈亏平衡独立报告。只作探索性判断。
