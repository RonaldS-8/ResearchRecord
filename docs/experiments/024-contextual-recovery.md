# 实验 024 · 同错误下的任务与历史动作反转

状态为已批准的探索性预登记。代码、配置和判据在运行前提交冻结，CPU 试验在 LabServer 执行。Agent 配对只有通过预登记判据才提交设计审核。见[ADR-0022](../adr/0022-contextual-recovery.md)。

## 假设与最小反例

假设是任务依赖改变路径成本，较早的工具反馈改变条件成功率，两者可共同改变同一 A 错误后的首选。竞争解释包括任务分层固定顺序、完整历史的局部费用阈值或一次探针规则已足够，以及历史估计误差掩盖或制造排序差。两种证据均通过公开合同与合法回执给出。

从共同首错进入恢复，再令 A 的一次合法重试失败。保持错误、动作菜单、价格、最近一次反馈和四次剩余执行额度相同。动作反转见证关闭诊断额度，B/C 都可试到首个成功。令 $Z$ 为网关好态，先验 $1/2$，准备反馈准确率 $0.8$，A 在好／坏态成功率为 $0.60/0.05$，B 为 $0.90/0.10$，C 恒为 $0.70$。准备反馈正／负后再观察同一次 A 失败，$P(Z\mid h)$ 分别为 $32/51$、$2/21$，对应 B 的条件成功率约 0.602、0.176。固定任务看历史差异，固定历史看任务差异，另记录两者共同变化的两条对角配对。

令 $p=P(B\text{ 成功}\mid h)$，$d$ 为 B 成功后的期望验证费，标准任务 $d=0$，跨域任务 $d=1$。固定续程为首选失败后试另一条，成功后按回执登记。两顺序完成概率均为 $0.70+0.30p$，共同期望登记费相消。B 优先的工具费为 $1.20+2(1-p)+pd$，C 优先为 $2.36+0.30pd$。

| 任务需求 | 较早准备回执 | B 优先费 | C 优先费 | 预期首选 |
|---|---|---:|---:|---|
| 标准 | 正 | 1.996 | 2.360 | B |
| 标准 | 负 | 2.848 | 2.360 | C |
| 跨域 | 正 | 2.598 | 2.541 | C |
| 跨域 | 负 | 3.024 | 2.413 | C |

表为推导值，省略共同登记费。开启诊断后，另验跨域／正回执这一格。正诊断应将 B 的条件成功率提高到约 0.797 并改选 B，负诊断继续选 C，完成概率不变。预期工具费下降约 0.113，扣除 0.05 后净节省约 0.063。无信息探针应保持选 C。所有见证用精确枚举和独立执行器回放双校验，单独归档。

## 随机矩阵与历史

| 格 | A/B 故障关联 | B 短凭据概率（标准／跨域） | 准备反馈准确率 | 诊断准确率 |
|---|---|---|---:|---:|
| 完整机制 | 共享 | 0／0.50 | 0.80 | 0.80 |
| 去依赖 | 共享 | 0／0 | 0.80 | 0.80 |
| 去关联 | 独立，边际不变 | 0／0.50 | 0.80 | 0.80 |
| 无信息诊断 | 共享 | 0／0.50 | 0.80 | 0.50 |
| 无信息准备反馈 | 共享 | 0／0.50 | 0.50 | 0.80 |

沿用 Gate 21 的生成率与按语义事件键配对。同一基础实例跑两类需求和各格，保留全部随机结果。每格训练用包裹、发票，种子 2201–2203，每家族每种子每需求 12 例。前六例各半分配 A→B→C 或 A→C→B，其余六例分配六种顺序，每种首动作各一条首轮探针与无探针记录。验证用制品发布，种子 2211–2212，每种子每需求 8 例。留出用预约、凭证归档，种子 2221–2224，每家族每种子每需求 4 例，共 320 个带需求的起点。两需求与各格共享基础键，按种子报告配对方向。

历史拟合复用 Gate 21 网格似然与 Beta 平滑，各需求分别估计工具率和凭据续程。BTM 主代理按两需求的合并历史统计，另报使用同需求历史的 BTM 代理。完整机制格同时保留匹配、局部缺样本与去关联历史迁移三种估计。局部缺样本复用同一批训练世界与分配，仅在正准备回执、刚观察到 A 失败且未诊断时，将原本选 B 的采集动作改为仍合法的 C。记录该检查点 B/C 的直接尝试数。若匹配历史任一需求的两种准备符号下，B 或 C 的直接支持少于三条，标为证据不足，保留结果。

估值回放在共同的任务固定策略轨迹上强制各合法动作、随后使用冻结的完整历史局部阈值。比较同续程估值、按生成律计算的条件期望和同事件实得，分别报告排序误判、完成 Brier、工具与诊断费的绝对误差和有符号偏差。隐藏状态与生成参数只在评估侧使用。

## 强基线与放行

比较验证集选出的全局最佳固定顺序、按需求分别选出的最佳固定规则、当前成功率／价格阈值、最近反馈规则、完整历史费用阈值、Gate 21 最佳固定续程及单次诊断规则、Action-Conditioned Memory 和完整规划。最近反馈在 A 重试失败后使用这条新反馈，完整历史同时使用准备回执。另比较移除准备证据的 Memory 和两种 BTM 代理。简单规则按独立验证集的严格完成、正确停止、平均总费用顺序择优，并列按登记顺序。所有策略使用共同合法合同及严格评分。

- **工程与机制 Go。** 旧有防泄漏与专项测试通过，账本、凭据范围、终态和事件键配对一致。三组单因素对照与反例相符。去依赖消除任务排序差，去关联或去准备信息消除早期历史的排序差，无信息探针无净收益。精确反例、随机留出和 Agent 证据分别陈述。
- **提交 Agent 设计的门槛。** 完整机制格相对验证集冻结的最强简单规则，两个留出家族均无严格完成率及正确停止率退步。精确期望完成率至少提高 2 个百分点，或同完成率下平均恢复总费用降低至少 5%。至少三个独立留出种子的配对结果方向一致，并至少有一组固定任务需求与最近反馈、只改变合法早期历史的动作反转。若强简单规则逐动作复现完整规划，判方法 No-Go。达到门槛只提交 Agent 设计审核。留出样本、门槛和报价在首次试验前冻结。

## 云端结果（2026-11-10）

运行提交 `3c370ca`，Python 3.10.12。27 项云端验收通过。归档 `results/024-gate22-contextual-01/` 于新加坡时间 11:07 完成，包含 320 个带需求的留出起点及 4,608 条策略轨迹。每格的两类需求复用 32 个基础事件键。逐条复核严格审计均通过，无过早停止或预算耗尽。本轮无模型请求。

**精确机制见证通过。** 关闭诊断额度时，同一 A 失败后，标准任务的较早准备回执由正转负使首选从 B 改为 C。保持正回执、把任务改为跨域也使首选从 B 改为 C。去依赖后两类需求的排序一致。去关联后标准恒选 B、跨域恒选 C。去准备信息后两种回执均选 C。跨域／正回执下，开启有信息探针使预期工具费由 2.893 降至 2.780，诊断费 0.05，净节省 0.063，严格完成概率仍为 0.881。无信息探针不买。见 `witnesses.json`。

- 两个需求各自从验证集选出的固定顺序都是 A→C→B。完整规划比最近反馈实得节费 3.21%，精确期望节费 3.70%。预约严格完成 26/32、正确停止 6/6，归档完成 30/32、正确停止 2/2，两家族与最近反馈持平。四个测试种子中 2221、2223、2224 省费，2222 多花。预约家族的任务固定顺序仍比完整规划便宜（2.325 对 2.445）。
- 单次探针规则与完整规划在 64 例上的执行工具序列完全相同，差别只在探针时机。跨域且正准备回执的 16 例，单次规则都先买探针，完整规划先试 A，在 A 失败的 8 例才买。因此全格探针数从 48 降到 40，精确期望总费仅降 0.27%。例如跨域预约 2222 实例 0，A 直接成功，两组都以 0.80 工具费完成，先买探针的一组另付 0.05。
- 保留准备证据的 Memory 代理比去准备证据代理少付平均 0.144 工具与诊断总费。它与单次探针规则逐动作相同。相对 BTM 代理，Memory 的留出平均费用下降 3.46%，精确期望下降 2.63%，严格完成持平。成功轨迹的平均冗余工具调用从 0.714 到 0.446。该比较限于确定性统计代理。

去依赖、去关联和无信息诊断三格中，学习后的完整规划与单次探针规则逐动作一致。去关联格的精确见证消除了历史对 B/C 选择的影响；随机留出中，学习策略仍可能为了 A 买探针。各格分别拟合训练历史，格间实得费用差包含估计差异。

完整格每需求有 72 条匹配历史和同规模的局部缺样本历史。A 失败且未诊断时，正回执的 B/C 直接支持数由 5/5 变为 0/10，负回执保持 11/13。匹配与缺样本估计均在 128 个获取检查点中误排 8 次，都发生于标准、正回执、A 失败后，将 B 排在诊断之前。去关联历史迁移则误排 30 次，均为标准负回执中把 B 排在 C 前。排序计数来自重复的公开证据形状。匹配历史下，首动作 A 的平均工具费偏差 +0.285 可分为 +0.213 拟合偏差和 +0.072 抽样残差，完成 Brier 为 0.096。迁移历史的 B 费用平均偏差接近零，但 −0.120 的拟合偏差与 +0.120 的抽样残差相抵。详见 `evaluation.json`、`expected.json`、`history.json`。

**工程与机制 Go，方法 No-Go。** 精确见证支持任务和历史分别改变动作价值。完整规划的学习收益在本批未达 5% 节费门槛，相对可买探针的强规则也只节省少量诊断费。按预登记不提交 Agent 实验设计，真实 Agent 表现仍未评估。
