# 2_012 · 参数依赖图的独立恢复价值

基线 68ac842。先登记资格与 CPU 审计，正式 GPU 待批。假设是异名且存在竞争来源时，In-N-Out 的语义判边能减少错接并帮助完成恢复；竞争解释是强语义规则已足够、公开合同欠定、执行/验收限制或可见菜单透露答案。

**独立选择。** 隔离评测侧枚举原生 C1–C4 全部基础任务与 126 个替代组，按基础任务、工具实现和故障家族去重。凡 Gate054 已登记核查的原生基础任务及公开替代组，均不得算作新留出。P0–P4 不另计。另列已见同名对照 M4。即使图与规则均失败也保留入组项。独立正式样本要求至少两个互不共享实现的异名/条件家族和一个简单同名对照；各层按任务 ID 字典序选首个合格样本。每例须有重置后主路故障、合法备用路径、用户要求的业务结果和可独立核对的读回/只读预期值；副作用不能核对记 unknown。资格不足停止正式阶段，禁止从模型结果补样。

**拟议比较。** 同一 Qwen3-4B、种子、冻结前缀、公开 FC 合同与共享 MCP 输出字段、相同全域菜单、温度 0。原生 ReAct、强语义规则、In-N-Out 自动图；若有重置能力，追加自动图加执行验证。共同从任务和公开输入确定未满足义务与候选端点，禁止人工指定读回端点或端点命名特判。规则含类型/单位、字段名和说明的词元、语义相似度、实体与来源一致性；规则与图使用同一候选字段对、搜索、序列呈现和绑定器。允许异名配对。独立评测可用标注，不得输入策略。禁用 M4 的同名预筛、发布专用端点选择、作者依赖标签的候选补齐；补齐按公共相似度固定执行。图和规则均不访问任务答案文件或插件源码。

**指标和拟议上限。** 按独立家族列出边的精确率、召回和错接（含同型困难负例，欠定单列），前五候选中可满足义务的路线覆盖、合法绑定、状态核验、严格评分、完整恢复的逐任务配对差。执行验证用重置副本按相同离线预算，不回传实参或未来结果。分别报告构图、验证、在线和验收重放的调用、Token、时延。首轮若达资格仅三例四臂各一回合，每臂最多六个在线模型请求和六次工具调用，图构建每例最多十二个请求，验证最多六次模拟调用；GPU 上限一小时、总模型请求上限 108、单请求 6144 输出 Token，零外部 API，超限保留失败。验证臂报告额外消耗。三例仅作开发性配对描述，扩大样本另议。

CPU 验收结论：400 个原生基础任务中，具备已登记备用路径的 300 项全部复用已见替代组。当前独立正式样本为零。保留 M4 已见简单对照，正式四臂均未启动。见[审查及逐边证据](../reviews/2_012-dependency-value.md)。
