# 实验 013 · Gate 11 最小验证

依据 [ADR-0011](../adr/0011-action-value-and-btm-comparability.md)，验证分支结局按公开报价重算是否消除 Gate 10 的费用迁移偏差，以及已有同键证据是否足以支撑比较。完整 BTM 模型运行与多步环境开发不在本批。

- **回归。** 原样复用 `gate10.json` 的任务、采样、种子和单位调用价，因此不另建配置。保留旧费用迁移、固定规则、聚合与上下文阈值、One-bit Memory。首重试率继续用 Beta(1,1)，续程分别记录实测完成频数与分母，缺分支则回退到同一上下文阈值。续程必成时两规则应在 144 个起点全部同选，严格完成数及实际费用一致。任一不一致保留轨迹并排查。该回归使用既见任务与条件，不作新泛化证据。
- **同键。** 只读复用 Gate 1、3、6 的存档，按失败工具／原始报错列候选。Gate 3 另按扩展统一错误及实际切换入口列候选。任务 ID 或模板哈希不同不能单独证明家族独立。候选仍需通过家族核对、合法续程和两臂训练覆盖，才可启动同键比较。保留无独立样本或统计饱和的结果。
- **多步。** 精确枚举两种等概率的合法失败反馈，各自可再重试或切换。与初始直接切换、同失败位恒定动作及无信息对照比较。手算验收为 37/20 对 2，所有列入的策略最终完成。无信息格应无增益。读取当前反馈的简单规则若达到最优，则不支持复杂方法。
- 云端运行既有防泄漏及扩展测试，结果使用新的 `results/<run_id>/`。记录提交、种子、版本、完整轨迹和分组费用。模型、诊断费和正确停止率按配置记录为不适用或零。
