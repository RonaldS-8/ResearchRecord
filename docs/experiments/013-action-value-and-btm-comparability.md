# 实验 013 · Gate 11 最小验证

依据 [ADR-0011](../adr/0011-action-value-and-btm-comparability.md)，验证分支结局按公开报价重算是否消除 Gate 10 的费用迁移偏差，以及已有同键证据是否足以支撑比较。完整 BTM 模型运行与多步环境开发不在本批。

- **回归。** 原样复用 `gate10.json` 的任务、采样、种子和单位调用价，因此不另建配置。保留旧费用迁移、固定规则、聚合与上下文阈值、One-bit Memory。首重试率继续用 Beta(1,1)，续程分别记录实测完成频数与分母，缺分支则回退到同一上下文阈值。续程必成时两规则应在 144 个起点全部同选，严格完成数及实际费用一致。任一不一致保留轨迹并排查。该回归使用既见任务与条件，不作新泛化证据。
- **同键。** 只读复用 Gate 1、3、6 的存档，按失败工具／原始报错列候选。Gate 3 另按扩展统一错误及实际切换入口列候选。任务 ID 或模板哈希不同不能单独证明家族独立。候选仍需通过家族核对、合法续程和两臂训练覆盖，才可启动同键比较。保留无独立样本或统计饱和的结果。
- **多步。** 精确枚举两种等概率的合法失败反馈，各自可再重试或切换。与初始直接切换、同失败位恒定动作及无信息对照比较。手算验收为 37/20 对 2，所有列入的策略最终完成。无信息格应无增益。读取当前反馈的简单规则若达到最优，则不支持复杂方法。
- 云端运行既有防泄漏及扩展测试，结果使用新的 `results/<run_id>/`。记录提交、种子、版本、完整轨迹和分组费用。模型、诊断费和正确停止率按配置记录为不适用或零。

## 结果

运行提交 `e91cdde`，云端目录 `results/013-gate11-minimal-01/`。12 项测试通过，包括 5 项既有隔离、4 项 MVP 回归和 3 项新增专项。回归保持 192 条训练轨迹和 144 个留出起点。三个上下文的三类续程均有样本且严格完成率为 1，最小分母为 8。重算与上下文阈值及上下文版 One-bit Memory 在 144 个起点首动作完全一致，无覆盖回退。失败重试的续程规则相同。

**同键审计。** Gate 1 存档有 65 个跨任务的原生工具／错误键，其中 49 个工具／错误／切换入口组合也跨任务；Gate 6 有 3 个工具／错误键，均出自 C3-002/003。按 Gate 3 可复用队列与扩展统一错误，只有 020/027 同时共享切换入口，仍同组。原生候选中，019/089 共享 `generate_invoice_from_cart`、`Resource Temporarily Locked` 和 `get_cart_summary`，025/026 共享 `generate_invoice_for_best_recommendation`、`Gateway Timeout` 和 `hold_best_recommendation`。两组的任务模板哈希和外围依赖序列均不同，现有 P1 的重试和切换均过原生评分。它们仍共享恢复子结构；089/026 尚在 Gate 3 注册队列外，缺扩展严格完成、参数来源与分组验收。因此记录为待准入候选，未执行同键训练／测试或声称统计量造成决策差异。完整 BTM 未验证。

**多步理论。** 两种反馈下选择不同动作，预期费用为 37/20，忽略反馈的最优常量规则和初始直接切换均为 2。无信息对照的四个映射全部为 2。直接读当前错误的阈值达到该理论最优，因此当前证据只确认构造中的执行反馈价值。未开发多步环境。

**判断。** 修正通过工程验收，复杂方法开发仍为 No-Go。同键比较等待独立家族和严格回放验收。
