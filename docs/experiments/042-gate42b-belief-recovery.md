# 实验 042 · Gate 42B：信念感知恢复（CPU Autoresearch）

2026-11-13，探索性、仅 CPU。用户授权在 `research/decision-recovery-autoresearch` 上继续，通过 PR 提交。不运行 LLM/GPU/API，不改已冻结结果与 main，不改评分定义。Q2 科学问题不变。本文先登记，再追加结果。

**读数须知。** 所有数值都是 CPU 环境模型内的参照。真实 LLM 的动作遵从、参数绑定、续程成功和推理成本均未知，CPU 上的任何优势都不等于 Agent 上的优势。

## 1. 承接的负结果

- 实验 040：成本余量有上界；严格“先比完成率”在完成率需要估计时不收敛。
- 实验 041：多路径下上下文余量的典型值仍是个位数；逐节点的频率估计分不清“完成率真的相同”与“只差一点”，宽松的比较规则丢完成率，保守的省不下钱；在深的树上，所有逐节点方法都因为缺支持而丢完成率，1000 条历史以内不如一条不需要历史的固定顺序；混杂、迁移、缺支持时比较规则无能为力。
- Bench2Robust 拆解：它的随机错误按构造必为暂态，按“连续失败次数”封顶，这种依赖事件计数的规律不是一个小的隐藏状态模型能准确表达的，正好用作结构设错的对照。

本轮只问一件事：把“隐藏状态”显式地放进估计，能不能解决上面两个由逐节点估计造成的问题（结构性并列、深处缺支持），以及它在什么条件下反而更差。不新增 Benchmark 格。

## 2. 模型与数学假设

代码 `extensions/toolmaze_recovery/belief.py`，建在实验 041 的进度图上。

**模型。** K 个隐藏状态的隐马尔可夫模型，参数为：每个公开上下文 $x$ 的初始分布 $\pi_x(z)$；每个（状态, 工具）的结果分布 $\theta_{z,a}(o)$，结果是成功、各种失败细节或诊断信号；每次调用之后生效的转移矩阵 $T(z'\mid z)$。信念更新为
$$b_{t+1}(z')\ \propto\ \sum_z b_t(z)\,\theta_{z,a_t}(o_{t+1})\,T(z'\mid z),\qquad b_0=\pi_x .$$
转移与动作无关，这是最小的写法；$T$ 取单位阵就是静态的潜在类别模型。

**训练只用什么。** 日志里每个回合的公开上下文、调用了哪个工具、得到什么反馈。EM 的充分统计量是“（上下文, 工具与结果的序列）出现了几次”。它读不到生成器的隐藏状态、真实成功率与转移，也读不到测试回合的结局；单元测试用一个不含生成器的空格重新拟合，得到逐位相同的模型。伪计数固定为：结果与初始分布各 0.1，停留在原状态 2.0，离开 0.05。每个 K 取两个随机初值中似然较高者。

**规划。** 把拟合出的模型当作一个环境，用实验 041 的精确求解器在公开进度图、当前任务报价和调用预算下求字典序最优。模型参数是浮点数，完成率相差不到 $10^{-9}$ 视为同一个数；这只是数值精度，不是评分上的容差。

**隐状态何时可识别。**

1. 模型是“给定状态后各次调用条件独立”的混合。这类混合一般需要同一回合里至少三次有信息的观测才可识别。因此日志里必须有相当比例的回合打了三次以上、且涉及不同工具或同一工具的重复调用。
2. 状态只能识别到重新编号为止，并且只能通过日志里出现过的工具来区分。在所有已记录工具上表现相同的两个状态会被合并；这对已记录工具的预测无害，对从未记录的工具则没有任何信息。
3. 多个上下文共享同一组 $\theta$、只有 $\pi_x$ 不同，等于多了几组约束，有助于识别。
4. 转移只能从同一回合内的多次调用里识别。
5. 日志策略若依赖隐藏状态（混杂），忽略日志策略的似然就是错的，模型不可识别。

不可识别无法直接观察，只能看它的后果，所以用下面的检查代替。

**跨工具、跨路径怎样共享统计。** $\theta_{z,a}$ 在所有节点上是同一组参数。工具 A 的一次失败改变对状态的信念，从而改变对工具 B 的预测，即使“先 A 失败再调 B”这个节点在日志里一次也没出现过。这是它与逐节点频率的根本区别。

**未尝试的动作怎样估计，何时回退。** 某个节点上没试过的工具，只要该工具在日志别处被调用过至少 5 次，就按当前信念给出预测。调用不足 5 次的工具没有可用的结果分布，不进入规划。模型没有给出计划的历史（模型认为不可能的反馈），以及模型被下面的检查否决时，回退到逐节点 ACV（容差 0.05）。

**怎样防止结构设错时的错误自信。** 三道闸，阈值全部事先固定、不调：

- 预测性检查：在每个被调用至少 30 次的日志节点上，模型给出的成功率与观测频率之差不得超过 $4\sqrt{p(1-p)/n+10^{-4}}$。任何一个节点不满足，整个模型弃用，回退。
- 状态数用 BIC 在 1–5 里选（记作 auto）。
- 转移矩阵带偏向“停留”的先验，数据不足时退化为静态模型。

**诊断。** 诊断信号是“诊断”这个动作的结果分布。买不买诊断由规划自己决定：信号改变信念，信念改变后续动作，净价值为正才会买。

## 3. 比较对象与指标

全部在同一份日志上拟合，历史种子 5000–5099，随机日志（每个节点对合法的非停止动作等概率），N∈{30,100,300,1000,3000}，小 N 是大 N 的前缀。

| 对象 | 说明 |
| --- | --- |
| `acv_strict`、`acv_tol0.05` | 实验 041 的逐节点规划器，严格字典序与固定容差 0.05，原样保留 |
| `learned_context_order` | 同一份历史上最强的简单规则：每个上下文从“工具的全部有序子集 × 失败上限 1 或 2”里按估计值选一条固定顺序（容差 0.05） |
| `belief_auto` | 隐藏状态模型，K 由 BIC 选，带预测性检查 |
| `belief_trueK`、`belief_K-1`、`belief_K+1` | K 取生成器的真实状态数及其加减一（真实状态数是我知道而方法不知道的，仅作消融） |
| `belief_static` | 真实状态数，但不许转移 |
| `belief_auto_noguard` | 同 `belief_auto`，去掉预测性检查 |
| 公共最优、不读上下文的最优 | 知道生成律的精确参照，不参与排名 |

指标沿用实验 041：平均严格完成率、平均剩余费用、达到公共最优的种子数、实质性落后的种子数（完成率低 5 个百分点以上，或相差不到 5 个百分点而费用高 5% 以上；这条线仍是待确认的建议值，只用来计数，不代表 5 个百分点的损失是可接受的）、错误首动作与实质错误首动作、策略对自己所选动作的完成率估计与真实值之差（偏差与绝对误差）。评分定义不变。

## 4. 轮次与登记的假设

格全部沿用已有的：M5（三条互斥路径加阻断）、M3（预算 8，三条路径带再次故障）、S4b（含“一次调用后恢复”的共享故障）、E 与 E 的无信息对照（付费诊断）、B2R-mini（第四阶段混合，事件计数式的噪声）。

- **c1 主比较**：六个格，全部对象。
- **c2 覆盖**：M5 与 M3，只有 30% 或 10% 的日志步骤随机，其余按合同顺序；N∈{300, 3000}，60 个种子。
- **c3 负对照**：混杂日志（K 格，日志者看得到隐藏状态）与同样条数的随机日志；分布迁移（在暂态概率 0.9 的历史上学，测试 0.9、0.3、0.1）；N=1000，60 个种子。

| 假设 | 内容 | 被否定的条件 |
| --- | --- | --- |
| H1 结构性并列 | M5 上 `belief_trueK` 在 N=300 时平均费用不高于 3.47（最优 3.4 的 2%）、完成率不低于 0.895；两个 ACV 在 N=3000 时平均费用仍不低于 3.6 | 任一数值不符 |
| H2 对强简单规则 | M5 与 M3 上 N≥300 时 `belief_auto` 的平均费用低于 `learned_context_order`，完成率不低 0.5 个百分点以上；S4b 上 N=3000 时两者费用相差不超过 1% | 任一格、任一 N 不符 |
| H3 深处缺支持 | M3 上 `belief_auto` 在 N=300 时平均完成率不低于 0.99（实验 041 里逐节点方法为 0.905） | 低于 0.99 |
| H4 结构设错 | B2R-mini 上 N=3000 时预测性检查否决模型的种子不少于一半；去掉检查的版本实质性落后的种子多于 `acv_tol0.05` | 任一条不符 |
| H5 状态数 | M5 与 M3 上 N=3000 时，K−1 比真实 K 多出至少 20 个实质性落后的种子，或被检查否决；K+1 与真实 K 相差不超过 5 个种子；M5、M3、S4b 上 N≥1000 时 BIC 选到不小于真实 K 的种子不少于 80% | 任一条不符 |
| H6 诊断 | E 上 `belief_auto` 在 N=300 时平均费用不高于 3.74（最优 3.7；实验 040 里 ACV 为 3.754）；无信息对照上不高于 4.01（最优 4.0；ACV 为 4.025） | 任一数值不符 |
| H7 负对照 | 混杂日志下 `belief_auto` 至少 95% 的种子选重试（费用 4.4）；迁移到 0.3、0.1 时费用为 4.4、4.8，与 ACV 相同 | 信念模型明显好于 ACV |
| H8 覆盖 | M5 上只有 10% 的步骤随机、N=3000 时，`belief_auto` 的平均费用在最优的 3% 以内、完成率不低 0.5 个百分点；`acv_tol0.05` 做不到 | 任一条不符 |
| H9 转移 | S4b 上 N≥1000 时 `belief_static` 被检查否决的种子不少于 80%；`belief_trueK` 被否决的不超过 20%，N=3000 时平均费用在最优的 2% 以内 | 任一条不符 |

竞争解释：EM 有局部最优，小样本下模型不稳，可能在 N=30–100 时比 ACV 更差；BIC 在小样本下可能选少状态；预测性检查的阈值可能过松（放过设错的模型）或过严（否决正确的模型，白白回退）；M5 的最优本来就是“每个上下文一条固定顺序”，同历史学出的简单规则在数据足够时也能达到，信念模型的优势可能只在样本效率上；在两个工具的浅格上，隐藏状态模型可能没有任何用处。
