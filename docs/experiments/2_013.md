# 2_013 · 异名字段判边开发验证
基线 011afc5。覆盖 2_012 的全部 13 种异名引用。以每对来源工具和消费参数为开发查询，候选取该来源所有可直接传递的公开 MCP 输出字段，标明整数到 number 的安全放宽；数组包装与其他转换分列。此查询已给出来源和目标，不衡量工具发现。规则与作者分类器共用逐字段候选；不使用路径、任务答案或来源真值排序。离线评测把目录边、轨迹同值见证、同类型竞争字段分别记录，未列出的边不能一概当假。公开合同欠定允许 unknown。规则用本地冻结 MiniLM 编码字段、说明、工具上下文，词元重叠作为另一语义线索；平分/弱证据允许弃选。报告候选覆盖、首次选择、错接和弃选、计算时间及 Token。固定顺序，不按方法结果抽样。
GPU 待批：固定本地模型和作者零样本分类入口，最多 48 请求、30 分钟、6144 输出 Token/请求，超限未测，空响应保留。独立 Agent 尚不运行。外部环境优先查可执行状态评分、与上游训练/图目录重合、故障注入和备用路线可证明性。

已获开发判边 GPU 授权。固定规则权重为 MiniLM 余弦 0.75、源字段词元在目标合同内的覆盖率 0.25；最高分低于 0.45 或领先不足 0.05 时弃选。分类器结果和无公开证据的评测标签分别保存。按源、目标、参数、字段字典序运行，保留原始响应和预算内未完成项。

## 开发结果

LabServer 的 2_013-edge-01 正常退出。13 个查询共 41 个类型兼容候选，逐行键、顺序和模型响应已核对。11 个有轨迹同值见证的目录边中，7 个进入候选；其余为三条未声明 final_total、一条需要单元素列表包装的 email。对这 7 个可覆盖查询，强规则唯一命中目录字段 3 个、弃选 2 个、另选字段 2 个；作者判边保留 strong 或 weak 时包含目录字段 7 个，仅 3 个唯一保留目录字段。不能把集合召回与规则首选当作同一准确率。另两个缺见证的告警查询，业务意图欠定，保留 unknown。逐项结果、Token 与原始哈希见[派生证据](../evidence/2_013/comparison.json)。

两条未选目录字段的规则中，会议提醒选 title 有真实角色错误风险；预留的 product_id 则来自选中推荐商品，与 recommended_product_id 可能同值，不按业务错误计。还需对同值字段互换、原商品与推荐商品不同时的错绑做实际状态核查。自动图能缩小日期与商品标识候选但仍混淆起止、原商品与推荐商品。下一步用同候选同预算的任务条件选择与简单执行校验做已见机制试验。独立环境优先 AppWorld 原生数据库及状态评分；须筛除作者 AppWorld 样本重合，隔离任务族并实际证明屏蔽入口后还有合法续程。现阶段未认证独立任务或取得新 Agent 完成率。冻结 M4 使用无类型输出说明；共享类型候选目前只在 2_013 公开 MCP 输出合同入口运行，M4 在线接线待验证。
