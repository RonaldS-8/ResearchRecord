# ADR-0023 · 真实 Agent 的恢复效率对照

日期为 2026-11-10。范围为一轮 LabServer 小规模 Qwen 配对试点，先冻结后验收。Gate 22 的 CPU 方法判定与归档独立保留。Gate 23 检验相同模型与执行接口下，两种统计表示能否改变真实 Agent 的严格恢复及调用开销。见[实验 025](../experiments/025-agent-efficiency.md)。

## 公平对照

保持 Q2 与诊断定义。BTM 使用训练行为策略下按工具／错误或观察到的切换分组的最终回合成功后验。Action-Conditioned Memory 使用从当前合法历史强制首动作、沿冻结续程计算的 $Q^\pi(h,a)$，分列严格完成概率、期望工具费和诊断费。复用 Gate 22 的训练统计、参数和局部阈值续程，按合法回执更新当前估值。历史观察与受控动作效果分开。

无历史、BTM、Memory 三组共用系统提示、动作枚举、解码和原执行器。混合组仅换为 Gate 19 的指定证据抽取函数，校验回执后由同一动作价值选路。六个模型组均由同一个 Gate 22 绑定器执行。独立参考为 BTM 加先重试提示及附录 B.1 完整结构的任务合同复现。完整复现包含历史后验、替代路径、选择指引及恢复约束。先重试只在该动作合法时适用。价格由公开报价给出，没有额外计算工具；升级由停止表示，合法停止判据不变。论文方法为提示复现。[Bench2Robust 附录 B.1](https://arxiv.org/html/2608.11977v2#A2.SS1)

## 执行与计价

新增 Gate 23 入口、配置、专项测试。复用 Gate 19 请求解析与回执协议、Gate 22 的公开合同和双账本。模型调用沿用原本地 vLLM 模型及参数。保留逐臂、逐任务轨迹、失败、Token、延迟和实参来源。模型实际 Token 按冻结 API 参考费率估值，环境模拟单位单列。只有在显式声明每个模拟费用单位的美元映射时，才计算端到端美元情景及盈亏平衡。
