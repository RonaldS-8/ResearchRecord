# ADR-0012 · 同键任务与多步恢复反馈

- 日期：2026-11-07
- 状态：按用户授权实施最小实验

Gate 12 保留原生审计。019/089 的共享键只在本次核对的 P1 成立，且重试在两任务均更省。026 的原生通过轨迹有不能从可见历史解析的参数。原生候选不足以独立检验同键下的动态反馈和动作反转。

扩展内新增两个合成家族，分别派送包裹、登记发票。二者共享提交服务及首错键，准备流程、参数来源和最终写入效果各自独立。用现有公开视图回调、分数、费用分项和 Gate 11 的两次重试机制。首错固定，首次重试失败时由实际执行返回带噪错误细节，之后可再重试一次或走两调用的备用路径。故障机制只进入扩展。用独立状态与轨迹检查器核验依赖、最终效果及逐调用账本。

只运行规则和精确配对，无模型训练或推理。参数、分组及判据见[实验 014](../experiments/014-recovery-benchmark-extension.md)。简单规则达到同等结果时保留证据，停止复杂方法开发。
