# ADR-0021 · 多路径依赖与关联故障下的恢复决策

状态为已批准。Gate 21 的首批范围为 LabServer 上的 CPU 机制试验。Qwen3-4B Agent 配对须另行批准。沿用 Q2、显式诊断定义及 Gate 19 的严格完成与分项计价。设计依据为 Gate 20 对 Gate 19 结果的机制审计。冻结矩阵与放行判据见[实验 023](../experiments/023-multipath-recovery.md)。

## 执行合同

合法准备后，从共同的 A 报错进入恢复。该报错由交接夹具固定，不提供当前网关状态的额外证据。任务仍是获取凭据并登记，成功回执决定当前能执行的下一步。恢复段每条获取路径至多尝试一次，成功后进入该凭据的登记路径。登记效果必须与原任务及绑定凭据一致。

| 恢复动作 | 工具费 | 成功回执与下一步 |
|---|---:|---|
| 重试 A | 0.40 | 标准凭据，可直接调用原生登记 |
| 切换 B | 1.20 | 标准凭据可直接登记，短作用域凭据只允许先验证再登记 |
| 切换 C | 2.00 | 外部凭据，只允许外部登记 |
| 验证短作用域凭据 | 2.00 | 返回同一请求的标准凭据 |
| 原生或外部登记 | 各 0.40 | 校验对应凭据后提交，产生严格完成证据 |

获取失败照计费，不产生凭据，其他未尝试的获取路径仍可用。主矩阵各组有五次执行额度，覆盖三次获取、一次验证和一次登记。验证与登记在合法绑定后确定成功，用于隔离由上游动作造成的下游差异。获取阶段可在任意决策点购买一次显式诊断，诊断费 0.05，额度独立。停止免费。只有三条获取路径都经合法反馈证实失败后主动停止，才计正确停止。剩余执行额度不足完成公开合同下的最短可行续程时记预算耗尽，其他可继续时的主动退出记过早停止。动态回执、工具费和诊断费分别记录。

**可观察信息。** 策略共享任务、接口能力与可能的凭据类型、报价、当前可用动作、剩余预算、既有错误及合法回执。A、B 的成功率可随未观察的网关状态关联变化，C 有独立失败风险。诊断返回关于 A 所在网关的噪声信号。运行中的网关状态、故障关联参数、各动作抽样结果和 B 的凭据类型在揭示前均由环境持有。诊断准确率作为公共接口合同，B 的凭据类型概率从训练数据估计。

## 估值与公平比较

BTM 估计训练行为策略下的 $P(Y=1\mid\text{工具错误})$ 及 $P(Y=1\mid\text{观察到的切换})$，其中 $Y$ 表示回合最终严格完成。沿用同一回合只计一次同键、Beta 平滑和支持数。动作条件价值保留 $Q^\pi(h,a)=(P_\pi(Y=1\mid h,\mathrm{do}(a)),\mathbb E_\pi[C_{\mathrm{tool}}\mid h,\mathrm{do}(a)],\mathbb E_\pi[C_{\mathrm{diag}}\mid h,\mathrm{do}(a)])$。每次从同一个合法历史 $h$ 强制首动作 $a$，再用统一续程 $\pi$。比较先看严格完成概率，等概率时比较工具和诊断总费用，报告仍分项。历史拟合与受控回放分开；完整前瞻另与固定续程比较。

CPU 试验报告任务级统计和动作条件值，并运行明示为代理的确定性选路。后续 Agent 对照复用 Gate 19 的共同提示、合法动作枚举和绑定协议，只更换历史表示，完整 BTM 提示复现沿用既有参考口径。Oracle 使用环境真值，只作为同一动作、合同、预算下的上界。生成参数已知、状态仍隐藏的策略另列。
