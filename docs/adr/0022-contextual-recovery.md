# ADR-0022 · 任务上下文与历史证据驱动的恢复

日期为 2026-11-10。状态为已批准。Gate 21 的完整机制格仍可由固定 A→C→B 覆盖。本轮检验同一个 A 错误下，公开任务需求和较早的合法反馈是否改变恢复动作，以及强简单规则能否解释全部差距。范围为 LabServer 上的小规模 CPU 试验。见[实验 023](../experiments/023-multipath-recovery.md)及[实验 024](../experiments/024-contextual-recovery.md)。

## 执行合同

- 复用 A/B/C、凭据验证及登记。两类需求在每个任务家族内交叉出现。标准登记时 B 返回可直接登记的凭据；跨域登记时 B 可能返回短作用域凭据，必须先验证。C 仍走外部登记，A 仍走原生登记。是否需验证只由合法回执揭示，实际提交必须包含请求的登记范围。
- 现有准备回执带一条噪声质量反馈，模拟准备路径是否命中健康网关的缓存。它不新增工具、不消耗恢复预算，也不进入执行实参。共同首错由原夹具给出。恢复段 A 的实际失败是随后可合法观察的另一条证据。共享故障下，二者都更新对 B 的判断。C 保持独立。任务、质量反馈及其校准、合法菜单、工具报价和已发生的执行反馈对所有策略公开。网关状态、凭据类型抽样、未来成功与诊断结果只由环境持有。
- 复用 Gate 21 的五次执行额度和费用。A/B/C 分别为 0.40／1.20／2.00，验证为 2.00，登记为 0.40。获取阶段可另买一次 0.05 的诊断，其噪声与准备反馈在给定网关状态后独立。严格完成、正确停止、过早退出、预算耗尽和两类账本沿用 Gate 21。无需新增费用项。

## 估值与对照

保留 Q2 与诊断定义。BTM 提供训练策略观察到工具错误后最终恢复的 $P(Y=1\mid\text{工具},\text{错误})$，以及 Gate 19 复现口径下的观察性切换统计。$Q^\pi(h,a)$ 比较同一合法历史 $h$ 下强制动作 $a$、再按同一续程 $\pi$ 执行的严格完成概率与期望工具费、诊断费。先比完成概率，同完成率时比较两项总费用，报告仍分项。任务需求决定凭据续程，公开反馈决定条件故障信念。历史观察估计与同起点受控效果分别记录。

固定顺序和按任务需求选择的固定规则均用独立验证集择优。最近反馈、完整历史成本阈值和单次探针规则均可使用公共任务合同及同源估计。完整历史阈值可以直接利用验证费用。若它或其他强规则逐动作复现规划，本轮保留反例并判方法 No-Go。Oracle 和已知生成参数但状态隐藏的参照独立报告。

## 必要工程改动

在 Gate 21 执行器中增加可选准备回执和任务范围，保持原默认视图、绑定、计价和终态。复用原随机键，新增一个准备反馈噪声键。沿用 Gate 21 的条件似然、动作价值、排序、基线和汇总，仅扩展公开证据与支持数分层。Gate 22 入口及配置负责两类合同、独立划分、配对和精确反例。专项测试核验凭据范围、绑定、防泄漏与反例。复用 Gate 19–21 的旧测试，原冻结配置与归档保持原版本。
