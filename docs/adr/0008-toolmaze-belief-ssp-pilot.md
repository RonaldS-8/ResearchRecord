# ADR-0008 · ToolMaze 独立恢复原型

- 日期 2026-11-06
- 状态：最小原型有条件批准，范围限 C2-018。科研扩展另行决策。

## 决策

固定 Gate 3 已核对的 C2-018、`path_0` 首错起点和替代路径。独立扩展仅包含尝试驱动的随机持续性、部分可观测反馈及付费诊断、异质工具成本。原生 ToolMaze 数据、扰动和评分保持原样。原生 P1/P2 结果继续单列。状态、事件顺序和参数矩阵见[实验 010](../experiments/010-gate7-belief-ssp-pilot.md)。

可信执行侧复用 Gate 3 的模板绑定、实际工具调用、有效中间结果及独立参数验证。扩展故障覆盖受影响节点，其他调用使用原生无扰动执行。用原生 P0 完成检查与独立依赖检查联合验收。失败返回不能写入可复用结果。策略只能读取公共历史、动作、价格、模型参数和预算。知情参照独立读取隐藏状态。

## 放行

第一层只验收单任务环境、回放、隔离、评分、计费和精确枚举。第二层根据预登记的稳健差距决定是否提议扩任务或正式开发方法。首层通过不授予第二层执行范围。

拟增 `extensions/toolmaze_belief_ssp/` 和必要的专属测试，沿用现有云端环境和依赖。运行前提交预登记，云端执行并保存完整证据。现有模型、原生基准和全局计价保持原样。
