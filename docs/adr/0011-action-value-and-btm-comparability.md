# ADR-0011 · 动作价值估计与 BTM 可比性

- 日期：2026-11-07
- 状态：已批准，限动作价值修正、同键审计与多步理论验证

## 1. 动作价值按当前任务报价重算

Gate 10 的直接动作价值规则迁移训练任务的平均费用，在两组均高于上下文阈值。Gate 11 保留该结果，另加动作结局重估。用随机分配的训练轨迹估计首重试成功率 p，并区分直接切换后的严格完成率 qS、重试成功后续程的 qR、重试失败后切换的 qRS。记录各分支的训练分母；只从实际进入相应分支的轨迹统计 qRS，不能用直接切换样本代填。无覆盖时标记证据不足，使用预登记的回退规则。

对固定后续策略，直接切换的价值为 (qS, S)，先重试的价值为 (p qR + (1−p) qRS, p R + (1−p)(F+S))。R、F、S 分别为当前任务公开的重试成功续程包总报价、失败重试报价和切换报价。此费用式要求分支内价格固定；若实际执行可能提前终止，按可观测终止分支分别计价再加权，失败费用照计。评估从首错后计费，严格完成率与费用分列。

以相同历史、平滑、预算、平局规则及报价比较修正版与上下文阈值。若三个续程均合法必成，完成概率相同，比较式与 Gate 10 的上下文阈值完全等价。这是必须通过的回归验收。稀疏样本中独立估计的概率差异另报分母，不能据此认定真实续程机制不同。

## 2. 同键样本与统计对照

只读核对发现，020/027 的失败工具均为 `generate_invoice_with_best_discount`，共享扩展的统一报错，切换入口均为 `get_available_coupons`。模板哈希不同，但共享恢复子结构，继续放在同一组。Gate 6 的 C3-002/003 也共享银行工具与报错，可作独立性核对的候选，尚无跨家族证据。

先在已有候选中按任务目标、参数来源、分支依赖图和规范化模板指纹核对家族。最低验收为同一工具／原始错误键有一个独立训练家族和一个独立留出家族，两臂均有覆盖；切换统计的比较另要求来源与目标工具键均有训练覆盖。若现有候选不足，报告缺口。另行审核后才考虑合成两条共享公开 API 契约、但目标和剩余依赖不同的独立工作流，并单列合成证据。

冻结分组、两臂采样、种子和规则。一个任务的种子、报价、故障变体和反事实分支不得跨组。训练/测试使用独立随机流；评估策略仅收到公开视图与冻结的训练摘要。测试结局、生成概率、模板标识、配对分支和真值留在评估侧。控制相同报价的检查点，以区分由统计信息改变的动作与价格驱动的动作差异。

统计对照按同一历史分别提供任务回合完成后验、加来源→目标切换后验、加上下文动作经验。统计版本使用同一预登记选择规则与静态工具信息，单列固定规则、无历史公开成本阈值和上下文版 One-bit Memory。若任务率与切换率饱和，报告其动作区分能力及负结果。任务完成率与观察到的切换后完成率均不能直接代替首重试成功率；缺少可用映射时单列公开成本回退及覆盖率。

**完整 BTM** 另作固定权重模型基线。优先使用作者实现；当前未定位到可核验公开实现。后续若依论文提示复现，须明确来源与偏差，保留静态替代工具、粒度、验证和至少重试一次等约束，冻结训练后验；若审核运行在线版，单列顺序和回合后更新。统计对照、提示复现和作者实现分别标记。本阶段完整 BTM 未验证。[Bench2Robust §3.1 与附录 B.1](https://arxiv.org/html/2608.11977v2#S3.SS1)

## 3. 多步反馈的最小可证伪检查

Gate 9–10 的失败重试后只剩切换或停止。先验算一个独立反例。两个回合初始上下文相同，首次重试均失败，失败位同为 1；失败调用合法返回两种有噪声的错误细节。两种细节在失败条件下等概率，分别令第二次重试成功率为 0.8 和 0.2。第二次重试计 1、失败后切换计 2，直接切换计 2，均能最终完成。因此两种反馈后的最优动作分别是重试和切换，失败节点的平均最优费用为 1.7，固定单动作的最优费用为 2。

为排除“最初直接切换就更好”，在手算格中令首重试费用为 1、成功率 1/2，成功即完成。首重试后使用反馈的全程期望费用为 1.85；始终只用失败位的最佳费用为 2。参数仅用于验证机制。加入无信息对照，并与读取当前错误的简单阈值及可读当前反馈的 One-bit Memory 比较。若简单规则持平，则只确认执行反馈有价值。真实可执行任务仍需核对第二次重试的合法性、依赖、报价、严格评分和返回是否泄漏真值。

工程 Go 要求严格完成、隔离、账单及等价回归通过；同键 Go 另要求实际训练覆盖，且在留出配对中能核对动作差异、完成率与实际恢复费用。报告首动作和后续动作分歧、分母、逐家族配对差值及固定规则表现。缺乏同键独立样本记为证据不足；若结果持平、费用无改善或最强简单规则已覆盖收益，保留结果并停止据此开发复杂方法。运行仅在云端，登记提交、配置、种子和完整轨迹，已有负结果独立保存。
