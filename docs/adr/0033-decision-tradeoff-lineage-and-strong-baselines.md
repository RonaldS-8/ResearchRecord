# ADR-0033 · 有决策权衡的恢复谱系与强基线冻结设计

- 日期：2026-11-12
- 状态：提议。设计草案，待用户审批；本 ADR 不授权实现新 Benchmark、估值算法或任何模型运行
- 详细设计：[实验 037](../experiments/037-decision-tradeoff-lineage-design.md)

Gate 34。Q2、诊断定义与 $Q^\pi(h,a)$ 沿用 AGENTS.md，统一研究设计沿用 [ADR-0024](0024-agent-recovery-research-design.md)。用户 2026-11-12 授权起草，范围限于设计。

## 背景与问题

Gate 33 说明执行链路可用：强制模型重新预留后，它能填对参数并自主完成（[实验 035](../experiments/035-advice-enforcement-and-assignment.md)）。但那条写入谱系上“查询无记录就重写”永远正确，手写规则必然满分，对动作价值方法没有余量。同时，Gate 17–23 在受控合同和小样本上多次得到同一个负结果：固定顺序或最近反馈规则覆盖了主要收益（[实验 026](../experiments/026-agent-recovery-benchmark-audit.md) 的汇总）。

所以下一步的问题不是“再证明一次方法能跑”，而是：

> 在合法公开信息不足以直接确定恢复状态、但历史统计与公开成本可以支持决策的场景中，简单规则、完整 BTM 与动作条件价值之间，是否存在可检验的完成率或成本差异？

两种结局都算结果。有差异，继续做方法；没有差异，按证据收缩方法线，把规则与 BTM 的适用边界作为结论。

## 决策

**1. 换到有重试与切换权衡的读取故障谱系。** 首次错误的公开回执相同，最优首动作取决于重试成功率 $p$ 与当前公开报价。$p$ 不是任何策略都读不到的隐藏量：它由登记的隐藏状态分布决定，可以从合法训练观测、公开上下文或付费诊断中估计。写入谱系与发布任务继续留在开发侧。

**2. 三个量分开定义、分开估计、分开报告。**

- $p(h)=P(\text{重试成功}\mid h)$：由登记分布决定，只能从合法训练观测估计。
- $Q^\pi(h,a)$：实际执行动作 $a$、之后按续程 $\pi$ 走完时的严格完成概率与期望剩余成本，二元组，不合并。
- 显式诊断的净价值：新增诊断信息改变后续动作所带来的收益减去诊断费。

不用隐藏真值填充任何估值。一次强制执行的结果是一次观察，不是概率估计；每个估值都带样本数与支持度。

**3. 信息来源与落实方式是两个独立的实验维度。** 信息来源分四层：不用历史、只用当前公开报价、任务级恢复统计（完整 BTM）、按动作的统计。落实方式分两种：作为上下文或建议交给模型，或由控制器强制工具选择。所有方法共用同一个历史池、同一份工具说明、报价、合法反馈、预算与评分。

**4. 信息分层只用于消融，正式比较必须包含同信息的强基线。** 在“按动作的统计”这一层放两个决策器：

- 阈值决策器：用同样的 $\hat p(h)$ 和当前报价，按闭式条件 $\hat p>\frac{F}{S+F-R}$ 选择重试或切换。
- 我们的方法：对每个合法动作估计 $Q^\pi(h,a)$ 二元组，含诊断与停止，带支持度与回退。

由此把结论拆成两级。阈值决策器胜过前三层的最强者，只能说“动作条件统计量有用”，这是信息优势。我们的方法再胜过阈值决策器，才能说建模有贡献。只有第一级成立时，论文表述为统计量加简单阈值，不开发复杂估计器。

**5. 完整 BTM 按原方法的形式进入。** BTM 向模型提供恢复统计、备用关系、返回粒度与恢复约束，由模型自己选动作，因此它的原版只出现在“建议”一侧。强制一侧若需要 BTM 的对应物，单列为“BTM 衍生选择器”，注明不是原方法复现。复现以论文原文为据，注明来源与偏差；论文报告的数字不作为对照。

**6. 规则在新谱系运行之前冻结。** 冻结的是通用决策逻辑与阈值选择方式，在验证集上选定；新家族只按预先写明的方式适配公开工具合同。规则可以使用模型拥有的全部公开知识，不故意削弱。

**7. 历史用随机分配的首动作采集。** 在首错检查点按登记概率分配合法首动作并记录概率，用 Gate 33 的工具级干预落实，之后按固定续程走完。这样估计的是干预效果，不是模型自选动作的相关性。强制请求是工具级干预，不等同于模型自然选中该动作。

**8. 谱系按机制预登记，不按方法表现选题。** 同时保留简单规则本来就够用的格子、只有报价变化的格子、任务级恢复率相同而 $p$ 不同的格子、完成率不等的格子、诊断值得买与不值得买的格子，以及不可恢复格子。按基础任务、共享实现与故障事件谱系划分训练、验证与确认性留出；确认性留出在冻结前不运行任何候选方法。

## 备选与取舍

- **继续在写入谱系上扩样本。** 放弃：正确动作由一条回执唯一确定，不回答新的问题。
- **只做信息分层比较。** 放弃：我们的方法若只因多拿到按动作的统计而胜出，收益来自信息而不是建模。
- **把 BTM 做成强制选路器再比。** 放弃作为主对照：改变了原方法，只保留为标注清楚的变体。
- **让隐藏状态完全不可估计。** 放弃：任何方法都无从决策，比较没有意义。
- **先实现贝叶斯预测器或规划器。** 暂缓：在余量被独立样本证实之前不投入。

代价：需要新建带公开上下文、可变报价、登记分布与不完美诊断的任务家族，并采集有随机分配的真实 Agent 历史，工作量明显大于此前各 Gate。

## 验证与边界

本 ADR 只冻结设计原则。分阶段的放行与止损标准见实验 037，要点是：

- Benchmark 实现后先做 CPU 精确核算，确认登记分布下各机制格的理论余量与设计一致，再运行真实 Agent。
- 在独立探索样本上比较真实 Agent、验证集最强简单规则与知情参照。若最强简单规则在所有机制格上都在最小实质差异之内，方法线收缩。
- 阈值决策器与我们的方法持平时，不声称算法创新。

未决事项需用户确认：共同提示（等实验 036 退出措辞对照的结果，该登记在另一个 PR 中）、正式比较采用哪种落实方式作主表、历史采集所用的续程策略、最小实质差异与样本量、计价口径（`docs/metrics.md` 仍是草案）。撤回方式：本 ADR 未被批准前不产生任何代码或运行；批准后若止损条件触发，状态改为相应结论并保留全部记录。
