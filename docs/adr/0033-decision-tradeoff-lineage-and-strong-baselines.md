# ADR-0033 · 有决策权衡的恢复谱系与强基线冻结设计

- 日期：2026-11-12
- 状态：提议。设计草案，待用户审批；本 ADR 不授权实现新 Benchmark、估值算法或任何模型运行
- 详细设计：[实验 037](../experiments/037-decision-tradeoff-lineage-design.md)

Gate 34。Q2、诊断定义与 $Q^\pi(h,a)$ 沿用 AGENTS.md，统一研究设计沿用 [ADR-0024](0024-agent-recovery-research-design.md)。用户 2026-11-12 授权起草，范围限于设计。

2026-11-12 修订：初稿把“同样按动作统计加字典序选择的强规则”列为外部基线。按用户同日的决定，它改归我们的方法并记为 M0，决策 3–5 相应重写；状态仍为提议。

## 背景与问题

Gate 33 说明执行链路可用：强制模型重新预留后，它能填对参数并自主完成（[实验 035](../experiments/035-advice-enforcement-and-assignment.md)）。但那条写入谱系上“查询无记录就重写”永远正确，手写规则必然满分，对动作价值方法没有余量。同时，Gate 17–23 在受控合同和小样本上多次得到同一个负结果：固定顺序或最近反馈规则覆盖了主要收益（[实验 026](../experiments/026-agent-recovery-benchmark-audit.md) 的汇总）。

所以下一步的问题不是“再证明一次方法能跑”，而是：

> 在合法公开信息不足以直接确定恢复状态、但历史统计与公开成本可以支持决策的场景中，简单规则、完整 BTM 与动作条件价值之间，是否存在可检验的完成率或成本差异？

两种结局都算结果。有差异，继续做方法；没有差异，按证据收缩方法线，把规则与 BTM 的适用边界作为结论。

## 决策

**1. 换到有重试与切换权衡的读取故障谱系。** 首次错误的公开回执相同，最优首动作取决于重试成功率 $p$ 与当前公开报价。$p$ 不是任何策略都读不到的隐藏量：它由登记的隐藏状态分布决定，可以从合法训练观测、公开上下文或付费诊断中估计。写入谱系与发布任务继续留在开发侧。

**2. 概率、采样与估值分开定义、分开估计、分开报告。** 完整定义见实验 037 第 2 节，要点：

- 隐藏状态分布 $P(Z\mid X)$ 是 Benchmark 生成器登记的量，只在环境与评分侧。
- 实际动作成功是某次被接受的调用在某个回合里的结果，是一次观察，不是概率。
- 动作成功概率 $p_a(h)$ 是给定公开历史后、对隐藏状态后验求和得到的待估量；重试成功率 $p(h)$ 是其特例。
- 工具级干预 $T_a$ 是带 `tool_choice` 的一次请求，参数由模型填写，被拒绝的调用不算执行。
- 固定续程 $\pi$ 必须具名；相对一个续程估计的 $Q$ 不能当作另一个续程下的 $Q$。
- 动作条件估值 $\hat Q^\pi(h,a)$ 是严格完成率与平均实际后缀成本的二元组，来自按登记概率分配了 $T_a$ 的训练回合，附样本数与区间。
- 显式诊断的净价值是新增诊断信息改变后续动作所带来的收益减去诊断费。

不用隐藏真值填充任何估值。机制格的理论值是在登记分布和理想续程下的核算，用来检查设计自洽，不是对真实 Agent 的预测。

**3. 信息公平定在原始材料上，落实方式是独立的实验维度。** 所有方法共用同一个原始历史池、同一份工具合同与静态工具知识、报价、合法反馈、预算与评分；各方法从中计算什么统计量属于方法本身，不强求一致。落实方式分两种，分开比较：作为上下文或建议交给模型，或由控制器强制工具选择。

**4. 我们的方法逐级定义，外部基线不被削弱。** 外部基线是 ReAct、在验证集上选定的最强简单规则（当前反馈、固定顺序、成本启发式、固定门槛的诊断规则）和完整 BTM。我们的方法分四级，后三级是待检验的增量假设，不承诺全部实现：

- M0：动作条件估值加字典序决策，按预先统计的动作结果与阶段选计划。在每个检查点只考虑当前合法、剩余预算内走得完的候选计划，用各分支的成功率、完成率和按当前报价重算的实际条件期望成本，先比完成率再比成本，全部不可行时停止。它不假定任何一步必成。
- M1：加显式诊断的净价值。
- M2：加基于反馈内容的信念更新。用新反馈的具体内容更新对隐藏故障状态的判断，并重新评估动作及其信息价值；失败后重新决策 M0 已经具备，不算 M2 的增量。
- M3：加支持度、估计不确定性与回退。

闭式条件 $\hat p>\frac{F}{S+F-R}$ 只在“直接切换必成、重试失败后切换必成、预算足够、续程必定完成”同时成立时才是 M0 的化简结果，不是独立的方法或基线。

正式报告两组比较。同一原始历史池上，外部基线对 M0，回答不同的历史建模方式是否改善恢复。同一动作条件统计上，M0 对 M1–M3，回答更复杂的决策机制是否有额外价值。不把“超过一个与自己基本相同的决策器”设为贡献的必要条件。实验允许 M0 已经足够，也允许 BTM 或简单规则持平；不为了让 M1–M3 各有收益而增加 Benchmark 的复杂度。

M0 不因归入我们的方法而被认定有创新性。$Q^\pi(h,a)$ 与字典序选择是标准的序贯决策建模。可能的贡献在于：从有偏的历史轨迹和有限的工具级干预里估计恢复动作的完整续程价值，并利用新反馈做序贯决策。冻结前须核对最近邻，说明它相对已有的上下文决策、历史记忆与部分可观测恢复规划新增了什么。

**5. 完整 BTM 按原方法的形式进入，统计表示消融单列。** BTM 向模型提供恢复统计、备用关系、返回粒度与恢复约束，由模型自己选动作，因此原版只出现在“建议”一侧，与它的正式比较只用这个形式。复现以论文原文为据，注明来源与偏差；论文报告的数字不作为对照。

另设“BTM 衍生选择器”作为统计表示消融：保持 M0 的决策器不变，只把输入换成 BTM 的任务级统计，用来区分收益来自统计表示还是决策器。它是我们构造的，不是原版 BTM，不承担主要的创新性比较。任务级恢复率不能直接代填动作条件完成率，也不能给每个动作填同一个数再按价格排序；动作排序须按 BTM 自己的键生成，映射方式暂按实验 037 第 5 节的候选，冻结前最终确认。衍生选择器用的仍是历史恢复的相关统计，不称为动作因果价值。

历史池含随机分配首动作的回合，与 BTM 原文的自然轨迹不同，记为复现偏差；正式评测之前另给 BTM 一份等量的自然轨迹池做敏感性实验，需另行批准才运行。

**6. 规则在新谱系运行之前冻结。** 冻结的是通用决策逻辑与阈值选择方式，在验证集上选定；新家族只按预先写明的方式适配公开工具合同。规则可以使用模型拥有的全部公开知识，不故意削弱。

**7. 历史用随机分配的首动作采集。** 在首错检查点按登记概率分配合法首动作并记录概率，用 Gate 33 的工具级干预落实，之后按固定续程走完。这样估计的是干预效果，不是模型自选动作的相关性。强制请求是工具级干预，不等同于模型自然选中该动作。

**8. 谱系按机制预登记，不按方法表现选题。** 同时保留简单规则本来就够用的格子、只有报价变化的格子、任务级恢复率相同而 $p$ 不同的格子、完成率不等的格子、诊断值得买与不值得买的格子，以及不可恢复格子。按基础任务、共享实现与故障事件谱系划分训练、验证与确认性留出；确认性留出在冻结前不运行任何候选方法。

## 备选与取舍

- **继续在写入谱系上扩样本。** 放弃：正确动作由一条回执唯一确定，不回答新的问题。
- **另设一个拿同样按动作统计、按字典序选择的外部强规则。** 初稿的做法，放弃：它就是 $Q^\pi(h,a)$ 的最简决策形式，列为基线等于人为造一个与自己相同的竞争者。它担心的“收益只来自多拿信息”改由共同的原始历史池和统计表示消融来回答。
- **强制所有方法使用同一种统计量。** 放弃：从同样的原始数据里算什么量正是方法的一部分。
- **把 BTM 做成强制选路器当主对照。** 放弃：改变了原方法，只保留为标注清楚的统计表示消融。
- **让隐藏状态完全不可估计。** 放弃：任何方法都无从决策，比较没有意义。
- **先实现贝叶斯预测器或规划器。** 暂缓：在余量被独立样本证实之前不投入。

代价：需要新建带公开上下文、可变报价、登记分布与不完美诊断的任务家族，并采集有随机分配的真实 Agent 历史，工作量明显大于此前各 Gate。

## 验证与边界

本 ADR 只冻结设计原则。分阶段的放行与止损标准见实验 037，要点是：

- Benchmark 实现后先做 CPU 精确核算，确认登记分布下各机制格的理论余量与设计一致，再运行真实 Agent。
- 在独立探索样本上比较真实 Agent、验证集最强简单规则与知情参照。若最强简单规则在所有机制格上都在最小实质差异之内，方法线收缩。
- M0 相对外部基线最强者持平时，方法线收缩；M1、M2、M3 中某一项相对 M0 持平时，不实现也不声称该项。
- 最近邻核对完成之前，不声称 M0 是算法创新。

未决事项需用户确认：M1、M3 的边界、BTM 衍生选择器映射方式的最终确认、自然轨迹池敏感性实验的时点、共同提示（等 [实验 036](../experiments/036-exit-wording-control.md) 退出措辞对照的结果，该实验同样待审批）、正式比较采用哪种落实方式作主表、历史采集所用的续程策略、最小实质差异与样本量、计价口径（`docs/metrics.md` 仍是草案）。撤回方式：本 ADR 未被批准前不产生任何代码或运行；批准后若止损条件触发，状态改为相应结论并保留全部记录。
