# ADR-0018 · Agent 级动作条件恢复对照

日期为 2026-11-08。状态为已批准，限冻结的小规模配对试点。试点范围与判据见[实验 020](../experiments/020-agent-recovery-comparison.md)。

## 决策

沿用 Q2。故障已被发现，状态与持续性仅部分可见。已有错误与历史反馈不增加动作，显式诊断单独计费，重试和切换的结果是执行反馈。诊断的价值取决于它是否改善后续选择及总成本。Gate 17 的强规则在 2,560 个配对起点与完整规划逐动作一致。Gate 18 检验固定权重 Agent 在整段恢复中能否利用这些信息，并保留该强规则检验 LLM 是否带来额外收益。[Gate 17 证据](../experiments/019-stochastic-dynamic-recovery.md)

在相同合法恢复历史 $h$ 上，对每个合法动作 $a$ 估计 $Q^\pi(h,a)$ 的三个分量，即严格完成概率、从当前动作开始的期望工具费和诊断费，续程使用固定的局部决策规则 $\pi$。每一步先用合法回执更新二状态信念，再用当前公开报价、剩余预算及公开路由概率重算。未揭示的具体分支在估值时按概率积分。先比较完成概率，再比较同一计价单位下的工具费与诊断费之和。报告仍按分项列示。用训练侧受控校准回放拟合动作结果与转移，保留各臂分母和验证误差。BTM 的历史统计则来自行为策略真实走过的轨迹，切换样本受策略选择影响。两类估计及各自的续程假设分开标记。

## 完整 BTM 的复现口径

核对 Bench2Robust v2 §3.1、§5.4、附录 B.1 的 Figure 2、arXiv 项目入口，并检索作者页面、GitHub 和 Hugging Face。截至 2026-11-08，未定位到可核验的作者实现。试点登记为 **BTM（论文提示复现，冻结后验）**。论文同时报告固定与跨回合在线版。论文主结果的在线版会用已结束评估回合的结局更新后验。严格留出试点采用固定版，所有评估回合共享训练后验初始化。BTM 与 Gate 18 的任务、评分和训练样本均来自本项目 Benchmark，论文 Retail 数字只作背景。鉴于缺少可核验代码，Gate 18 的判断以本项目复现结果及其覆盖度为准。[论文 §3.1](https://arxiv.org/html/2608.11977v2#S3.SS1) · [附录 B.1 与 Figure 2](https://arxiv.org/html/2608.11977v2#A2.SS1) · [论文记录](https://arxiv.org/abs/2608.11977v2)

- **历史部分。** 按公开工具与可见错误类别统计遭遇该键的回合中最终严格完成的比例。按同节点来源工具→替代工具统计实际发生该切换后最终严格完成的比例。回合内每个键至多计一次。Beta(1,1) 起始，显示后验均值 $(1+s)/(2+n)$ 及样本数 $n$，其中 $s$ 为最终严格完成的回合数。无样本用均匀先验并标记缺证据。Gate 17 共享错误归为一个公开类别。先验、去重和错误映射是本地复现选择。论文切换样本量约 6–20，其统计同样针对回合恢复。
- **完整提示。** 在系统提示中放工具／错误后验、切换后验、替代工具及结果粒度、如何比较两个统计并选择重试／切换／求助的说明，以及六项约束。失败后先重试至少一次，再尝试其他选项。切换后验证所需字段及粒度。不可逆操作前从实际回执确认全部必要字段。涉及价格计算时调用计算工具。写入后检查响应是否报错。重试及替代路线耗尽后才升级。Gate 17 的报价直接给定，价格计算工具条款标记不适用，求助或转交映射为结束恢复的 `stop`，写入和校验按现有任务契约表达。保留“先重试”和基于后验推荐切换之间的提示张力，由 LLM 按实际可用动作处理。环境合法性检查各组一致。
- **消融。** 单独去掉“先重试一次”条款，其余保持相同。另设完整静态提示加均匀概率，移除观测支持数，保留六项约束及替代工具说明，用于估计训练统计的增量。所有版本使用同一提示位置与注入时机。

## 统一执行

| Agent | 逐步决策 |
|---|---|
| 原始 ReAct | 同一基础任务提示与工具反馈，每次由 Qwen 选工具并填实参。保留任务内对话历史。 |
| 完整 BTM | 在 ReAct 上加入完整 BTM 系统提示，每次由同一 Qwen 自主选动作。 |
| Action-Conditioned Memory | 在 ReAct 的每步观察中加入各动作的完成概率、费用、估计支持度及本回合证据引用，由同一 Qwen 自主选择。 |
| LLM + 轻量决策器 | 每步由同一 Qwen 从工具契约、原始回执与任务中提取语义角色、当前凭据和相关反馈，标注证据位置。校验后用与上一组相同的 $Q^\pi$ 选择动作。 |

同一个工具适配器、公开信息、执行器和评分器贯穿首错到完成或停止。必要凭据由 Agent 从实际回执绑定，包装层只校验。失败、诊断和新路由回执均返回给 Agent 后再决策。Gate 17 原有的原子终态写入保持在执行器。ReAct 及两个提示组直接提交工具调用，混合组由抽取结果绑定实参。为混合组设置同决策器、确定性公开回执解析的非 LLM 对照。Gate 17 的回执结构规则，语义收益可能为零。所有模型组使用 Qwen3-4B-Thinking-2507、同一模型预算及非法动作处理。

## 最小工程范围

审核后在 `extensions/action_conditioned_recovery/` 增加 `gate18.py`、`gate18.json` 和专项测试。复用 `workflow17.py` 的回放与独立审计、`planning17.py` 的值递推和强规则、`gate17.py` 的训练校准轨迹和配对键、既有 vLLM 客户端及请求日志。只在必要位置让 Planner 接收训练拟合的发射概率，Gate 17 的默认参数和冻结配置保持原样。现有模型适配器的旧提示与宏动作面向旧任务，Gate 18 只复用客户端和协议记录方式。禁止向模型与常规策略传递隐藏状态、故障实现、未来回执、评估结果或参考路径。Oracle 如用于核验，独立标记并留在评估侧。运行前冻结提交并通过 `tests/test_no_leakage.py` 与专项验收。试点仅在 LabServer 执行。
