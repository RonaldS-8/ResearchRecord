# ADR-0027 · ToolMaze-Recovery Benchmark MVP

2026-11-10。路线 B 已批准，范围为最小工程实现、CPU 验收与少量已知任务的 Agent 冒烟。正式方法比较另行审核。

**Q2。** 工具故障已被发现、但原因或持续性等状态不完全可观测时，Agent 如何权衡信息获取价值、任务恢复收益与执行成本，选择显式诊断、重试、切换或停止，以兼顾任务完成质量与恢复效率？

Gate 26 的 [库存与合同审计](../experiments/028-toolmaze-recovery-integration.md#gate-26-补充审计--toolmaze-可用性与工程瓶颈)表明，原生静态路径不足以保证用户目标和独立状态证据。新建独立标识的 ToolMaze-Recovery 扩展，复用原生 Agent、工具定义格式、插件执行器和 Gate 25 调用账本。复用 Gate 26 方法适配器，MVP 中只提供零支持历史。原生任务、评分和冻结结果保留。ToolMaze 是任务执行参照，BTM 是任务级统计对照。MVP 的目标是验证动作条件价值与信息价值可在真实 Agent 循环中被研究，方法优势留待独立数据验证。

首版用工单摘要归档与通知、仓库实物库存预留与状态确认两个任务家族。Agent 读取自然语言任务、公开工具合同、实时回执和诊断证据，自主决定全部调用及参数。回执引用只承认当前会话真实签发的记录。独立评分读取模拟状态、实际内容、对象、次数与因果来源，允许任意满足义务的执行顺序。正确停止要求有明确阻断证据且模型报告阻断。

读入口可发生短暂、持续或共享依赖故障。相同首错隔离故障持续性。付费诊断读当前服务状态，可能提供有限证据、无新证据或自身失败。普通读取获得的信息仍计执行。所有费用为工程单位。工程放行依据 [实验 029](../experiments/029-toolmaze-recovery-mvp.md) 的登记条件。

## 2026-11-11 设计校准

Q2、诊断定义及动作价值公式沿用 AGENTS.md。路线 B 保留易例和可靠备用。首个增量使用库存预留的非幂等写入，两种相同超时分别对应未提交和已提交但响应丢失。增加按任务授权请求号查询的只读诊断，查询实际已提交记录，续程仍由 Agent 自主执行。共享后端故障沿用已有夹具。凭据失效、待提交或延迟可见、幂等键及其作用域留待后续。原开发任务、历史验收和费用口径保留。

规则续程与模型续程分别估值。Action-Conditioned Recovery 仍是候选，先保留完整 BTM、固定与最近反馈等强解释。余量分析在冻结的探索分布上进行，知情参照单列。正式比较前冻结三轴独立留出、配对统计、样本量与成本规则，并按跨 Gate 负结果约束继续投入。具体边界与本轮 CPU 登记见 [实验 029](../experiments/029-toolmaze-recovery-mvp.md#2026-11-11-设计校准)。
