# ADR-0028 · 真实 Agent 写入恢复与覆盖设计

2026-11-11。Gate 28，沿用 AGENTS.md 的 Q2、诊断定义与动作条件价值公式。

复用 Gate 27 的库存非幂等预留、提交前超时／提交后丢回执、授权查询和严格状态评分。原生 ReAct 的固定检查点恢复与自然语言完整执行分别验收。固定前缀由工程脚本执行真实工具调用，将实际回执按原生协议交给模型。之后模型自主选择全部动作与参数。两种隐藏状态不得改变公开前缀。

四个开发回合、模型版本、预算与判据先登记在 [实验 030](../experiments/030-agent-write-recovery.md)。失败完整保留，依登记结果决定下一阶段，不追加成功导向的提示修补。这个样本支持行为与工程诊断。

覆盖矩阵按业务合理性冻结设计，保留易例。下一批候选为制品发布和设施访问授权，独立建立工具合同与状态谓词，复用 Agent、执行、计费及诊断框架。本轮只审查接口并规划分组。探索性余量分析须另有独立验证样本、规则选优、知情信息声明与样本预算。
