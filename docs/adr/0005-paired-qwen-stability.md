# ADR-0005：共享首次抽样的 Prompt 与种子对照

- 日期：2026-11-05；状态：用户批准 Gate 5。
- 继承 ADR-0003/0004 的环境、评分与模型接口；不改原 Benchmark 或 Gate 4 文件。

新增独立 `run_stability.py` 和必要测试/启动脚本，复用严格模型适配器及 Gate 4 哈希核验、错误标签和基线。用一个轻量子类设置系统文本、种子、确定性检查温度，并复制已采样消息创建两个独立后续会话。模型侧只接收公共视图，不接收环境和配对标签。

正式环境故障状态只在可信执行侧展开。同一初始请求仅调用一次；复制的是实际 assistant 响应，不能生成第二次请求或合成新的推理。成对日志保存共享请求来源，后续反馈不跨分支。Token/延迟通过真实请求账本计数；分支归属首请求的一半，避免两次计费。实验指标与判据见实验 007。

分阶段：先提交登记 → 实现与云端必要测试 → 一对最小运行 → 六请求确定性检查 → 120 对正式运行。串行运行，不改 vLLM 服务或正式采样条件，不新增依赖，不修复模型输出。所有阶段按追加文件保留失败证据。
