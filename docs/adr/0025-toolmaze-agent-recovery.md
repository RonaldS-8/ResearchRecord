# ADR-0025 · ToolMaze Agent 恢复的最小执行切片

- 日期：2026-11-10
- 状态：获准最小实现与 CPU 验收
- 验收与样本审计：[实验 027](../experiments/027-toolmaze-agent-recovery.md)

**Q2 原文。** 工具故障已被发现、但原因或持续性等状态不完全可观测时，Agent 如何权衡信息获取价值、任务恢复收益与执行成本，选择显式诊断、重试、切换或停止，以兼顾任务完成质量与恢复效率？

复用 ToolMaze 的 OpenAI/vLLM Agent 协议、任务、工具定义和插件。独立包装层只执行 Agent 提交的调用，使用统一提示，在注册的读取工具上注入故障，并记录工具账本。私有验收侧从实际成功回执检查必要依赖与实参，再核对独立的模拟写入记录。已登记的复合插件在原生叶调用处记录效果，其他内部效果缺证据时不予认证。保留 Gate 19–23 冻结代码。

C3-002 是完整恢复验收样例。C3-001 的发布契约与原生参数存在冲突，且最终工具只生成预约请求。将它用于链路与误报拦截验收，待确认可观察的发布和预约契约后再纳入完整任务。已有状态与详情工具逐项核查。合法查询应仅按公开标识返回接口可提供的证据，并独立计费。完整 Q2 评估需通过诊断准入。

原生 ReAct、完整 BTM、Action-Conditioned Memory 和强规则对照在新环境共用合法工具、可见历史、价格和验收。保留既有方法作为实现来源，迁移任务绑定及历史键须用新环境训练侧证据验收。当前批准范围限于工程切片与只读样本审计。完整 Agent 实验须满足独立终态、三类独立留出及合法诊断的放行条件。
