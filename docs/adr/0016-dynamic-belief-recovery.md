# ADR-0016 · 动态路径与信念状态下的恢复

- 日期：2026-11-08
- 状态：已批准，限最小 CPU 验收

## 问题与决策

沿用 Q2、诊断定义和动作条件价值切口。在相同合法恢复起点分别估计重试、切换、显式诊断与停止的严格完成概率、工具费和诊断费。BTM 提供回合级历史恢复统计、切换统计与静态约束，仍独立保留。ToolMaze 提供多槽位依赖结构参照。有限状态信念更新是现成的数学工具，本轮贡献候选是可验证的决策反转及其证据来源。[实验 017](../experiments/017-recovery-decision-complexity.md) · [ToolMaze](https://arxiv.org/html/2606.05806v1) · [Bench2Robust §3.1](https://arxiv.org/html/2608.11977v2#S3.SS1) · [部分可观测决策的经典框架](https://cs.brown.edu/courses/csci2951-k/papers/kaelbling98.pdf)

复用 Gate 15 合成发票与凭据链。槽一合法准备可返回已有线索；在槽二同一报错后恢复；槽二成功后，合法回执才揭示是否需要槽三附加核验。共享服务商具有部分相关的故障，备用路径在主对照中可用，在压力格中也可失败。诊断仅在恢复起点开放一次，返回有噪证据，独立收费。重试或切换执行中的返回与推进任务的结果一同记账。

主实验把当前任务状态（已取得的凭据、可行动作和余额）、完整公开历史、故障信念及未来路径分布分别记录。用同一历史和报价分别改变状态估计或前瞻范围，避免把较好的先验、额外观测与更长规划混在一起。独立枚举与强简单规则并行。若把下一槽出现概率纳入 Gate 15 的闭式规则就已达到最优，保留机制结果并停止该条件下的方法开发。

## 实施边界

审核后仅在 `extensions/action_conditioned_recovery/` 增加 `gate16.json`、三槽位薄适配、有限枚举／回放入口和专项测试。复用 Gate 15 的公开策略回调、轨迹和账本，复用 Gate 14 的观测分组枚举。保留原生 ToolMaze 与已冻结的 Gate 12–15。初版只用云端 CPU 和有理数。完整 BTM 标记未运行，继续作为独立基线。矩阵与判据见[实验 018](../experiments/018-dynamic-belief-recovery.md)。
