# ADR-0009 · 独立恢复动作基准

- 日期：2026-11-06
- 状态：已接受，限最小 MVP
- 配套设计：[Gate 9 设计报告](../action-conditioned-recovery-benchmark.md)

## 背景

Gate 8 在原生 ToolMaze 中核实了剩余调用数与动作结果的差异，现有小样本未建立同一工具和错误统计项下可由合法上下文解释的动作反转。Gate 7 的 One-bit Memory 在其登记矩阵中达到理论最优。Q2 保持原研究范围，Gate 9 先检验基准能否分离任务恢复统计、动作条件经验和当前反馈的贡献。

## 拟议决策

在 `extensions/action_conditioned_recovery/` 建独立扩展。先用一个 C2 形状的两路径任务和固定故障检查点，复用 Gate 3 的执行、参数绑定和验证模式，复用 Gate 6 的前缀核对以及 Gate 7 的精确枚举思路。新故障与计价仅在扩展内生效。原生 ToolMaze 与已有运行记录独立保留。

MVP 只需确定性配对入口、可配置环境、规则对照和验证。优先直接复用可独立调用的现有函数；旧接口若绑定 ToolMaze 状态，则在扩展内做薄适配。真值和反事实分支只进入评测，策略通过同一公开接口交互。运行与测试在 LabServer 进行，配置和代码进入 Git，生成数据及运行产物留在云端。

## 验收与放行

审核本 ADR 与配套设计后才实施 MVP。探索性修订保留版本、理由和失败记录。正式实验前另行登记并冻结条件、划分、基线、指标及判据。强简单基线达到可见信息下的最优时，保留 Benchmark 验收结果并停止该条件下的方法开发。正式条件变更按 AGENTS.md 请示。
