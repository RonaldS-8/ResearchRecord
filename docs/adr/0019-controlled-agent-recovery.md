# ADR-0019 · BTM 与动作条件恢复的公平对照

日期为 2026-11-09。状态为已批准，限冻结的小规模配对试点。配对矩阵和放行判据见[实验 021](../experiments/021-controlled-agent-recovery.md)。

## 控制变量

沿用 Q2、诊断定义和 $Q^\pi(h,a)$。$h$ 是合法恢复历史，$a$ 是当前合法动作，$\pi$ 是 Gate 18 的固定局部续程规则。三个分量仍是严格完成概率、从当前动作开始的期望工具费和诊断费。用合法反馈更新信念。选择时先比较完成概率，再比较同一计价单位下的工具费与诊断费。结果分项报告。

核心组共用一份静态知识和操作提示，包含同节点替代工具映射、能力与凭据粒度、付费诊断、失败处理、后续节点发现、写入检查和完成验证。共用环境可用动作、停止语义和预算。BTM 与 Memory 使用相同的提示骨架、历史字段位置和动作选择协议，仅更换统计内容及必要的字段释义。BTM 提供工具／错误及切换后的回合完成后验。Memory 提供每个合法动作的 $Q^\pi$。核心提示不附加先重试要求，另用同一 BTM 提示只加 Gate 18 的先重试条款做消融。完整 BTM 与原始 ReAct 继续引用 Gate 18 的原始端到端轨迹，单列其接口与提示差异。[ADR-0018](0018-agent-recovery-comparison.md) · [实验 020 结果](../experiments/020-agent-recovery-comparison.md)

## 执行与权限

- **共用合法绑定。** Agent 只提交动作标识。适配层按当前公开动作集、预算与节点校验，再交给 Gate 17 的 `Workflow.act`，沿用该接口对准备回执和后续凭据的绑定。诊断和停止无需实参。记录绑定来源、实际调用、回执和账本。任何模型实参、越权动作及跳过未完成节点的请求都应被拒绝。严格评分及独立费用审计沿用原实现。
- **分开抽取与动作选择。** 直接组使用指定函数返回当前合法动作枚举。混合组使用独立的抽取提示和唯一指定函数，结构只含最新已揭示恢复观测的引用、结果类别和分支标志。初始无恢复观测的标记单独约定。工具能力可作为描述提供，环境工具不注册到抽取请求。逐字段验证所引回执和语义，成功后将验证过的证据交给同一 $Q^\pi$ 决策器，由决策器每轮选动作。抽取失败单列并停止回合，确定性解析只作为独立对照。两类请求均使用现有 vLLM 的指定函数机制和同一模型预算。混合组整体与 Memory 拥有同一公开信息和估值来源。
- **同源历史。** BTM 和动作价值均使用 Gate 18 已冻结的 36 条基础 ReAct 训练轨迹。保留 BTM 的 Beta 平滑、回合分母及切换定义。动作价值用同一批合法观测拟合 Gate 18 的二状态模型，按已走动作条件化序列似然，并按公开合同处理诊断和路由。既有受控 A／B 校准独立留作参照。本次共享观察历史有选路偏差和动作覆盖缺口，模型估值所依赖的跨节点共享假设及缺少直接样本的动作须单独披露。
