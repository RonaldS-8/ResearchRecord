# ADR-0004：Qwen3-4B 真实恢复决策接入

- 日期：2026-11-05
- 状态：用户明确批准 Gate 4；继承 ADR-0002 的本机 vLLM 与 ADR-0003 的固定 MVP。

仅新增独立模型适配器、配置、运行器和必要测试。复用 VLLMAgent 的客户端与消息/工具返回接口，使用 SDK 的原始 Chat Completions 响应完整记录输入、输出、usage 和请求耗时。原 Agent.step 会重试空响应并截取多个调用，故不使用该方法；本适配器禁止透明重试、并行多动作和输出修复，不改原 Agent。

模型只收到 RecoverySession 公共字典（动作列表限制为用户指定的 retry/switch/diagnose），以及三种无参恢复函数。背景工具描述仅用于理解任务，实际展开仍由 Gate 3 执行器完成。系统说明环境一般动力学、费用目标和交互协议，不提供当前状态、参考路径、理想动作或诊断收益公式。诊断和重试后的可见信息照常返回。

使用现有 Qwen3-4B-Thinking-2507 服务，vLLM 0.31.0，HF 修订 768f209d9ea81521153ed38c47d515654e938aea。温度 1、max_tokens 16000、超时 300 秒沿用既有配置；seed=0+步号，串行请求，SDK max_retries=0。环境、任务、价格、故障机制、预算和评分器不变；模型 Token/延迟单列，不擅自换算为请求成本或启用全局指标草案。

先做独立标记的诊断接口自检，再做单任务 4 情况自主决策，全部通过基本交互与评分检查后才运行 10×2×2=40 情况。自检的先诊断指令不计入自主结果，也不用于调提示。模型选择合法但昂贵的动作是实验结果；协议失败、泄漏、评分异常或预算耗尽无法完成基本交互则停止，不改条件。
