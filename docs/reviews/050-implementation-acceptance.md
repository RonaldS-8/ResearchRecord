## 判据实现与登记冲突

实验050第5节竞争解释3要求：**“参数错误导致的失败不计入机制份额。”** 第6节及 `summarize()` 用重复发布或预算耗尽份额决定 Go。

当前 `budget_failures` 只检查 `publications < 2 and budget_exhausted`，没有失败原因字段或排除步骤。因参数错误耗尽预算的回合也会进入分子。`illegal_calls` 虽另行报告，却不参与这一判断。实现不能保证执行第5节的排除要求。

可复算证据：[合成计数脚本](../evidence/050/acceptance-counterexample.py)、[输出](../evidence/050/acceptance-counterexample.json)。在仓库根执行：

```sh
python3 docs/evidence/050/acceptance-counterexample.py
```

脚本仅提取冻结的 `wilson()` 和 `summarize()`，构造120条合成汇总行：BTM-C十次失败均有非法调用、耗尽预算且没有重复发布，其余成功。函数返回机制份额1.0、H−BTM=1/3、`go`。**这不是 Agent 结果，也不能证明非法调用导致合成失败；它证明计数函数没有实施该排除。** 实际原因仍须阅读工具轨迹，不能用“存在非法调用”代替原因判断。
