# 实验 040 报告：CPU Autoresearch 的结论、候选机制与独立批评

2026-11-13。分支 `research/decision-recovery-autoresearch`，仅 CPU，未运行任何模型。登记、逐轮预测与完整数值见[实验 040](../experiments/040-cpu-autoresearch-decision-recovery.md)；代码 `extensions/toolmaze_recovery/autoresearch.py`（模型与方法）、`autoresearch_rounds.py`（各轮）、`tests/test_toolmaze_autoresearch.py`（16 项）。本文只写结论、依据和需要你们决定的事。Q2 科学问题未改。

## 结论

1. **成本权衡的余量有硬上限。** 在“重试还是切换”的成本权衡里，任何策略（包括知道隐藏状态的 Oracle）相对“两条固定规则中较好的一条”能省的比例不超过 $F\Delta/\big((F+\Delta)(R+\Delta)\big)$，只要失败的重试不比成功的重试贵，这个数不超过 25%。Gate 34 夹具的单位价格下是 12.5%，现实的诊断（准确率 0.9、费用 0.1）只有 7.5%。这解释了 Gate 9–17 为什么七次都是“规则够用”：不是方法不行，是环境里可省的钱本来就和 5% 的实质差异线同一量级。
2. **每个机制只需要很少的公开信息。** 十个机制格里八个的最优决策只依赖零个或一个公开因素；专门构造的两个多因素格里，只读一个因素的最好规则仅差 0.93% 和 1.62%。动作条件估值（下称 ACV）在同一份历史上从不差于学出来的简单规则，但优势只有 0%–4%，都低于 5%。
3. **真正值钱的是避免失误。** 损失大的不是“选错合理路线”，而是：不可恢复时不停（多花 25%–75%）、不顾预算地重试（丢 20 个百分点完成率，冻结的 simple_feedback 规则就有这个问题）、共享故障下不肯多等一步（14%–29%）、照着没有信息的诊断信号行动（最多 17.7%）。
4. **“先比完成率、再比成本”有三个此前没有记录的后果。** 精确意义下，备用工具只要有一点不可靠，最优策略就为十万分之一的完成率多花 25% 的钱；停止只在确定不可恢复时才最优，有噪声的诊断永远不能成为停止的理由；估计意义下，严格字典序会让完成率估计里的抽样噪声直接决定动作，ACV 因此在组合格上比最优高 8.7% 且不随样本收敛。加并列容差能修复大半，但固定容差不够好。
5. **BTM 式任务级统计的边界可以说清楚了。** 它的键里没有上下文、报价和诊断信号，在依赖这些信息的五个格上，信息上界等于“什么都不读”；在只依赖错误细节的格上它可以达到最优，但需要每格各自的门槛，没有一个门槛在所有格上损失都低于 5%。历史来自确定性策略时它处处饱和在 1；历史带混杂时它看不出任何问题。
6. **对论文的含义。** “ACV 在成本上赢过强规则”这条路被余量上限封住了，继续加机制复杂度找不回来。可以立得住的贡献更可能是：余量与信息需求的分析（解释负结果、指出哪里有余量）、字典序评测的脆弱性与修正、以及一个以“失误”为测量对象的 Benchmark。这是我的判断，供你们审核。

## 一、数学模型、公式与适用条件

**模型。** 首次超时之后是一个有限的部分可观测决策问题：隐藏故障状态 $z$ 的先验依赖公开上下文 $x$；动作为重试、切换、付费诊断（至多一次）、停止；失败调用照收费；调用预算有限；合法反馈是错误细节与诊断信号。价值是（严格完成概率，期望剩余费用），字典序比较。所有数值用有理数精确枚举。宏观模型在 Gate 34 的 9 个登记条件上与调用级精确参照及真实合同回放逐一相等。

**公式。** 记 $R$、$S$、$F$ 为重试成功续程、切换续程、失败重试的费用，$\Delta=S-R$，$p$ 为首次重试成功率。

| 结论 | 公式 | 适用条件 |
| --- | --- | --- |
| 首动作阈值 | 重试优于切换当且仅当 $p>p^*=F/(F+\Delta)$ | 备用必成、预算够重试后再切换（完成率并列） |
| 余量上界（绝对） | 任何策略的节省 $\le\min\{\bar p\Delta,(1-\bar p)F\}\le F\Delta/(F+\Delta)$ | 同上；$\bar p$ 为跨上下文的平均先验 |
| 余量上界（相对） | 节省÷较好固定规则的费用 $\le F\Delta/\big((F+\Delta)(R+\Delta)\big)\le 1/4$ | 另需 $F\le R$，即失败的尝试不比成功的贵 |
| 公开信息的价值 | $\min\{\bar p\Delta,(1-\bar p)F\}-\mathbb E_x\min\{p_x\Delta,(1-p_x)F\}$ | 同上 |
| 诊断净价值 | $p\le p^*$：$p\gamma\Delta-(1-p)(1-\gamma)F-d$；$p>p^*$：$(1-p)\gamma F-p(1-\gamma)\Delta-d$ | 二元状态、对称准确率 γ、诊断费 $d$ |
| 值得买的先验区间 | $\dfrac{d+(1-\gamma)F}{\gamma\Delta+(1-\gamma)F}<p<\dfrac{\gamma F-d}{\gamma F+(1-\gamma)\Delta}$ | 同上；γ=0.5 时为空 |
| 字典序翻转 | 备用每次以 β 成功时，先切换的完成率比先重试高 $P(\text{持续})(1-\beta)^2\beta$ | 夹具的调用预算 |

上界在 4500 个参数格上零违例，购买区间在 114 个参数点上与精确最优一致。

**“信息集下的最优”。** 对公开信息的任一子集，可以精确算出“只读这些信息的任何规则”能达到的最好值。它把“规则够不够”变成可计算的问题：读不够就有结构性损失，调参补不回来；读够了就等于最优。Gate 9–17 的强规则之所以都等于估值，是因为它们恰好读了各自机制的最小充分信息。

**ACV 的做法与假设。** 在每个可观测节点统计“动作→观测”的次数，用当前任务的报价沿估计树回推。没有支持的动作不参与比较，执行时回退到切换。它成立需要：历史在相同检查点上对动作做过随机分配（或倾向已知且不依赖未记录的信息）；历史与测试同分布；完成率的比较带并列容差。三条中任何一条不满足都有对应的失败实验（见第四节）。参数已知时 ACV 就是公共最优，这是定义，不是证据。

## 二、候选 Benchmark 机制

价位沿用 Gate 34 夹具。“余量”指读够信息的最优相对读得最少的最好规则。C、D、F、G、H 是实验 037 谱系草案在本模型下的对应物。

| 格 | 机制 | 最优决策要读什么 | 能区分什么 | 量级 | 判断 |
| --- | --- | --- | --- | --- | --- |
| A | 快暂态 0.9 | 无 | 是否肯重试 | 固定切换多 25% | 保留，规则足够的对照 |
| B | 先验随上下文变 | 上下文 | 是否利用上下文相关的历史 | 8.1% | 保留 |
| C | 只有报价变 | 报价 | 是否按当前报价重算 | 2.6% | 保留但低于 5%，单独不能区分方法 |
| D | 预算不足 | 无 | 是否顾及预算 | 丢 20 个百分点完成率 | 保留，失误格 |
| E | 有噪声付费诊断 | 信号 | 诊断是否改变动作 | 8.1%；无信息时照听多 2.5%–17.7% | 保留，并加无信息对照 |
| F | 多步错误细节 | 细节 | 新反馈到达后是否更新 | 3.9% | 保留但低于 5% |
| G | 不可恢复 | 无 | 是否及时停止 | 25%–75% | 保留，失误格，量级最大 |
| H | 共享故障一步后恢复 | 无 | 是否再等一步而不是换路 | 14%–29% | 保留，失误格 |
| CX | 上下文×报价 | 两者 | 两因素交互 | 交互项 0.93% | 淘汰为区分格，保留为负结果 |
| V | 上下文×诊断价×信号 | 三者 | 三因素交互 | 交互项 1.62% | 同上 |
| U | 备用不可靠 | — | 暴露字典序的脆弱 | 0.001% 完成率换 25% 费用 | 待你们定并列规则后再用 |
| S4 | 四种故障并存、先验随上下文变 | 上下文 | 尝试顺序与何时停 | 上下文 4.3%；无停止条款的规则 14%–19% | 候选主格，见第四节 |

**科研意义。** 这组格把 Q2 的四个动作各自“什么时候值钱”拆开了：重试的价值在 A、H，切换在 B、D，诊断在 E（及其无信息对照），停止在 G、S4。每格的最优值、Oracle 值和各规则的损失都是精确的，差异可以归因到某一条信息或某一个条款（预算保护、停止条款、是否听信号）。它们都能用合同语义实现：上下文是任务里的公开标签，报价在工具合同里，细节在失败回执里，诊断是单独计费的工具，费用与副作用由执行器逐次记账。但 C、D、F、G、H、S4 目前只存在于宏观模型里，执行器级实现是实验 037 的第二阶段，本轮未做。

## 四、最有效的候选与失败案例

**最有效的候选：S4 加一个无信息诊断对照。** 四种故障（快暂态、共享故障、持续、阻断）并存，先验随公开上下文变化，三个上下文的最优顺序各不相同（重试→切换→停；切换→重试→停；重试→重试→切换→停）。它同时满足本轮的五条目标：权衡不是人为指定的，而是由先验和调用费算出来的；历史改变决策（不读上下文多 4.3%）；每一次无效调用都是执行器里一条计费记录，停止是可观察的；规则、BTM 与 ACV 的差距可以分别归因到停止条款（14%–19%）、上下文（4.3%）和并列规则；模型是有限假设下的序贯搜索，有精确最优。配上 E 格的无信息诊断对照，可以检验“是否照着没有信息的信号行动”。

必须同时说明它的限度：在 S4 上，ACV 相对“不读上下文的最好顺序”最多好 4.3%，仍低于 5%；它能拉开的是“有没有失误”，不是“合理路线之间选哪条”。

**失败案例（全部保留）。**

1. ACV 在 S4 上不收敛（R7）。严格字典序下 N=3000 的平均费用 3.786，比最优高 8.7%，还不如固定顺序。原因是完成率要估计时，两个真实完成率相同的动作的估计值相差约 0.02，字典序把这点噪声当成了决定因素。G 格同理：严格版本即使 N=3000 也只有一半种子达到最优。
2. 固定容差只修好一部分（R8）。容差 0.05 在 S4 上 N=3000 时仍高 1.6%（我预测 1% 以内，被否定），N=300 时高 6.1%；容差 0.1 更省钱，但 N=300 时丢约 1 个百分点完成率；容差 0.3 在 D 格直接丢 20 个百分点。容差应当随估计误差缩放，这一步没有做。
3. 平滑估计配严格字典序会越学越错（R4）。A 格上加一平滑的版本在 N=1000 时 200 个种子全部选了更贵的切换，因为样本多的动作平滑后“显得完成率更高”。
4. 混杂日志（R5）。日志策略看得到隐藏状态而日志里没记时，ACV 把重试成功率估成 0.82（真实 0.3），全部种子选错，多花 10%。
5. 分布迁移（R5）。在成功率 0.9 的历史上学到的 ACV，到成功率 0.1 的测试上多花 20%；固定切换在反方向多花 25%。只靠旧历史没有稳健的方法。
6. 自然轨迹没有支持（R5）。日志策略恒切换时（038 里原生模型的行为），ACV 等于固定切换。
7. 诊断的可学性比预想的慢（R3）。无信息诊断的误买率在 1000 条历史时还有 12%，到 3000 条才降到 2%。有信息格里，历史不到 1000 条时“直接买”的冻结规则比 ACV 好。
8. 简单规则获胜或持平的场景。A、D、H 有一条固定顺序就是最优；未见过的报价上，固定重试在每个种子都是最优、不需要任何数据，ACV 到 3000 条才基本追平（6.002 对 6.0）；B 上学到的上下文规则与 ACV 完全相同；S4 上历史不足 1000 条时，一条不读上下文的固定顺序比 ACV 好。
9. BTM 式统计持平的场景。F 格上任务级恢复信念确实能区分两种错误细节（0.847 对 0.756），配合适的门槛达到最优。H 格上的持平是饱和统计量的样本数巧合，不算。
10. 我自己的两个错误。在估计值上给规则打分时，把规则的无效付费调用当成了免费停止（已修正并加了测试；R6、R7 修正后重跑，结果与首次运行逐字段相同，没有影响任何已报告的数值）；学到的成本阈值在未见报价上的坏结果来自我的并列取值方式，不能算 ACV 的胜利。

预测被否定的共 7 条，均在实验记录的各轮结果里标出。

## 五、独立批评

**创新性。** 本轮用到的数学都是教科书内容：阈值来自期望成本比较，诊断净价值是标准的信息价值，序贯部分是有限状态的部分可观测决策。“任务级统计不等于动作条件价值”这句话是对的，但第二节的结果说明，在这些机制里它等价于“读对一个因素的规则”。把创新点放在“ACV 优于规则”上站不住。我认为可能站得住的是三样：（一）余量上界与信息需求分析，它能事先告诉一个恢复 Benchmark 哪里有余量、哪里没有；（二）“完成率优先”的评测在精确与估计两种意义下的脆弱性及其修正；（三）以失误为测量对象并给出精确损失的机制格。最近邻需要核对：决策论故障排查（按成功概率与成本之比安排修复顺序的经典结果，我记得是 Heckerman 等 1995 年的工作，本轮没有重读）、信息价值、离线强化学习里的悲观估计、字典序与约束型决策过程。**本轮没有做文献检索**，以上是待查清单，不是结论。

**Benchmark 偏置。**

- 余量小是夹具结构决定的：路径只有 3–4 次调用，失败只花 1 次。价格再怎么调，相对余量也不超过 25%，现实参数下是个位数。
- 所有格的参数都是我定的。S4 里上下文值 4.3% 这个数依赖我选的三组先验；换一组可能更大也可能为零。本轮没有对 S4 的先验做扫描。
- 宏观模型假定“读成功之后一定走完”。真实 Agent 不是这样：038 里一个漏掉的句号就让一回合失败。CPU 上最大的成本差是个位数百分比，而真实执行失败是整回合的输赢，前者很可能被后者淹没。
- 字典序在真实 Agent 上会更成问题：备用路径多一步核验，Agent 走完它的概率很可能低于主路径。严格字典序下，这点完成率差就足以让成本完全不起作用。
- BTM 式代理是我写的确定性映射，不是 LLM 读提示后的行为；它只说明这些统计量带多少信息。
- 随机日志假设每个节点都能对动作做均匀随机分配。对真实 Agent 这意味着强制首动作，035 证明了工具级强制可行，但强制之后的续程是模型自己的，估出来的是该续程下的 $Q$。

**真实 Agent 的可行性。**

- 历史量：A 格上 10% 的步骤随机分配、300 条回合就够；学会“诊断有没有用”要 1000 条以上。按 038 的 20 回合 103 个请求估，每回合约 5 个请求，1000 条约 5000 个请求。若改用规则续程在 CPU 上采集，成本为零，但估的是规则续程下的价值。
- 温度为 0 时独立单位是不同的提示而不是种子（上一份审查已指出），有效样本量远小于回合数。
- 最便宜也最有信息量的一步不是采历史，而是先看 4B 模型在 G、D、H 和无信息诊断这几个检查点上**会不会犯这些失误**。如果它本来就会及时停、顾预算，那里就没有余量；如果会犯，这才是方法该去的地方。

## 六、需要你们决定的事与建议的下一步

1. **完成率并列怎么算。** 现行口径是严格字典序。本轮显示它在精确和估计两种意义下都会让成本失效。建议在方法的决策里把完成率相差不到最小实质差异（5 个百分点）视为并列，评测照旧分列两个数。这改变了指标在决策中的用法，按 AGENTS.md 需要你们确认，我没有改。
2. **Benchmark 第二阶段先做哪些格。** 建议先做 G、D、H 和 E 的无信息对照的执行器级实现，其次 S4；CX、V 不做。
3. **方法线的定位。** 若接受结论 6，M0–M3 的目标应从“成本上优于强规则”改为“用历史校准来避免失误，并决定诊断该不该买”。这涉及优先顺序，由你们定。
4. **建议的最小下一步（需批准，含模型推理）。** 在上述失误检查点上各跑原生 ReAct 与冻结规则，每个检查点只需少量不同提示，统计失误是否出现。止损：若原生模型在这些检查点上都不犯失误，方法线在这组机制上停止，只报告规则边界。
