## 数学与信息边界

1. **时钟是宏步近似，不能称逐工具调用 HMM。** 拟合、过滤、规划均为一次日志动作/反馈后转移一次；`certain` 尾部只消耗预算/费用，不产生观测或额外转移。三者内部一致。例：留在某状态概率为 0.8，一宏步后为 0.8，真实动作加三次尾部逐调用后则为 `0.8^4=0.4096`。Gate 42A 仍是固定隐藏状态、调用者自主绑参的真实合同；本 PR 没有把动态 HMM 接入该执行器，也没有实际 Agent 价值证据。
2. **标签来源可核验，但边界须保留。** 登记代码默认 `cell.alphabet()` 从生成器汇总标签，新增 `logged_labels` 没有用于登记轮次。独立检查 4,800 个训练前缀，仅 E_placebo / seed 6047 / N=30 少见一个 `persistent_hint`；两种信号名已有 Gate 34 的公开诊断合同依据，不是隐藏状态或概率泄漏。其余五格只有普通失败标签。换私有配置、保留同一公开标签表不改变训练/动作；不能把这种依赖生成器汇总表的接口泛称为已实现生产级信息隔离。
3. **固定容差有顺序依赖。** 独立构造 `(完成率,费用)=(1,3),(.96,2),(.92,1)`，容差 .05，六种枚举顺序分别可选出三个不同动作，损失可超过一次容差。ACV 与 Belief 求解器的初始候选/枚举顺序不同；“同宽度”不等于相同决策语义。0.01、0.05 均未因此获得可靠性或科研批准；未改变它们来追结果。
4. **保存的似然不是返回参数的似然。** `belief.py:150–159` 在 M 步之后返回更新参数，却保留前一 E 步的 loglik；train 用它选重启，BIC 用它选模型。独立小例两步更新后差 `0.002574`（静态）、`0.120711`（动态）。原文已披露，未修复；不能称为最终参数的精确似然/BIC。若后续修复，须另存版本并复核选择影响，不可悄悄替换已冻结结果。
5. **没有验证不确定性控制。** guard 在训练历史上做预测检查，非独立校准；薄历史下可能没有任何节点达到阈值。置信带只在根计算，错误确信完成率接近 1 时反而更宽。混杂/迁移无保护，已复现。真实状态数只进入具名消融；自动 K、第二版固定 K=5 未读取本回合真值或真实成功概率。选优包括已登记的重启、BIC、固定顺序族；不存在据留出终态选动作的代码路径。
6. **似然记号需谨慎。** 公开历史决定日志动作时，动作策略因子不依赖待估参数，可以从轨迹似然中略去，EM 的这一用法成立；报告把它直接写成“给定完整自适应动作序列的反馈条件概率”并不普遍成立。混杂日志不满足上述可忽略条件，不能作干预价值估计。文中的经典可识别性引用未提供原文核查，本次未把“三次观测”视为充分性定理，也未据此认证可识别性。

- “强简单规则”应称固定顺序＋ACV 选择器的混合对象；c5 仅一族未验证集选优的规则。不能据此宣称击败最强简单规则。低费用伴随低完成率不算效率收益；例如 E / N=300 的 ACV .05 实为 `.9975 / 3.735`，严格 ACV 为 `1 / 3.760`，须分别标注。

- 比例分母是登记的历史种子数（c1 为100，其余60）；每个种子再按登记上下文质量加权精确求值。不是工具调用数或独立任务数。校准量受支持/拒绝筛选影响，分段合并仍有近似，不能作为独立置信保证。
