# Q2 恢复决策方法线 · 止损结论与判据（供导师讨论）

2026-11-15。状态：**用户提议止损，待导师确认**。本文只汇总已有证据，不新增实验；数字均来自已提交记录，链接见各节。AGENTS.md 的研究目标在导师确认前不改。

## 一、结论

**建议终止 Q2“诊断与恢复联合决策”的方法线**，不再开发动作条件估值（ACV）、信息价值（VOI）、HMM/信念状态等方法，也不再为其扩建 Benchmark。

理由有两条，彼此独立：

1. **方法能争取的空间太小。** 在我们能想到的恢复场景里，读对一两个公开信号的简单规则已经等于或接近最优策略。成本维度的节省有数学上界；完成率维度在 7524 个参数格里没有一格达到 10 个百分点的差距。
2. **真实 Agent 的失败不在决策上。** 真实模型失败时，主要是认不出或不接受备用路线，而不是“理解了局面却选错动作”。只要告诉它“这条路走不通可以改走那条”，它就能完成。这是简单提示能解决的问题，不需要估值方法。

## 二、事先定下的判据与实际结果

### 2.1 余量判据（阶段 0，实验 048 登记）

“余量”指：只用合法信息的最优策略，比最强简单规则多完成的任务比例（严格完成率，百分点）。

| 判据（登记于实验 048 第 5 节） | 第一轮 2916 格 | 第二轮 4608 格 |
| --- | --- | --- |
| 有余量：≥10 个百分点的格占比 ≥10% | 2.9%，不满足 | 0%，不满足 |
| 无余量：全网格最大值 <5 | 最大 12.7，不满足 | 最大 7.2，不满足 |
| 局部余量：介于两者之间 | **是** | **是** |
| 事后检查：再加一条同样简单的规则（投票 / 报错重读） | 最大 0 | 最大 5.7，≥5 的格 0.28%，≥10 的格 0 |

**如实说明**：按登记判据，两轮结论都是“局部余量”，不是“无余量”。止损依据是：局部余量只出现在回读有噪声或会失败、首次报错无信息量的少数格；再加一条同样简单的规则后，第一轮降为 0，第二轮降到最大 5.7。这个量级不足以支撑“新方法明显优于强规则”的论文主张。

### 2.2 成本维度（实验 040/041，此前已完成）

| 结论 | 数值 |
| --- | --- |
| 任何策略（含知道隐藏状态的上界）相对较好固定规则能省的费用比例 | 理论上界 25%；本项目价格下 12.5%；现实诊断参数下 7.5% |
| 多路径场景中，读上下文带来的余量 | 中位 2.1%，最大 16.7%；M4 结构仅 1.5% |
| ACV 相对同历史学出的简单规则 | 优势 0%–4%，低于登记的 5% 实质差异线 |
| 第二轮完成率持平时，最优策略的费用节省 | 中位 0，91% 的格低于 5%，最大 34% |

此外，Gate 9–17 的七次比较、Gate 15–17 与 Gate 21 的多槽位/多路径比较，结论都是“简单规则等于精确规划”。

### 2.3 真实 Agent 判据（阶段 1，Gate47 预登记）

| 预登记判据 | 实际证据 | 判断 |
| --- | --- | --- |
| A：强 API 模型在足够多样的任务上接近 ≥90% | M3 3/3，M4 0/10；只有两个固定检查点 | 不满足 |
| B：语义/执行错误占失败过半，或澄清能消除主要失败 | 4B 语义误读 17/24；全部失败 17/34；参数/格式错误 0；合同澄清纠正 0/12 | 4B 满足前半句，整体恰好一半 |
| C：合同清楚时，强模型仍有可复现的“理解正确却选错” | 确认的此类失败 0 | 不满足 |
| D：其余 | — | **Inconclusive** |

配合 Gate45：不给信息或只给通用规则时，M4 为 0/5；给出“publish 失败可改走 prepare”的关系或首动作提示后，M4 为 5/5。统计数值本身的独立贡献无法识别。Bench2Robust 论文自己的消融结论相同：收益主要来自静态结构，而非历史统计。

## 三、没有测到、但不改变结论的部分

| 未覆盖 | 为什么不改变止损判断 |
| --- | --- |
| 强模型检查偏弱：qwen3.7-flash 平均每次请求推理约 50 Token（4B 约 1000），推理多为一句话 | 即使深度思考的模型也失败，Gate45 已显示关系提示即可纠正，属于“认路线”问题；若它成功，则说明失败来自浅推理或小模型能力。两种结果都不指向恢复决策方法 |
| 真实任务只有 M3/M4 两个检查点，temperature=0 下每格只有 1–2 种轨迹 | 不能做稳健统计，但 CPU 余量结论不依赖真实样本量 |
| CPU 模型是宏观抽象，规则在真实参数上挑选（对规则有利） | 方法即使在对它有利的估计下也只有个位数空间 |
| 没有覆盖多步依赖更深、状态更多的长流程 | 实验 041 的多路径/多槽位结构已显示同样规律；继续扩展需要自建 Benchmark，正是此前卡住的原因 |

**什么证据会推翻止损**：在多个独立任务上，强模型在合同清楚、关系已知时仍反复选错恢复动作，且最优策略相对强规则的完成率差 ≥10 个百分点。目前没有任何迹象指向这一点。

## 四、成本与可复用资产

- 投入：约 10 天、48 个编号实验；真实模型调用约数百次，API 费用可忽略（Gate47 为 0.013 元）。
- 可复用：ToolMaze 上的真实 Agent 运行与原始证据归档、API 预算控制、独立重放评分、防泄漏测试、精确 CPU 求解器（`extensions/toolmaze_recovery/`）。
- 方法教训：余量用 CPU 两三天即可算出，却在建好 Benchmark 之后才算；新题目应在第一周同时完成复现、余量估计和强模型检查。
